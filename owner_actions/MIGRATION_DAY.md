# Assisto সার্ভার মাইগ্রেশন — এক দিনের গাইড (মালিকের জন্য)

এই গাইড ধরে এগোলে Assisto নতুন সার্ভারে সরাতে এক দিনই যথেষ্ট। অ্যাপ ব্যাকএন্ডে
পৌঁছায় শুধু **ডোমেইন নাম** দিয়ে (raw IP নয়) — তাই সার্ভার বদলালে মূলত শুধু
**DNS বদলাতে হয়, নতুন APK লাগে না।**

সব স্ক্রিপ্ট আছে: `~/assisto/migration/` — টেকনিক্যাল বিস্তারিত ওখানকার `README.md`-তে।

---

## ১) নতুন সার্ভার কত বড় নেব?

| ব্যবহার | রিকমেন্ডেশন |
|---|---|
| **এখনকার মতো (1:1 + ছোট গ্রুপ কল TURN দিয়ে)** | 2 vCPU, **4 GB RAM** (বর্তমানের চেয়ে ভালো), 40 GB SSD |
| **গ্রুপ কল (SFU সহ, অনেক জন একসাথে)** | 4 vCPU, **8 GB RAM**, 60 GB SSD — SFU আলাদা RAM চায়; এর কমে Asalify-এর মতো চাপ পড়বে |

> এখনকার সার্ভারে RAM কম (3.7 GB, swap ~65% ব্যবহৃত) বলেই বড় গ্রুপ-কল SFU বসাইনি।
> নতুন সার্ভার 8 GB RAM নিলে বলবেন — আমি হার্ড-ক্যাপসহ SFU যোগ করে দেব।

## ২) ডোমেইন — নিজের ডোমেইন নেওয়া উচিত?

**হ্যাঁ, লঞ্চের আগে Assisto-র নিজের ডোমেইন নেওয়া ভালো** (যেমন `assisto.app` বা
`assisto.com.bd`), `assisto.asalify.com`-এর বদলে। কারণ:
- Asalify থেকে পুরো আলাদা ব্র্যান্ড + আলাদা DNS — ভবিষ্যতে একটার সমস্যা অন্যটায় যাবে না।
- Play Store/মার্কেটিং-এ নিজের ডোমেইন পেশাদার দেখায়।

**যদি নেন, ধাপ:** ডোমেইন কিনুন → DNS-এ একটা `A` রেকর্ড নতুন সার্ভারের IP-তে →
`provision.sh`-এ `DOMAIN=yourdomain` দিন → অ্যাপের পরের বিল্ডে base URL ঐ ডোমেইনে
দিন (একবারই)। এরপর থেকে সার্ভার বদল = শুধু DNS।
**এখন না নিলেও সমস্যা নেই** — `assisto.asalify.com` দিয়েই মাইগ্রেশন কাজ করবে; পরে
ডোমেইন বদলানো যাবে।

## ৩) নিরাপত্তা-গ্রুপ পোর্ট (ক্লাউড ফায়ারওয়াল)

নতুন সার্ভারের Security Group-এ এই ইনবাউন্ড পোর্ট খুলুন (বিস্তারিত ও কারণ:
`owner_actions/aws_ports.md`):

| পোর্ট | প্রোটোকল | কেন |
|---|---|---|
| 22 | TCP | SSH (আপনার IP-তে সীমাবদ্ধ রাখুন) |
| 80, 443 | TCP | ওয়েব + SSL |
| 3478 | UDP ও TCP | কল সার্ভার (STUN/TURN) |
| 49200–49300 | UDP | কল রিলে (হার্ড-ক্যাপড) |

> coturn লক করা আছে — private/loopback-এ রিলে নিষিদ্ধ, তাই পোর্ট খোলা থাকলেও
> ভেতরের কিছুতে (DB ইত্যাদি) পৌঁছাতে পারবে না।

## ৪) স্ক্রিপ্ট চালানোর ক্রম (মাইগ্রেশন দিন)

1. **আগের দিন:** DNS-এর TTL 300s করে দিন (দ্রুত কাটওভারের জন্য)।
2. **নতুন সার্ভারে** (root/sudo):
   ```
   sudo DOMAIN=assisto.asalify.com REPO=<git-url> ADMIN_EMAIL=<আপনার-ইমেইল> bash ~/assisto/migration/provision.sh
   ```
   (Python, Postgres, nginx+SSL, gunicorn, coturn—একই হার্ড-ক্যাপ, ব্যাকআপ-cron, watchdog সব বসায়)
3. **DNS:** `assisto.asalify.com` (এবং `TURN_HOST`) নতুন সার্ভারের IP-তে পয়েন্ট করুন।
4. **পুরোনো সার্ভারে:** `~/assisto/migration/backup.sh` → একটা এনক্রিপ্টেড `.enc` ফাইল
   + পাসফ্রেজ নতুন সার্ভারে কপি করুন।
5. **নতুন সার্ভারে:** `~/assisto/migration/restore.sh <bundle>.enc`
   (ডেটাবেস + media + পুরোনো secrets আনে — তাই Integrations-এর key গুলো পড়া যাবে)
6. `cd ~/assisto/backend && ../.venv/bin/python manage.py migrate`
7. নিরাপত্তা-গ্রুপ পোর্ট খুলুন (ধাপ ৩)।
8. **যাচাই:** `~/assisto/migration/smoke_test.sh https://assisto.asalify.com` → সব OK আসবে।

## ৫) কোন key কোথায় দেবেন

- **বুট secrets** (DB পাসওয়ার্ড, Django key, Fernet key, TURN secret, owner লগইন):
  `/home/ubuntu/.assisto_secrets.env`-এ। `restore.sh` পুরোনোগুলো নিয়ে আসে —
  **`INTEGRATIONS_FERNET_KEY` অবশ্যই আগেরটাই রাখবেন** (বদলালে Integrations-এ সেভ করা
  সব key অচল হয়ে যাবে)।
- **ফিচার provider key** (AI, Firebase/push, Maps, SMS/IVR, WhatsApp/Messenger,
  পেমেন্ট পার্টনার, Gmail OAuth, OCR, transcription, booking, Instagram/FB-Page,
  weather/news, voice-clone, Telegram): অ্যাপের ভেতর **Settings → Owner →
  Integrations** পেজে পেস্ট করুন। প্রতিটা না দিলে ঐ ফিচার সৎ "key লাগবে" অবস্থায়
  থাকবে — অ্যাপ ভাঙবে না। পুরো তালিকা: `~/assisto/migration/.env.template`।

## ৬) যাচাই (কাটওভার ঠিক হলো কিনা)

- `smoke_test.sh` সব সবুজ।
- অ্যাপ খুলুন — কোনো আপডেট ছাড়াই নতুন সার্ভারে যুক্ত হবে (ডোমেইন-ভিত্তিক)।
- পোর্ট খোলার পর দুই ফোনে একটা 1:1 কল করে দেখুন রিলে দিয়ে যুক্ত হয়।

## ৭) রোলব্যাক (নতুন সার্ভারে সমস্যা হলে)

- **সবচেয়ে দ্রুত:** DNS `A` রেকর্ড **আবার পুরোনো সার্ভারে** ফিরিয়ে দিন। অ্যাপ
  ডোমেইন-ভিত্তিক বলে TTL-এর মধ্যেই পুরোনো ব্যাকএন্ডে ফিরে যাবে — অ্যাপ বদলাতে হবে না।
- **পুরোনো সার্ভার কয়েক দিন চালু রাখুন** (ধ্বংস করবেন না) যতক্ষণ না নতুনটা নিশ্চিত হয়।
- নতুন সার্ভারে এর মধ্যে ডেটা বদলে থাকলে, ফেরানোর আগে নতুন সার্ভার থেকে একটা
  `backup.sh` নিয়ে নিন যাতে কিছু না হারায়।

---

**মূল কথা:** কোড + স্ক্রিপ্ট সব তৈরি। মাইগ্রেশন দিনে আপনি শুধু — নতুন সার্ভার নিন →
`provision.sh` → DNS → `backup.sh`/`restore.sh` → পোর্ট → `smoke_test.sh` → key পেস্ট।
আটকে গেলে আমাকে বলবেন।
