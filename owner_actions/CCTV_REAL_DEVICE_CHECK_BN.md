আসল Shop Box প্রোগ্রাম, আসল সার্ভার কোড, নকল FCM): `tools/e2e/cctv_e2e.sh`।

## ১০ মিনিটের পরীক্ষা

1. **(১ মিনিট) চালু করা** — মালিকের ফোনে Assisto → পাহারাদার → বাড়ি → গেটওয়ে "কম্পিউটার" →
   জোড়া লাগানোর কোড। পিসিতে AssistoShopBox খুলে কোডটি দিন।
   ✅ অ্যাপে গেটওয়ে "অনলাইন" দেখাবে (৩০ সেকেন্ডের মধ্যে)।
2. **(২ মিনিট) ক্যামেরা খোঁজা ও পরীক্ষা** — "আমার Wi-Fi-তে ক্যামেরা খুঁজুন" চাপুন।
   ✅ ONVIF ক্যামেরাটি তালিকায় আসবে (নাম/মডেলসহ)। ক্যামেরা যোগ করুন → পাসওয়ার্ড দিন →
   "যোগ করে পরীক্ষা করুন"। ✅ চারটি ধাপ সবুজ (পৌঁছানো, পাসওয়ার্ড, ভিডিও, ছবি) আর একটি ছবি দেখাবে।
   একবার ভুল পাসওয়ার্ড দিন → ✅ "পাসওয়ার্ড ভুল" বলবে, অন্য কিছু নয়।
3. **(১ মিনিট) জোন** — "জোন ও পাহারার সময়" → ছবির ওপর দরজার জায়গায় "নিষিদ্ধ এলাকা" আঁকুন →
   সময়সূচি "সবসময়" → সংরক্ষণ।
4. **(২ মিনিট) মানুষ চেনা** — ক্যামেরার সামনে দিয়ে হেঁটে যান।
   ✅ ১ মিনিটের মধ্যে দুই ফোনেই নোটিফিকেশন: "সন্দেহজনক — একটু দেখে নিন" (কখনো "চুরি" নয়),
   আত্মবিশ্বাস %, আর **একটি** ছবি। ✅ ছবিটি খুললে দেখা যায়; পরিবারের ফোনে শুধু দেখা যায়,
   চিহ্ন দেওয়ার বোতাম নেই। আবার হাঁটুন → ✅ একই সতর্কতায় "২ বার দেখা গেছে", নতুন নোটিফিকেশন নয়।
5. **(১ মিনিট) মতামত** — মালিকের ফোনে সতর্কতা → "ভুল" চাপুন। ✅ "ভুল হিসেবে চিহ্নিত" দেখাবে।
6. **(২ মিনিট) Hikvision** — অ্যাপে Hikvision ক্যামেরার ⋮ → "ক্যামেরার নিজের সতর্কতা (পুশ লিংক)"
   → লিংক কপি। ক্যামেরার ওয়েব পেজে: Configuration → Event → Smart Event → Line Crossing চালু,
   Linkage-এ "Notify Surveillance Center" টিক; Network → Advanced → **HTTP Listening** →
   Host: `lifeassisto.com`, Port: 80 (বা HTTPS 443), URL: লিংকের `/api/v1/shop/hook/...` অংশ।
   রেখা পার হয়ে হাঁটুন। ✅ দুই ফোনে সতর্কতা + ক্যামেরার নিজের ছবি।
7. **(১ মিনিট) Imou ক্লাউড** (চাবি থাকলে) — Imou ক্যামেরা যোগ → ডিভাইস সিরিয়াল + Safety Code →
   "Imou সতর্কতা যুক্ত করুন"। ক্যামেরার সামনে হাঁটুন। ✅ Imou-র নিজের মানুষ-সতর্কতা Assisto-তে আসবে
   (ছবিসহ, যদি Imou ছবি এনক্রিপ্ট না করে)। লেন্স বন্ধ/চালু (প্রাইভেসি মোড) করলে ✅ কোনো সতর্কতা আসবে না।

## কোনো ভিডিও জমা হয় না — নিজে দেখে নিন
সার্ভারে শুধু সতর্কতার তথ্য আর প্রতি সতর্কতায় একটি ছোট ছবি (৬৪০ পিক্সেল) থাকে; ৩ দিন পরে মুছে যায়।
ভিডিও কোথাও পাঠানো হয় না — পরীক্ষাটি `cctv_e2e.sh`-এ প্রতি বার যাচাই হয়।

## কিছু না মিললে
- গেটওয়ে অফলাইন: পিসি আর ক্যামেরা একই রাউটারে কিনা দেখুন; পিসির ঘুম (Sleep) বন্ধ রাখুন।
- খুঁজে পাচ্ছে না: ক্যামেরার ONVIF চালু করুন (অনেক মডেলে আলাদা ONVIF ইউজার লাগে)।
- Hikvision সতর্কতা আসে না: Linkage-এ "Notify Surveillance Center" টিক আছে কিনা, আর
  HTTP Listening-এ "Test" চাপলে সফল হয় কিনা দেখুন।
