# সিসিটিভি — আজকের মালিক-পরীক্ষা (৯ নভেম্বর ২০২৬) — সৎ অবস্থা + ধাপে ধাপে

**এক লাইনে:** আজ সবচেয়ে নিশ্চিত পথ = **দুটি ফোন** (একটি পুরনো ফোন ক্যামেরা, একটি আপনার ফোন)।
এর পুরো সার্ভার-পথ এখন প্রতিবার কম্পিউটারে আসল সার্ভার দিয়ে যাচাই হয় (CCTV লঞ্চ E2E-এর নতুন "phonecam" অংশ)।
কিন্তু **আসল দুটি ফোনে এটি আজ আপনার হাতেই প্রথমবার** — যা ঘটে, সময়সহ লিখে দিন; প্রতিটি ভুল নতুন টেস্ট হবে।

চিহ্ন: ✅ কাজ করে · 🟡 আংশিক · ❌ এখনো নয় · (কম্পিউটারে) = শুধু সিমুলেশনে প্রমাণিত, আসল ডিভাইসে নয়

## ১. কোন অংশ আজ কোথায়
| অংশ | অবস্থা |
|---|---|
| লাইভ দেখা | ✅ ফোন-ক্যামেরা: সরাসরি ফোন থেকে ফোনে (WebRTC), দরকারে আমাদের রিলে। ক্যামেরা-ফোন ১০ সেকেন্ডের মধ্যে অনুরোধ ধরে (আজ ২০ থেকে ১০ সেকেন্ড করা হলো)। একসাথে সর্বোচ্চ ২টি লাইভ, ৫ মিনিট না ছুঁলে নিজে বন্ধ। IP ক্যামেরা: শুধু পিসির Shop Box প্রোগ্রাম দিয়ে (কম্পিউটারে) |
| রেকর্ডিং | 🟡 ফোন-ক্যামেরা: প্রতি সতর্কতায় ~১০ সেকেন্ডের ক্লিপ ক্যামেরা-ফোনে (৫০০ MB সীমা)। **নতুন (cctvplay, পরের বিল্ডে):** সতর্কতার ছোট প্রিভিউ (কয়েকটি ছবি) নিজে থেকেই মালিক ও পরিবারের ফোনে যায়; পুরো ১০ সেকেন্ডের ভিডিও "পুরো ভিডিও আনুন" চাপলে ক্যামেরা-ফোন পাঠায় (এন্ড-টু-এন্ড এনক্রিপ্টেড, ফ্রি ২৪ ঘণ্টা / পেইড ৩০ দিন রাখা)। ঐচ্ছিক **একটানা রেকর্ডিং** (শুরুতে বন্ধ): ক্যামেরা-ফোনে ১ মিনিটের টুকরো, "রেকর্ডিং" পাতায় ঘণ্টার সময়রেখা, যেকোনো মিনিট দূর থেকে আনা যায় (কম্পিউটারে প্রমাণিত, আসল ফোনে নয়)। ভিডিও অ্যাড-অন (SD কার্ডের ক্লিপ) শুধু Hikvision/Dahua/Imou-র মতো ক্যামেরায়, আসল ক্যামেরায় পরীক্ষা হয়নি |
| নড়াচড়া সতর্কতা | ✅ ফোনেই ছবির পার্থক্য দেখে। মানুষ-চেনা মডেল না থাকলে সৎ লেবেল "হয়তো" (কম গুরুত্বের পুশ) |
| মানুষ সতর্কতা | ✅ ফোনেই YOLOX-Nano মডেল (প্রথমবার ~৩.৬ MB নামে)। পুশ + একটি ছবি মালিক ও পরিবারের ফোনে। **আজকের ঠিক করা:** দোকানের জায়গায় ফোন-ক্যামেরা দিনে চুপ থাকত (দোকানের রাত ৯টা–সকাল ৯টা সময়সূচি) — এখন ক্যামেরা চালু থাকলেই সবসময় পাহারা। বড় ছবি (১২ MP) আগে বাদ পড়ত — এখন ছোট করে পাঠানো হয় |
| AI যাচাই (ক্লাউড) | ❌ **আজ বন্ধ** — এটা Gemini-র উপর চলে, Gemini আজ বন্ধ (402)। AI-কে Claude-এ সরানোর কাজ আলাদা এজেন্ট করছে। এর মানে: সতর্কতার কার্ডে "AI যাচাই হয়নি" দেখাবে, আর ভিজিটরের ছবির বাংলা বর্ণনাও আসবে না। **সতর্কতা নিজে ঠিকই আসবে** |
| ফোনে যা AI চলে (ইন্টারনেট-AI ছাড়া) | ✅ নড়াচড়া, মানুষ-চেনা, লেন্স ঢাকা/অন্ধকার, চার্জ খোলা, ব্যাটারি কম, ফোন গরম — সব ক্যামেরা-ফোনেই/সার্ভারের নিয়মে, Gemini লাগে না |
| রিলে (TURN) | ✅ কোড ও কম্পিউটারে; আসল দুই নেটওয়ার্কে (একটা Wi-Fi, একটা মোবাইল ডেটা) আজ প্রথম। মাসে ক্যামেরাপ্রতি ০.৩ GB রিলে সীমা |
| পরিবার/স্টাফের সাথে শেয়ার | ✅ "দর্শক যোগ করুন" (নম্বর দিয়ে বা My Circle থেকে): তাঁরা একই সতর্কতা ও ছবি পান। ফোন-ক্যামেরার **লাইভ** পরিবার দেখতে পায় শুধু আপনি "পরিবার লাইভ দেখতে পারবে" চালু করলে |
| পুরনো সতর্কতা দেখা (প্লেব্যাক) | 🟡 সতর্কতার তালিকা + প্রতিটির ছবি ✅। দূর থেকে ভিডিও: পরের বিল্ডে (উপরে রেকর্ডিং দেখুন); সীমা স্ক্রিনেই লেখা থাকে — ক্লিপের দৈর্ঘ্য, এই মাসের ভিডিও সীমা কত বাকি, ক্যামেরা-ফোন অফলাইন কিনা |
| প্ল্যান ও সীমা | ✅ ফোন-ক্যামেরাও ১টি ক্যামেরা হিসেবে গোনা হয়। ফ্রি অ্যাকাউন্টে ১টি ক্যামেরা অন্তর্ভুক্ত; দ্বিতীয়টিতে ক্রেডিট লাগে। Play-তে সিসিটিভি সাবস্ক্রিপশন পণ্য আপনার বানানোর অপেক্ষায় (CCTV_PRICING_BN.md) |

## ২. কোন ক্যামেরা আজ চলে
| ক্যামেরা | আজ | কীভাবে / কেন |
|---|---|---|
| পুরনো Android ফোন (Android 8+) | ✅ | নিচের দুই-ফোন পরীক্ষা। স্ক্রিন খোলা রাখতে হয় (ম্লান কালো), চার্জে লাগানো |
| যেকোনো RTSP/ONVIF IP ক্যামেরা | 🟡 | একই Wi-Fi-তে **Windows পিসিতে Shop Box প্রোগ্রাম** লাগে (কম্পিউটারে প্রমাণিত, আসল ক্যামেরায় নয়)। প্রোগ্রামটির ডাউনলোড লিংক এখনো অ্যাপে/ওয়েবসাইটে নেই — লাগলে লিড ফাইল দেবে। পুরনো ফোন দিয়ে IP ক্যামেরা দেখা ("গার্ড বক্স") সুইচ বন্ধ |
| Hikvision (IP) | 🟡 | RTSP/ONVIF দিয়ে Shop Box-এ + ক্যামেরার নিজের "HTTP Listening" সতর্কতা সোজা আমাদের সার্ভারে (আসল ফরম্যাটের নকল বার্তায় প্রমাণিত)। DS-2CE (অ্যানালগ/DVR) ❌ সরাসরি নয় |
| Dahua (IP) | 🟡 | Hikvision-এর মতোই (RTSP + নিজের ইভেন্ট পুশ) |
| EZVIZ | 🟡 | RTSP চালু করা গেলে Shop Box দিয়ে। EZVIZ ক্লাউড লিংক ❌ (আসল ডেভেলপার চাবি নেই, শুধু নকল সার্ভারে টেস্ট) |
| Imou | 🟡 | RTSP দিয়ে Shop Box-এ। Imou ক্লাউড সতর্কতা ❌ যতক্ষণ appId/appSecret চাবি নেই |
| TP-Link Tapo | 🟡 | Tapo অ্যাপে "Camera Account" বানালে RTSP চলে → Shop Box দিয়ে। Tapo-র নিজের সতর্কতা আমরা পাই না |
| Xiaomi (Mi Home) | ❌ | বেশিরভাগ মডেলে RTSP/ONVIF নেই, ক্লাউড অন্য অ্যাপকে দেয় না — আজ চলবে না |

## ৩. দুই-ফোন পরীক্ষা (~২০ মিনিট) — ফোন A = আপনার, ফোন B = পুরনো ফোন (ক্যামেরা)
আগে: দুই ফোনে Assisto-র **আজকের নতুন বিল্ড**; B চার্জে লাগানো; সম্ভব হলে B Wi-Fi-তে, A মোবাইল ডেটায় (রিলেও পরীক্ষা হবে)।
প্রতিটি ধাপের পাশে সময় (সেকেন্ড) আর পাস/ফেল লিখুন।

1. **A:** লগইন → মেনু → "বাড়ি ও দোকানের পাহারাদার" → "সেটআপ শুরু করুন" → "আমার বাড়ি" → গেটওয়ে "পুরনো Android ফোন" → নাম → তৈরি।
   (একটা জোড়া লাগানোর শিট আসবে — ওটা পিসির জন্য; বন্ধ করে দিন।)
2. **A:** জায়গাটির ভেতরে "পুরনো ফোনকে ক্যামেরা বানান" → QR + বড় কোড আর সময় গোনা দেখাবে।
3. **B:** Assisto-তে লগইন করুন (যেকোনো অ্যাকাউন্ট, আপনারটাও চলে)। B-এর ক্যামেরা/Google Lens দিয়ে A-র QR স্ক্যান → Assisto খুলে কোড ভরা পাতা → "যুক্ত করুন"।
   না খুললে: B-তে পাহারাদার → "এই ফোনকে ক্যামেরা বানান" → কোড টাইপ।
   ✅ A-র শিটে সবুজ টিক "যুক্ত হয়েছে" (≤১০ সেকেন্ড)।
4. **B:** "ক্যামেরা চালু করুন" → ক্যামেরার অনুমতি দিন → স্ক্রিন ম্লান কালো, উপরে "রেকর্ড হচ্ছে" লেখা।
   ✅ লেখা "এই ফোনেই মানুষ-চেনা: চালু" (প্রথমবার মডেল নামতে ১ মিনিট লাগতে পারে; না নামলে "মানুষ-চেনা নেই — যেকোনো নড়াচড়ায় সতর্কতা")।
5. **মানুষ সতর্কতা:** B-এর সামনে দিয়ে হেঁটে যান।
   ✅ ≤১৫ সেকেন্ডে A-তে পুশ "সন্দেহজনক — একটু দেখে নিন" + আত্মবিশ্বাস % + **একটি ছবি**। পুশ চাপলে সতর্কতা খোলে, ছবিসহ।
   ✅ B-তে "ফোনে ক্লিপ" সংখ্যা ১ বাড়ে। ২–৫ মিনিট পরে আবার হাঁটুন → নতুন পুশ নয়, একই সতর্কতায় "২ বার দেখা গেছে" (১০ মিনিটের ভেতরে একসাথে গোনা হয়)।
6. **লাইভ:** A-তে ক্যামেরাটি → "লাইভ"। ✅ ≤২০ সেকেন্ডে ছবি (সময় লিখুন)। HD চাপুন। উপরে পথ দেখায় (একই Wi-Fi / সরাসরি / রিলে)।
   লাইভ চলাকালীন B-তে নড়াচড়া-চেক থামে (পুরনো ফোন গরম হয় বলে) — এটা ইচ্ছাকৃত।
7. **প্লেব্যাক:** A → সতর্কতার তালিকা → আজকের সতর্কতা → ছবি খোলে ✅। ভিডিও ক্লিপ শুধু B-তে আছে (দূর থেকে চালানো যায় না — আজকের সৎ সীমা)।
8. **পরিবারের সাথে শেয়ার:** তৃতীয় ফোন (C) থাকলে: A → জায়গা → "পরিবারের যারা দেখবেন" → "দর্শক যোগ করুন" → C-র Assisto নম্বর।
   আবার B-এর সামনে হাঁটুন → ✅ A ও C দুটোতেই পুশ + ছবি। C-তে লাইভ চাপুন → ✅ লাইভ খোলে না, বার্তা দেয় যে মালিক এই ক্যামেরার লাইভ নিজের কাছে রেখেছেন।
   A-তে ক্যামেরার "পরিবার লাইভ দেখতে পারবে" চালু → "অনুমতি দিন" → C-তে লাইভ ✅ চলে।
9. **স্বাস্থ্য:** B-এর চার্জার খুলুন → ≤১ মিনিটে A-তে "চার্জ খুলে গেছে"। B-এর লেন্স হাতে ১ মিনিট ঢাকুন → "ক্যামেরা ঢাকা/অন্ধকার"।
10. **সরানো:** B → "এই ফোনকে ক্যামেরা থেকে সরান" → A-র তালিকা থেকে ক্যামেরা চলে যায় ✅।

লিখে পাঠান: দুই ফোনের মডেল + Android সংস্করণ, ধাপ ৩/৫/৬-এর সেকেন্ড, কোন ধাপ ফেল করল আর স্ক্রিনে কী লেখা ছিল।

## ৪. IP ক্যামেরা থাকলে (ঐচ্ছিক, ~১৫ মিনিট)
লাগবে: একই রাউটারে একটি Windows পিসি + Shop Box প্রোগ্রাম (লিডের কাছে চান)। তারপর CCTV_REAL_DEVICE_CHECK_BN.md-এর ১০ মিনিটের তালিকা।
Hikvision/Dahua হলে পিসি ছাড়াও ক্যামেরার নিজের সতর্কতা পরীক্ষা করা যায় (ওই ফাইলের ধাপ ৬) — কিন্তু তাতে লাইভ নেই।

## ৫. AI-র নির্ভুলতা (সৎ হিসাব)
লেবেল-করা টেস্ট সেটে মানুষ-চেনার precision/recall মাপা হচ্ছে (CI-তে, পাবলিক লাইসেন্সের ছবি)। ফল এলে এখানে বসবে।
লক্ষ্য ≥৯০%। আসল সিসিটিভি ফুটেজে (রাত, IR, দূর থেকে) সংখ্যা কম হতে পারে — তাই আপনার আজকের পরীক্ষাই আসল প্রমাণ।

## ৬. দূর থেকে ভিডিও (cctvplay — যে বিল্ডে আসবে, তাতে ~১০ মিনিট)
1. B-এর সামনে হাঁটুন → A-তে পুশ → সতর্কতা → "ভিডিও দেখুন" → ✅ ≤১ মিনিটে ছোট প্রিভিউ চলে। C (পরিবার) থাকলে C-তেও চলে।
2. একই শিটে "পুরো ভিডিও আনুন" → ✅ সাধারণত ৩০ সেকেন্ডের মধ্যে পুরো ১০ সেকেন্ডের ভিডিও চলে (সময় লিখুন)। নিচে "এই মাসে ... MB বাকি" লেখা দেখুন।
3. B-এর Wi-Fi বন্ধ করে আরেকটি সতর্কতার পুরো ভিডিও চান → ✅ "ক্যামেরা-ফোন এখন অফলাইনে" লেখা; Wi-Fi চালু করলে ভিডিও আসে।
4. A → জায়গা → ক্যামেরার পাশে "রেকর্ডিং" আইকন → "একটানা রেকর্ডিং" চালু → B-তে ২–৩ মিনিট পর A-তে নীল দাগ দেখাবে → কোনো মিনিটে চাপ দিন → "পুরো ভিডিও আনুন" → ✅ সেই মিনিট চলে।
5. B গরম/চার্জ খোলা হলে রেকর্ডিং পাতায় "থেমে আছে" + কারণ লেখা থাকে; সতর্কতা ঠিকই আসে।
