# সিসিটিভি — আজকের মালিক-পরীক্ষা (৯ নভেম্বর ২০২৬) — সৎ অবস্থা + ধাপে ধাপে

**এক লাইনে:** আজ সবচেয়ে নিশ্চিত পথ = **দুটি ফোন** (একটি পুরনো ফোন ক্যামেরা, একটি আপনার ফোন)।
এর পুরো সার্ভার-পথ এখন প্রতিবার কম্পিউটারে আসল সার্ভার দিয়ে যাচাই হয় (CCTV লঞ্চ E2E-এর নতুন "phonecam" অংশ)।
কিন্তু **আসল দুটি ফোনে এটি আজ আপনার হাতেই প্রথমবার** — যা ঘটে, সময়সহ লিখে দিন; প্রতিটি ভুল নতুন টেস্ট হবে।

চিহ্ন: ✅ কাজ করে · 🟡 আংশিক · ❌ এখনো নয় · (কম্পিউটারে) = শুধু সিমুলেশনে প্রমাণিত, আসল ডিভাইসে নয়

## ১. কোন অংশ আজ কোথায়
| অংশ | অবস্থা |
|---|---|
| লাইভ দেখা | ✅ ফোন-ক্যামেরা: সরাসরি ফোন থেকে ফোনে (WebRTC), দরকারে আমাদের রিলে। ক্যামেরা-ফোন ১০ সেকেন্ডের মধ্যে অনুরোধ ধরে (আজ ২০ থেকে ১০ সেকেন্ড করা হলো)। একসাথে সর্বোচ্চ ২টি লাইভ, ৫ মিনিট না ছুঁলে নিজে বন্ধ। IP ক্যামেরা: শুধু পিসির Shop Box প্রোগ্রাম দিয়ে (কম্পিউটারে) |
| রেকর্ডিং | 🟡 ফোন-ক্যামেরা: প্রতি সতর্কতায় ~১০ সেকেন্ডের ক্লিপ ক্যামেরা-ফোনে (৫০০ MB সীমা)। **নতুন (cctvplay, পরের বিল্ডে):** সতর্কতার ছোট প্রিভিউ (কয়েকটি ছবি) নিজে থেকেই মালিক ও পরিবারের ফোনে যায়; পুরো ১০ সেকেন্ডের ভিডিও "পুরো ভিডিও আনুন" চাপলে ক্যামেরা-ফোন পাঠায় (এন্ড-টু-এন্ড এনক্রিপ্টেড, ফ্রি ২৪ ঘণ্টা / পেইড ৩০ দিন রাখা)। ঐচ্ছিক **একটানা রেকর্ডিং** (শুরুতে বন্ধ): ক্যামেরা-ফোনে ১ মিনিটের টুকরো, "রেকর্ডিং" পাতায় ঘণ্টার সময়রেখা, যেকোনো মিনিট দূর থেকে আনা যায় (কম্পিউটারে প্রমাণিত, আসল ফোনে নয়)। ভিডিও অ্যাড-অন (SD কার্ডের ক্লিপ) শুধু Hikvision/Dahua/Imou-র মতো ক্যামেরায়, আসল ক্যামেরায় পরীক্ষা হয়নি |
| নড়াচড়া সতর্কতা | ✅ ফোনেই ছবির পার্থক্য দেখে। মানুষ-চেনা মডেল না থাকলে সৎ লেবেল "হয়তো" (কম গুরুত্বের পুশ) |
| মানুষ সতর্কতা | ✅ ফোনেই YOLOX-Nano মডেল (প্রথমবার ~৩.৬ MB নামে)। পুশ + একটি ছবি মালিক ও পরিবারের ফোনে। **আজকের ঠিক করা:** দোকানের জায়গায় ফোন-ক্যামেরা দিনে চুপ থাকত (দোকানের রাত ৯টা–সকাল ৯টা সময়সূচি) — এখন ক্যামেরা চালু থাকলেই সবসময় পাহারা। বড় ছবি (১২ MP) আগে বাদ পড়ত — এখন ছোট করে পাঠানো হয় |
| AI যাচাই (ক্লাউড) | 🟡 সতর্কতার ছবি ক্লাউড AI দিয়ে যাচাই আর ভিজিটরের বাংলা বর্ণনা — আগে Gemini-তে চলত, Gemini আজ বন্ধ (402)। আজকের বিল্ড ৩০৮-এ এটা Claude Haiku-তে সরছে (geminioff কাজ)। সেই বিল্ডে: সতর্কতার ১–২ মিনিট পরে কার্ডে "AI: মানুষ দেখা গেছে ..%"। পুরনো বিল্ডে: "AI যাচাই হয়নি"। **সতর্কতা নিজে দুই ক্ষেত্রেই আসে** |
| ফোনে যা AI চলে (ইন্টারনেট-AI ছাড়া) | ✅ নড়াচড়া, মানুষ-চেনা, লেন্স ঢাকা/অন্ধকার, চার্জ খোলা, ব্যাটারি কম, ফোন গরম — সব ক্যামেরা-ফোনেই/সার্ভারের নিয়মে, Gemini লাগে না |
| রিলে (TURN) | ✅ কোড ও কম্পিউটারে; আসল দুই নেটওয়ার্কে (একটা Wi-Fi, একটা মোবাইল ডেটা) আজ প্রথম। মাসে ক্যামেরাপ্রতি ০.৩ GB রিলে সীমা |
| পরিবার/স্টাফের সাথে শেয়ার | ✅ "দর্শক যোগ করুন" (নম্বর দিয়ে বা My Circle থেকে): তাঁরা একই সতর্কতা ও ছবি পান। ফোন-ক্যামেরার **লাইভ** পরিবার দেখতে পায় শুধু আপনি "পরিবার লাইভ দেখতে পারবে" চালু করলে |
| পুরনো সতর্কতা দেখা (প্লেব্যাক) | 🟡 সতর্কতার তালিকা + প্রতিটির ছবি ✅। দূর থেকে ভিডিও: পরের বিল্ডে (উপরে রেকর্ডিং দেখুন); সীমা স্ক্রিনেই লেখা থাকে — ক্লিপের দৈর্ঘ্য, এই মাসের ভিডিও সীমা কত বাকি, ক্যামেরা-ফোন অফলাইন কিনা |
| প্ল্যান ও সীমা | ✅ ফোন-ক্যামেরাও ১টি ক্যামেরা হিসেবে গোনা হয়। ফ্রি অ্যাকাউন্টে ১টি ক্যামেরা অন্তর্ভুক্ত; দ্বিতীয়টিতে ক্রেডিট লাগে। Play-তে সিসিটিভি সাবস্ক্রিপশন পণ্য আপনার বানানোর অপেক্ষায় (CCTV_PRICING_BN.md) |

## ২. কোন ক্যামেরা আজ চলে
| ক্যামেরা | আজ | কীভাবে / কেন |
|---|---|---|
| পুরনো Android ফোন (Android 8+) | ✅ | নিচের দুই-ফোন পরীক্ষা। স্ক্রিন খোলা রাখতে হয় (ম্লান কালো), চার্জে লাগানো |
| যেকোনো RTSP/ONVIF IP ক্যামেরা | 🟡 | **নতুন (cctvbox): পিসি ছাড়া "গার্ড বক্স"** — একই ওয়াই-ফাইয়ের একটি পুরনো Android ফোন (বা Android TV বক্স, একই অ্যাপ) ক্যামেরার RTSP ভিডিও নিজেই খোলে, ফোনেই মানুষ চেনে, ছবিসহ সতর্কতা পাঠায়, আপনি চাইলে লাইভ দেখায় (দ্রুত ছবির ধারা, সেকেন্ডে ~৪টি, শব্দ নেই)। ক্যামেরার পাসওয়ার্ড শুধু ওই ফোনে থাকে। সুইচ এখনো বন্ধ — CI-র এমুলেটর পরীক্ষা (আসল RTSP স্ট্রিম) সবুজ হলে চালু হবে। আসল ক্যামেরায় এখনো প্রমাণ হয়নি — নিচের ৪ নম্বর পরীক্ষাটাই প্রথম আসল প্রমাণ। পিসির Shop Box প্রোগ্রামও আগের মতো চলে |
| Hikvision (IP) | 🟡 | RTSP/ONVIF দিয়ে Shop Box-এ + ক্যামেরার নিজের "HTTP Listening" সতর্কতা সোজা আমাদের সার্ভারে (আসল ফরম্যাটের নকল বার্তায় প্রমাণিত)। DS-2CE (অ্যানালগ/DVR) ❌ সরাসরি নয়। গার্ড বক্সে সাব স্ট্রিম (Channels/102) নিজে থেকে (সুইচ চালু হলে) |
| Dahua (IP) | 🟡 | Hikvision-এর মতোই (RTSP + নিজের ইভেন্ট পুশ)। গার্ড বক্সে subtype=1 নিজে থেকে (সুইচ চালু হলে) |
| EZVIZ | 🟡 | RTSP চালু করা গেলে Shop Box দিয়ে। EZVIZ ক্লাউড লিংক ❌ (আসল ডেভেলপার চাবি নেই, শুধু নকল সার্ভারে টেস্ট)। গার্ড বক্সে: ইউজার admin, পাসওয়ার্ড = স্টিকারের ৬ অক্ষরের কোড (সুইচ চালু হলে) |
| Imou | 🟡 | RTSP দিয়ে Shop Box-এ। Imou ক্লাউড সতর্কতা ❌ যতক্ষণ appId/appSecret চাবি নেই। গার্ড বক্সে: ইউজার admin, পাসওয়ার্ড = স্টিকারের Safety Code (সুইচ চালু হলে) |
| TP-Link Tapo | 🟡 | Tapo অ্যাপে "Camera Account" বানালে RTSP চলে → Shop Box দিয়ে। Tapo-র নিজের সতর্কতা আমরা পাই না। গার্ড বক্সে: Tapo অ্যাপের "Camera Account" দিয়ে stream2 (সুইচ চালু হলে) |
| Xiaomi (Mi Home) | ❌ | বেশিরভাগ মডেলে RTSP/ONVIF নেই, ক্লাউড অন্য অ্যাপকে দেয় না — আজ চলবে না |

## ৩. দুই-ফোন পরীক্ষা (~২০ মিনিট) — ফোন A = আপনার, ফোন B = পুরনো ফোন (ক্যামেরা)
আগে: দুই ফোনে Assisto-র **আজকের নতুন বিল্ড**; B চার্জে লাগানো; সম্ভব হলে B Wi-Fi-তে, A মোবাইল ডেটায় (রিলেও পরীক্ষা হবে)।
প্রতিটি ধাপের পাশে সময় (সেকেন্ড) আর পাস/ফেল লিখুন।

1. **A:** লগইন → মেনু → "বাড়ি ও দোকানের পাহারাদার" → "সেটআপ শুরু করুন" → "আমার বাড়ি" → গেটওয়ে "পুরনো Android ফোন" → নাম → তৈরি।
   (একটা জোড়া লাগানোর শিট আসবে — ওটা পিসির জন্য; বন্ধ করে দিন।)
2. **A:** জায়গাটির ভেতরে "পুরনো ফোনকে ক্যামেরা বানান" → QR + বড় কোড আর সময় গোনা দেখাবে।
3. **B:** Assisto-তে লগইন করুন (যেকোনো অ্যাকাউন্ট, আপনারটাও চলে)। B-এর ক্যামেরা/Google Lens দিয়ে A-র QR স্ক্যান → Assisto খুলে কোড ভরা পাতা → "যুক্ত করুন"।
   না খুললে: B-তে পাহারাদার → "এই ফোনকে ক্যামেরা বানান" → কোড টাইপ।
   ✅ A-র শিটে সবুজ টিক "যুক্ত হয়েছে" (≤১০ সেকেন্ড)।
4. **B:** "ক্যামেরা চালু করুন" → ক্যামেরার অনুমতি দিন → স্ক্রিন ম্লান কালো, উপরে "রেকর্ড হচ্ছে" লেখা।
   ✅ লেখা "এই ফোনেই মানুষ-চেনা: চালু" (প্রথমবার মডেল নামতে ১ মিনিট লাগতে পারে; না নামলে "মানুষ-চেনা নেই — যেকোনো নড়াচড়ায় সতর্কতা")।
5. **মানুষ সতর্কতা:** B-এর সামনে দিয়ে হেঁটে যান।
   ✅ ≤১৫ সেকেন্ডে A-তে পুশ "সন্দেহজনক — একটু দেখে নিন" + আত্মবিশ্বাস % + **একটি ছবি**। পুশ চাপলে সতর্কতা খোলে, ছবিসহ।
   ✅ B-তে "ফোনে ক্লিপ" সংখ্যা ১ বাড়ে। ২–৫ মিনিট পরে আবার হাঁটুন → নতুন পুশ নয়, একই সতর্কতায় "২ বার দেখা গেছে" (১০ মিনিটের ভেতরে একসাথে গোনা হয়)।
6. **লাইভ:** A-তে ক্যামেরাটি → "লাইভ"। ✅ ≤২০ সেকেন্ডে ছবি (সময় লিখুন)। HD চাপুন। উপরে পথ দেখায় (একই Wi-Fi / সরাসরি / রিলে)।
   লাইভ চলাকালীন B-তে নড়াচড়া-চেক থামে (পুরনো ফোন গরম হয় বলে) — এটা ইচ্ছাকৃত।
7. **প্লেব্যাক:** A → সতর্কতার তালিকা → আজকের সতর্কতা → ছবি খোলে ✅। ভিডিও ক্লিপ শুধু B-তে আছে (দূর থেকে চালানো যায় না — আজকের সৎ সীমা)।
8. **পরিবারের সাথে শেয়ার:** তৃতীয় ফোন (C) থাকলে: A → জায়গা → "পরিবারের যারা দেখবেন" → "দর্শক যোগ করুন" → C-র Assisto নম্বর।
   আবার B-এর সামনে হাঁটুন → ✅ A ও C দুটোতেই পুশ + ছবি। C-তে লাইভ চাপুন → ✅ লাইভ খোলে না, বার্তা দেয় যে মালিক এই ক্যামেরার লাইভ নিজের কাছে রেখেছেন।
   A-তে ক্যামেরার "পরিবার লাইভ দেখতে পারবে" চালু → "অনুমতি দিন" → C-তে লাইভ ✅ চলে।
9. **স্বাস্থ্য:** B-এর চার্জার খুলুন → ≤১ মিনিটে A-তে "চার্জ খুলে গেছে"। B-এর লেন্স হাতে ১ মিনিট ঢাকুন → "ক্যামেরা ঢাকা/অন্ধকার"।
10. **সরানো:** B → "এই ফোনকে ক্যামেরা থেকে সরান" → A-র তালিকা থেকে ক্যামেরা চলে যায় ✅।

লিখে পাঠান: দুই ফোনের মডেল + Android সংস্করণ, ধাপ ৩/৫/৬-এর সেকেন্ড, কোন ধাপ ফেল করল আর স্ক্রিনে কী লেখা ছিল।

## ৪. IP ক্যামেরা + পুরনো ফোন, পিসি ছাড়া (ঐচ্ছিক, ~১৫ মিনিট — "গার্ড বক্স" সুইচ চালু হওয়ার পর)

3. **B:** "এই ওয়াই-ফাইতে ক্যামেরা খুঁজুন" → ক্যামেরা এলে চাপুন (না এলে ক্যামেরার IP লিখুন) → ব্র্যান্ড বাছুন → পাসওয়ার্ড (Imou/EZVIZ = স্টিকারের কোড) → "ক্যামেরা পরীক্ষা করুন"। ✅ = ক্যামেরার ছবি আর "ক্যামেরা চলছে: H264 · ৬৪০×৩৬০" এর মতো লেখা। সময় লিখে রাখুন।

5. ক্যামেরার সামনে দিয়ে হাঁটুন → **A-তে ছবিসহ সতর্কতা** (≤১৫ সেকেন্ড লক্ষ্য)। কত সেকেন্ড লাগল লিখুন।
6. **A:** ক্যামেরা তালিকায় নতুন ক্যামেরা → "লাইভ দেখুন" → ক্যামেরার ছবি চলমান দেখাবে (সেকেন্ডে ~৪টি)। B-তে লেখা আসবে "কেউ লাইভ দেখছে"।
7. ক্যামেরার বিদ্যুৎ ২ মিনিট খুলে রাখুন → A-তে "আইপি ক্যামেরা পাওয়া যাচ্ছে না" পুশ; আবার লাগালে B নিজে থেকে আবার যুক্ত হয়।
8. রাউটার ১ মিনিট বন্ধ করে হাঁটুন → রাউটার চালুর পর সতর্কতাটা দেরিতে হলেও A-তে আসে।
ফেল হলে লিখে পাঠান: ক্যামেরার ব্র্যান্ড+মডেল, ফোন B-এর মডেল, কোন ধাপে, স্ক্রিনে কী লেখা ছিল।

1. **যুক্ত করুন (দুই পথের যেকোনো একটি):** অ্যাপ → CCTV → জায়গার কার্ড → **"DVR-এর ব্র্যান্ড অ্যাপ যুক্ত করুন"** → Imou → SN + Safety Code →
   **সম্মতির ঘরে টিক** ("আমি এই ক্যামেরার মালিক…") → যুক্ত করুন → চ্যানেল বেছে **যোগ করুন**। অথবা Owner Admin → **Imou পরীক্ষার ক্যামেরা** → একই তথ্য + টিক → Link।
   ✔ ক্যামেরার নিচে হলুদ **"মালিকের পরীক্ষার ডিভাইস"** ব্যাজ দেখাবে। কোডটি কোথাও জমা থাকে না।
2. **লাইভ:** ক্যামেরার পাশে 📺 → ৩–১০ সেকেন্ডে ছবি আসা উচিত (Imou ক্লাউডের HLS, SD আগে; HD ট্যাপে)। সময় লিখুন।
3. **সতর্কতা + ছবি:** Imou Life-এ ক্যামেরার "Human detection / Motion" চালু রাখুন → ক্যামেরার সামনে হাঁটুন → ১ মিনিটের মধ্যে ছবিসহ পুশ আপনার
   ফোনে **এবং** পরিবারের দর্শকের ফোনে (দুই-ফোন পরীক্ষা)। না এলে সময়সহ লিখুন — Owner Admin-এর Imou কার্ডে "মেসেজ" সংখ্যা বাড়ছে কিনা দেখুন।
4. **একই Wi-Fi-তে RTSP (কোনো ক্লাউড ছাড়া):** VLC অ্যাপে (ফোন/পিসি, একই Wi-Fi) খুলুন
   `rtsp://admin:<Safety Code>@<ক্যামেরার IP>:554/cam/realmonitor?channel=1&subtype=0` (HD) বা `…&subtype=1` (SD)।
   IP: Imou Life → ক্যামেরা → ⚙️ → Device info / Network (বা রাউটারের তালিকা)। ইউজার সবসময় `admin`, পাসওয়ার্ড = Safety Code
   (Imou-র সর্বজনীন ডক/FAQ-এর Dahua-ধাঁচের পথ; কিছু নতুন মডেলে Imou Life → Device Settings → "RTSP"/ONVIF চালু করতে হয়)। ছবি এলে Guard Box/পুরনো ফোন দিয়েও চলবে।
5. **সরান (Unlink):** অ্যাপে "সংযোগ সরান" বা Owner Admin → Imou পরীক্ষার ক্যামেরা → **Unlink** → Imou-র নিজের সার্ভারে ডিভাইস ছেড়ে দেয় (unBindDevice);
   এরপর Imou Life অ্যাপে আবার নিজের অ্যাকাউন্টে যোগ করা যায় কিনা দেখুন।
**নিয়ম:** এই পথ (আমাদের ডেভেলপার অ্যাকাউন্টে বাঁধা) শুধু আপনার/অ্যাডমিনের পরীক্ষার ক্যামেরার জন্য — গ্রাহকের ক্যামেরা তাঁর উপস্থিতি ও সম্মতি ছাড়া কখনো নয়;
গ্রাহকদের জন্য খুলতে চাইলে Owner Admin → Imou কার্ডে আলাদা সুইচ লাগবে (এখন বন্ধ)। গ্রাহকরা পাবেন নিজের Imou অ্যাকাউন্ট দিয়ে এক-ট্যাপ (OAuth, টিকিট ৪৮৩-এর অনুমোদনের পর)।

## EZVIZ ক্যামেরা — ৫ ধাপ (একটি EZVIZ ক্যামেরা হাতে এলে)
আগে: Owner Admin → Integrations → EZVIZ → Test সবুজ (✅)। EZVIZ কনসোলে **"Video Security"-র ফ্রি ট্রায়াল** চালু থাকতে হবে (নিচের নোট)।
ক্যামেরা EZVIZ অ্যাপে Wi-Fi-তে চালু; নিচের স্টিকারে **সিরিয়াল (৯ অক্ষর)** ও **৬ অক্ষরের Verification Code**। অন্য EZVIZ অ্যাকাউন্টে থাকলে আগে সেখান থেকে সরান।
1. **যুক্ত করুন:** অ্যাপ → CCTV → জায়গার কার্ড → "DVR-এর ব্র্যান্ড অ্যাপ যুক্ত করুন" → EZVIZ → সিরিয়াল + কোড → সম্মতির টিক → যুক্ত করুন → চ্যানেল বেছে যোগ।
   ✔ "মালিকের পরীক্ষার ডিভাইস" ব্যাজ।
2. **লাইভ:** ক্যামেরার পাশে 📺 → ছবি আসে কিনা (SD আগে, HD ট্যাপে)। না এলে Owner Admin-এর EZVIZ কার্ডের "Test"-এর বার্তা লিখুন।
3. **সতর্কতা:** EZVIZ অ্যাপে "Motion/Human detection" চালু → সামনে হাঁটুন → **১–২ মিনিটের মধ্যে** পুশ (EZVIZ ফ্রি ট্রায়ালে পুশ-মেসেজ নেই, তাই সার্ভার প্রতি মিনিটে খোঁজে)।
   ক্যামেরা ছবি "এনক্রিপ্ট" করলে (EZVIZ অ্যাপে Image Encryption চালু) ছবি ছাড়া সতর্কতা আসবে — সৎভাবে লেখা থাকবে।
4. **প্লেব্যাক:** সতর্কতার পাতায় "রেকর্ডিং" → SD কার্ডের আগের ৩০ সেকেন্ড চলে কিনা (ক্যামেরায় SD কার্ড লাগবে)।
5. **সরান:** "সংযোগ সরান" → EZVIZ-এর সার্ভারে ডিভাইস ছেড়ে দেয়; EZVIZ অ্যাপে আবার নিজের অ্যাকাউন্টে যোগ করা যায় কিনা দেখুন।
**EZVIZ সার্ভিস (সৎ তথ্য, isaopen.ezviz.com/price, ৯ Nov):** লাইভ/প্লেব্যাকের জন্য **"Video Security" (Video Surveillance)** খোলা লাগে — **ফ্রি ট্রায়াল ১২০ দিন:
১০টি ডিভাইস, ১ Mbps, দিনে ১০,০০০ API কল, ০ টাকা** — পরীক্ষার জন্য যথেষ্ট। **"Message Service" (পুশ মেসেজ) ফ্রি ট্রায়ালে নেই** — পেইড প্ল্যান E1:
১০০ ডিভাইস, ৫ Mbps, **বছরে USD ৫৯৯.৯৯ (~মাসে USD ৫০)**; বাড়তি ট্রাফিক USD ০.৪০/GB। পরীক্ষার জন্য Message Service **লাগবে না** (আমরা প্রতি মিনিটে খুঁজি)।
কোনো পেইড জিনিস আমরা নিজে চালু করি না — সিদ্ধান্ত আপনার।

## Dahua (DoLynk) ক্যামেরা — ৫ ধাপ (একটি Dahua/DMSS ক্যামেরা হাতে এলে)
আগে: Owner Admin → Integrations → **Dahua DoLynk** → Save → **Test**। কার্ডে **"DoLynk sign-in OK"** দেখালে তবেই অ্যাপে Dahua দেখাবে।
না দেখালে কার্ডে যে কোড দেখায় তা লিখে দিন — DoLynk-এর API ডক লগইন ছাড়া খোলে না, তাই Doc Center-এর ৬টি পাতা (লিড চেয়েছে) পেলে আমরা মিলিয়ে দেব।
1. **Callback:** কার্ডে দেখানো "Callback URL" DoLynk কনসোল → Cloud Message-এ বসান (সতর্কতা পুশের জন্য)।
2. **যুক্ত করুন:** অ্যাপ → CCTV → "DVR-এর ব্র্যান্ড অ্যাপ যুক্ত করুন" → Dahua DoLynk → সিরিয়াল + Safety Code/ডিভাইস কোড → সম্মতির টিক → চ্যানেল বেছে যোগ।
3. **লাইভ:** 📺 → ছবি আসে কিনা, সময় লিখুন।
4. **সতর্কতা:** ক্যামেরার SMD (মানুষ/গাড়ি) চালু → সামনে হাঁটুন → ছবিসহ পুশ আসে কিনা (পুশ না এলে ১৫ মিনিট পরপর সার্ভার খোঁজে)।
5. **সরান:** "সংযোগ সরান" → DMSS অ্যাপে ডিভাইস আবার যোগ করা যায় কিনা।
**একই Wi-Fi-তে (কোনো ক্লাউড ছাড়া):** Dahua DVR/ক্যামেরা: VLC-তে `rtsp://admin:<পাসওয়ার্ড>@<IP>:554/cam/realmonitor?channel=1&subtype=0`; Guard Box (পুরনো পিসি/মিনি পিসি)
একই নেটওয়ার্কে থাকলে নিজে খুঁজে নেয় ও হার্ডডিস্ক/রেকর্ডিং প্রতিদিন পরীক্ষা করে।
