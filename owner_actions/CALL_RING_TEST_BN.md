# কল বাজার টেস্ট — প্রতিটি ফোনে (ring-everywhere)

মালিকের নির্দেশ (২৪ অক্টোবর): **"WhatsApp-এর মতো প্রতিটি ফোনে কল বাজতে হবে"** — Assisto বন্ধ থাকলে, সোয়াইপ করে সরিয়ে দিলে, ব্যাকগ্রাউন্ডে থাকলে বা অন্য অ্যাপ খোলা থাকলেও।

## এই বিল্ডে কী বদলেছে

1. **কল এখন নেটিভভাবে বাজে।** কলের পুশ আসামাত্র অ্যান্ড্রয়েডের নিজস্ব কোড (Flutter চালু হওয়ার আগেই) পুরো স্ক্রিনের কল নোটিফিকেশন দেখায়: ধরুন / কেটে দিন বোতাম, রিংটোন, ভাইব্রেশন, লক স্ক্রিনেও। আগে এটা Flutter-এর ব্যাকগ্রাউন্ড অংশের উপর নির্ভর করত, যা অনেক ব্র্যান্ডে দেরিতে চালু হতো বা চালুই হতো না।
2. **অ্যান্ড্রয়েড টেলিকম-এ VoIP কল হিসেবে জানানো হয়** (WhatsApp-এর মতো "self-managed" কল), ফলে ফোন কলটিকে আসল কল হিসেবে ধরে।
3. **সার্ভার জানে ফোনে রিং পৌঁছেছে কি না।** পুশ পৌঁছামাত্র ফোন জানায় (অ্যাপ বন্ধ থাকলেও)। যিনি কল করছেন তিনি প্রথমে "কল হচ্ছে…" দেখেন, অন্য ফোনে বাজলে "রিং হচ্ছে"।
4. **৪ সেকেন্ডে উত্তর না এলে পুশ আবার পাঠানো হয়** (সর্বোচ্চ ২ বার, একই কলের জন্য একটাই নোটিফিকেশন)।
5. **কখনো না পৌঁছানো কল** — ফোন পরে অনলাইনে এলে (অ্যাপ খুললে) "মিসড কল" দেখায়, একবারই।
6. **"কল বাজার সেটআপ" চেকলিস্ট** — লগইনের পর একবার (কিছু চালু না থাকলে), আর সবসময় সেটিংস থেকে। প্রতিটি লাইনে "ঠিক আছে / চালু নেই / দেখে নিন" আর একটা "ঠিক করুন" বোতাম। কিছু বাকি থাকলে সাইডবারের সেটিংসে লাল চিহ্ন, আর My Circle-এর উপরে ছোট ব্যানার।
7. **Owner Admin → Calls** পাতায় নতুন টেবিল: কোন ব্র্যান্ড / মডেল / অ্যান্ড্রয়েড ভার্সনে কত শতাংশ কলের রিং পৌঁছেছে।

> সত্যি কথা: আসল OEM ফোনের ব্যাটারি সেভার (ColorOS, MIUI, XOS…) এমুলেটরে নেই। CI-তে আমরা শুধু প্রমাণ করতে পারি যে অ্যাপ বন্ধ / অন্য অ্যাপ খোলা / স্ক্রিন বন্ধ / Doze অবস্থায় নেটিভ রিং আসে। প্রতিটি ব্র্যান্ডে আসল টেস্ট টেস্টারদের ফোনেই করতে হবে — নিচের ধাপ অনুযায়ী।

> অ্যান্ড্রয়েডের নিয়ম: **সেটিংস → অ্যাপ → Assisto → "Force stop" চাপলে** কোনো অ্যাপই (WhatsApp-ও না) পুশ পায় না, যতক্ষণ না অ্যাপটা আবার খোলা হয়। এটা আমাদের হাতে নেই। অনেক ব্র্যান্ডে **রিসেন্ট থেকে সোয়াইপ করাও Force stop-এর মতো কাজ করে** — সেজন্যই নিচের "অটোস্টার্ট" অনুমতি জরুরি।

## প্রতিটি টেস্টারকে প্রথমে যা করতে হবে (সব ফোন)

1. নতুন বিল্ড ইনস্টল করে Assisto খুলুন, লগইন করুন।
2. **সেটিংস → কল বাজার সেটআপ** খুলুন। প্রতিটি লাইন "ঠিক আছে" না হওয়া পর্যন্ত "ঠিক করুন" চাপুন।
3. নোটিফিকেশন: অনুমতি দিন। "কল" অংশটি (চ্যানেল) সাউন্ডসহ চালু রাখুন।
4. অ্যান্ড্রয়েড ১৪ বা নতুন: **পুরো স্ক্রিনে কল** — "Full screen notifications" / "পূর্ণ স্ক্রিন নোটিফিকেশন" চালু করুন।
5. ব্যাটারি: Assisto-কে **"Unrestricted / Don't optimise / সীমাবদ্ধ নয়"** করুন।
6. নিচে নিজের ব্র্যান্ডের ধাপগুলো করুন, তারপর চেকলিস্টে "করেছি" চাপুন।

## ব্র্যান্ড অনুযায়ী ধাপ

### Xiaomi / Redmi / POCO (MIUI / HyperOS)
1. সেটিংস → অ্যাপ → অ্যাপ ম্যানেজ → Assisto → **Autostart** চালু।
2. একই পাতায় → **Battery saver → No restrictions**।
3. Assisto → Notifications → সব চালু, "Lock screen notifications" → Show, "Floating notifications" চালু।
4. Assisto → Other permissions → **"Show on Lock screen"** এবং **"Display pop-up windows while running in the background"** অনুমতি দিন।
5. রিসেন্ট অ্যাপে Assisto-র কার্ড নিচে টেনে / লম্বা চেপে **লক (তালা)** করুন।

### OPPO / realme / OnePlus (ColorOS / realme UI / OxygenOS)
1. সেটিংস → অ্যাপ → অ্যাপ ম্যানেজমেন্ট → Assisto → **Allow auto launch / অটো লঞ্চ** চালু।
2. Assisto → Battery usage → **Allow background activity** চালু, **Allow foreground activity** চালু, "Optimise battery use" বন্ধ।
3. সেটিংস → ব্যাটারি → আরও সেটিংস → **"Optimise battery use"** তালিকায় Assisto → **Don't optimise**।
4. Assisto → Notifications → সব চালু, "Lock screen" → Show, "Banners" চালু।
5. রিসেন্ট অ্যাপে Assisto কার্ডের উপরের মেনু (⋮) → **Lock**।

### vivo / iQOO (Funtouch / OriginOS)
1. সেটিংস → ব্যাটারি → **Background power consumption management** → Assisto → **Allow**।
2. i Manager → App manager → **Autostart manager** → Assisto চালু।
3. সেটিংস → অ্যাপ → Assisto → Notifications → সব চালু, Lock screen-এ দেখানো চালু।
4. রিসেন্ট অ্যাপে Assisto কার্ড নিচে টেনে **লক** করুন।

### Infinix / Tecno / itel (XOS / HiOS)
1. **Phone Master** অ্যাপ → App management / Auto-start management → Assisto চালু।
2. Phone Master → Power saving → **App power saving / Smart power saving**-এ Assisto বাদ দিন (No restriction)।
3. সেটিংস → অ্যাপ → Assisto → Battery → Unrestricted; Notifications সব চালু।
4. রিসেন্ট অ্যাপে Assisto কার্ড লক করুন।

### Samsung (One UI)
1. সেটিংস → অ্যাপ → Assisto → Battery → **Unrestricted**।
2. সেটিংস → Battery and device care → Battery → **Background usage limits** → "Sleeping apps" ও "Deep sleeping apps" তালিকা থেকে Assisto **সরান**; "Put unused apps to sleep" বন্ধ রাখা ভালো।
3. Assisto → Notifications → সব চালু, "Calls" ক্যাটাগরি চালু।
4. অ্যান্ড্রয়েড ১৪+: সেটিংস → অ্যাপ → Assisto → **Full screen notifications** চালু।

### Walton / Symphony / Nokia / Motorola / অন্যান্য (প্রায় সাধারণ অ্যান্ড্রয়েড)
1. সেটিংস → অ্যাপ → Assisto → Battery → **Unrestricted / Don't optimise**।
2. Assisto → Notifications → সব চালু।
3. ফোনে আলাদা "Power manager" / "Phone manager" অ্যাপ থাকলে সেখানে Assisto-কে অটোস্টার্ট ও ব্যাকগ্রাউন্ডে চলার অনুমতি দিন।

## টেস্ট ম্যাট্রিক্স (প্রতিটি ফোনে, দুইজন লাগবে: A কল করবে, B-র ফোন টেস্ট হবে)

প্রতিটি লাইনের জন্য A থেকে B-কে My Circle ভয়েস কল দিন। B-র ফোনে যা হয় তা লিখুন: **বেজেছে (কত সেকেন্ডে) / বাজেনি / অ্যাপ খোলার পর বেজেছে**। A-র স্ক্রিনে "কল হচ্ছে…" থেকে "রিং হচ্ছে" কখন হলো সেটাও লিখুন।

| # | B-র ফোনের অবস্থা | কীভাবে তৈরি করবেন | প্রত্যাশিত |
|---|---|---|---|
| ১ | অ্যাপ খোলা | Assisto সামনে খোলা রাখুন | সাথে সাথে অ্যাপের ভেতরে কল স্ক্রিন |
| ২ | অন্য অ্যাপ খোলা | YouTube / Facebook খুলে রাখুন | উপরে কল নোটিফিকেশন (ধরুন / কেটে দিন), রিংটোন |
| ৩ | ব্যাকগ্রাউন্ডে | Home চাপুন | কল নোটিফিকেশন + রিংটোন |
| ৪ | রিসেন্ট থেকে সোয়াইপ | রিসেন্ট অ্যাপ থেকে Assisto সরিয়ে দিন | কল নোটিফিকেশন + রিংটোন (অটোস্টার্ট দেওয়া থাকলে) |
| ৫ | স্ক্রিন বন্ধ ১০ মিনিট | ফোন লক করে ১০ মিনিট রেখে দিন | লক স্ক্রিনে পুরো স্ক্রিনে কল |
| ৬ | ব্যাটারি সেভার চালু | কুইক সেটিংসে Battery saver চালু | কল বাজবে (বাজলে না লিখুন) |
| ৭ | Force stop (শুধু তথ্যের জন্য) | সেটিংস → অ্যাপ → Assisto → Force stop | **বাজবে না** — অ্যান্ড্রয়েডের নিয়ম; অ্যাপ খোলার পর "মিসড কল" দেখাবে |
| ৮ | কেটে দিন বোতাম | ২ বা ৫ নম্বর অবস্থায় "কেটে দিন" চাপুন | A-র ফোনে সাথে সাথে "কল কেটে দিয়েছেন" |
| ৯ | ধরুন বোতাম | ২ বা ৫ নম্বর অবস্থায় "ধরুন" চাপুন | অ্যাপ খুলে কল যুক্ত হবে, দুইজনই শুনতে পাবেন |
| ১০ | কলার কেটে দিলে | B বাজছে, A কেটে দিক | B-র রিং সাথে সাথে থামবে, "মিসড কল" আসবে |

রিপোর্টে লিখুন: **ফোনের ব্র্যান্ড, মডেল, অ্যান্ড্রয়েড ভার্সন** (সেটিংস → ফোন সম্পর্কে), আর চেকলিস্টের কোন লাইন "ঠিক আছে" ছিল।

Owner Admin → Calls → **"ফোন অনুযায়ী রিং পৌঁছানো"** টেবিলে টেস্টের পর প্রতিটি ব্র্যান্ডের হার দেখা যাবে। কোনো ব্র্যান্ডে হার কম হলে সেই ব্র্যান্ডের ধাপগুলো আবার করাতে হবে।
