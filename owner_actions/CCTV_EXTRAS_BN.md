# সিসিটিভি এক্সট্রা — প্রতিযোগী তুলনা, স্পেক, অবস্থা ও খরচ (২৮ অক্টোবর ২০২৬)

শাখা: `agent/cctvx` (CI: `ci/cctvx`)। সব কাজ কম্পিউটারে (টেস্ট + CCTV E2E-তে আসল RTSP ভিডিও, আসল Shop Box প্রোগ্রাম, আসল সার্ভার কোড, নকল FCM) প্রমাণিত; **আসল ক্যামেরা ও আসল ফোনে এখনো একবারও নয়।**
"পকেটে হাত" লেবেল আগের মতোই **বন্ধ** — আসল ক্লিপে মাপা হয়নি।

## ক. প্রতিযোগীরা যা করে (পাবলিক তথ্য; যেখানে নিশ্চিত নই সেখানে "যাচাই করা যায়নি")

| বিক্রি ছাড়া ড্রয়ার | Verkada / Solink / Rhombus: POS-এর "no-sale / void" লাইনের পাশে ভিডিও (দামি, কোটেশনে) | ছোট দোকানের Assisto POS **আর খাতা** দুটোই মেলায়; বিক্রি মিললে কিছুই রাখে না; বাংলায়; কাউকে দোষী বলে না |
| সতর্কতা থেকে সাইরেন | Hik-Connect / EZVIZ / Imou অ্যাপে নিজের ক্যামেরার সাইরেন বোতাম (মডেলভেদে) | এক অ্যাপে কয়েক ব্র্যান্ড: Imou (ক্লাউড API) + Hikvision (দোকানের Shop Box দিয়ে LAN-এ); যেখানে অফিসিয়াল উপায় নেই সেখানে সৎভাবে "সমর্থন নেই" |
| ক্যামেরা অফলাইন | Ring / Wyze ধরনের অ্যাপে "device offline" নোটিফিকেশন (যাচাই করা যায়নি, সব মডেলে নয়) | ক্যামেরা, Shop Box **আর** ইন্টারনেট — তিনটিই; একবার সতর্কতা, ফিরলে "আবার চালু, N মিনিট বন্ধ ছিল"; নীরব সময় মানে, তবে "আমি দূরে" হলে বাজে |
| মালিক না দেখলে অন্যকে | ভোক্তা অ্যাপে নেই (শুধু একসাথে সবার ফোনে যায়); পাহারা কোম্পানির "call tree" আছে (মাসিক খরচ) | মালিক নিজে বেছে নেন ৩ জন পর্যন্ত (সার্কেল থেকে), ২ মিনিট পরপর একজন একজন করে; কেউ খুললেই থামে; প্রতিটি ধাপ লেখা থাকে |
| দোকান খোলা/বন্ধ | খুচরা বিশ্লেষণ সিস্টেমে "store opened late" রিপোর্ট (দামি) | খোলার সময়ের পরে প্রথম নড়াচড়া = "দোকান খুলেছে"; ৩০ মিনিটে নড়াচড়া না হলে "এখনো খোলেনি"; বন্ধের দিন বাদ |
| রাতের রিপোর্ট | — | সন্ধ্যার হিসাবে "পাহারার রিপোর্ট": ড্রয়ার বিক্রিসহ/ছাড়া, দূরে থাকার সময়ের সতর্কতা, বন্ধ মিনিট, অন্যকে পাঠানো — ০ ক্রেডিট |
| ক্যামেরা বসানো | ইনস্টলার চোখে দেখে | ছবির আলো, ঝলক, স্পষ্টতা, জোনের মাপ ও কিনারা — বাংলা পরামর্শ, AI খরচ ছাড়া |
| প্রমাণ | Verkada ইত্যাদিতে ক্লাউডে প্রমাণ শেয়ার লিংক | ফোনেই ZIP: ছবি + ক্লিপের ফ্রেম + সময় + প্রতিটি ফাইলের SHA-256 + manifest-এর SHA-256 + থানার জিডির খসড়া; সার্ভার খোলা ক্লিপ কখনো দেখে না |
| প্রাইভেসি নোটিশ | দোকানে কেনা স্টিকার | বাংলা + ইংরেজি স্টিকার PDF (A4/A5) আর কর্মীদের নোটিশ — যা সত্য তা-ই; কোনো আইনি দাবি নয় |

## খ. ৯টি কাজের অবস্থা
