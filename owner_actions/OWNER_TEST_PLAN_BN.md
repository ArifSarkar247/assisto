# মালিকের আসল-ফোন পরীক্ষা — সব ৬১টি ফিচার, ৮ দিনে (১৭ নভেম্বর ২০২৬)

**এক লাইনে:** কোয়ালিটি বোর্ডের (`QUALITY_BOARD_BN.md`, সিটি সার্ভিসসহ ৬১ সারি) প্রতিটি ফিচারের জন্য একটি ছোট আসল-ফোন পরীক্ষা।
দিন ১ = CCTV + গাড়ি ট্র্যাকিং + হারানো ফোন + ট্র্যাকার চিপ + ট্রেন ট্র্যাকার। তারপর বোর্ডে যার স্কোর সবচেয়ে কম, সে আগে।
প্রতিটি পাস = বোর্ডে আসল-ফোন প্রমাণ (৯ পর্যন্ত যাওয়ার শর্ত)। প্রতিটি ফেল = একটি স্বয়ংক্রিয় টেস্ট। **কোনো ফিচার লুকানো হবে না** — ফেল মানে ঠিক করা।

## ০. শুরুর আগে (একবারই পড়ুন)

**যন্ত্র ও মানুষ**
- **ফোন ক** = আপনার ফোন (মালিক)। **ফোন খ** = পরিবারের একজন, তাঁর নিজের Assisto অ্যাকাউন্ট (My Circle-এ আপনার সাথে যুক্ত)।
- **পুরনো ফোন** = Guard Box (দোকান/বাসার ক্যামেরা পাহারা)। চার্জারে লাগানো, Wi-Fi-তে।
- **ক্যামেরা:** Imou, EZVIZ, Dahua, Hikvision (যেটা হাতে আছে)।
- **GPS ট্র্যাকার ও ট্র্যাকার চিপ:** কেনার **অনুমোদন এখনো বাকি** (STATUS-এ "অনুমোদন — ট্র্যাকার যন্ত্র কেনা": গাড়ি SinoTrack ST-901 4G; চিপ SinoTrack ST-903)। আসার আগে যা পরীক্ষা করা যায় তা দিন ১-এ আলাদা লেখা।

**সুইচ (ফিচার চালু আছে কিনা)** — ১৭ Nov দুপুরে লাইভ সার্ভার থেকে **শুধু পড়ে** দেখা (কোনো সুইচ বদলানো হয়নি): Play সংস্করণে ১২৯টির মধ্যে ৪৫টি বন্ধ।
প্রতিটি ফিচারের পাশে লেখা আছে: **✅ চালু** অথবা **🔌 আগে চালু করুন: `নাম`**।
চালু করার পথ (১ মিনিট): ব্রাউজারে **https://api.lifeassisto.com/owner/features** → **খুঁজুন** ঘরে নাম → **দেখান** → **বদলান** →

৩০ সেকেন্ড পরে অ্যাপ বন্ধ করে আবার খুললে দেখা যায়। কোন সুইচ এখনই চালু করা নিরাপদ, তার রায় `FEATURE_SWITCHES_BN.md`-এ।

## দিন ১ — CCTV ও ট্র্যাকার (ফ্ল্যাগশিপ)

### ১.১ CCTV (বোর্ড #৯, স্কোর ৩) — ✅ চালু (`home_watchman`, `cctv_watchman`); Guard Box অংশে 🔌 `guard_box_mode`
**যন্ত্র:** ফোন ক, ফোন খ, পুরনো ফোন, Imou/EZVIZ/Dahua/Hikvision ক্যামেরা।
**ব্র্যান্ড ধরে ১০ ধাপের পরীক্ষা এখানে আবার লেখা হয়নি — পুরোটা `CCTV_REAL_TEST_BN.md`-এ** (অংশ ১ Imou, ২ EZVIZ, ৩ Dahua DoLynk, ৪ Hikvision → Guard Box; ফলাফলের ছক অংশ ৬)। সেখানে দেখা যাবে কোন ব্র্যান্ডে আজ কী প্রস্তুত (Dahua-তে আপনার দুটি ক্লিক বাকি, Hikvision-এর চাবি নেই → Guard Box পথ)।
এখানে শুধু অতিরিক্ত দুটি ছোট পরীক্ষা:
1. ফোন ক: সাইডবার → **CCTV পাহারা** → **এই ফোনকে ক্যামেরা বানান** (পুরনো ফোনে করুন) → ধাপ মেনে জোড়া লাগান।
2. ক্যামেরা-ফোনের সামনে হাত নাড়ান → ফোন ক-এ **আপনাকে পাঠানো সতর্কতা**-তে ছবিসহ সতর্কতা আসে।
3. ফোন খ-কে **পরিবার লাইভ দেখতে পারবে**-তে যোগ করুন → ফোন খ লাইভ দেখে।
4. (🔌 `guard_box_mode` চালু করে) পুরনো ফোনে সাইডবার → **শপ বক্স** → **গার্ড বক্স (পুরনো ফোন)** → জোড়া লাগানোর কোড → **এই ওয়াই-ফাইতে ক্যামেরা খুঁজুন** → **ক্যামেরা পরীক্ষা করুন** → **৩. পাহারা শুরু**।
**পাস:** ২ মিনিটের মধ্যে আসল ক্যামেরা/ফোন থেকে ছবিসহ সতর্কতা ফোন ক-এ আসে, আর ফোন খ লাইভ দেখে।

### ১.২ চুরি-রোধ ও হারানো ফোন (বোর্ড #১১, স্কোর ২) — ✅ চালু (`anti_theft`)
**যন্ত্র:** ফোন ক ("হারানো" ফোন), ফোন খ (পরিবার — খোঁজার ফোন), একটি বাড়তি সিম। **আগে থেকে কোনো যন্ত্র কেনার দরকার নেই — আজই পুরোটা করা যায়।**
1. ফোন ক: সাইডবার → **হারানো ফোন** → **হারানো / চুরি সুরক্ষা** → **চালু করুন** → **রিকভারি পিন** সেট → **সেভ**; ফোন খ-কে দেখার মানুষ হিসেবে দিন।
2. ফোন খ: সাইডবার → **হারানো ফোন** → **যাঁদের ফোন আমি দেখে রাখি** → ফোন ক → **লস্ট মোড চালু করুন**।
3. ফোন ক-এর লক স্ক্রিনে বার্তা আসে; ফোন খ-তে **সর্বশেষ জানা অবস্থান** → **ম্যাপে খুলুন** ঠিক জায়গা দেখায়।
4. ফোন ক-এ ৩ বার ভুল পিন দিন → ফোন খ-তে **অনুপ্রবেশকারীর ছবি** আসে।
5. ফোন ক বন্ধ করে বাড়তি সিম ঢুকিয়ে চালু করুন → ফোন খ-তে **সিম পরিবর্তন শনাক্ত হয়েছে**।
6. **ছিনতাই (নতুন, flag-antitheft):** ফোন ক টেবিলে ৫ সেকেন্ড স্থির রাখুন (স্ক্রিন বন্ধ) → জোরে তুলে নিয়ে ১০ সেকেন্ড দৌড়ান → ফোন ক কেঁপে ওঠে, **"আপনি ঠিক আছেন?"** → কিছু না করলে প্রায় ১৫ সেকেন্ডে ফোন খ-তে সতর্কতা। আবার করুন, এবার দৌড়ের পরেই ফোন ক-এর লক নিজের পিন/আঙুলে খুলুন → ফোন খ-তে **কিছুই যায় না**।
7. **ভুল-সতর্কতা নয়:** ফোন ক লক খুলে হাতে রেখে রিকশায় ১০ মিনিট; নরম জায়গায় ফোন ফেলে দিন; টেবিল থেকে তুলে ব্যাগে রেখে হাঁটুন; দ্রুত হাঁটুন → ফোন খ-তে **একটিও** ছিনতাই-সতর্কতা নয়। (**হারানো / চুরি সুরক্ষা** → **ছিনতাই-সতর্কতা কতটা সংবেদনশীল হবে?** → **স্বাভাবিক**।)
8. ফোন খ: **লস্ট মোড বন্ধ করুন**।
**পাস:** লক, অবস্থান, অনুপ্রবেশকারীর ছবি ও সিম-বদল — চারটিই ৫ মিনিটের মধ্যে ফোন খ-এ; সত্যিকারের টানে ১৫–৩০ সেকেন্ডে সতর্কতা, লক খুললে কিছু নয়, ধাপ ৭-এ শূন্য সতর্কতা।

### ১.৩ গাড়ি ট্র্যাকিং (বোর্ড #১২, স্কোর ২) — ✅ চালু (`vehicle_tracking`, `vehicles`); দূর থেকে ইঞ্জিন বন্ধ (`vehicle_engine_cut`) নিরাপত্তার কারণে বন্ধ — রিলে-লাগানো আসল গাড়িতে "থামা গাড়ি" পরীক্ষার আগে চালু করবেন না
**যন্ত্র:** GPS ট্র্যাকার (**অনুমোদনের অপেক্ষায়**: SinoTrack ST-901 4G + ডেটা সিম), গাড়ি/মোটরসাইকেল, ফোন ক, ফোন খ।
**যন্ত্র আসার আগে আজই:** সাইডবার → **আমার গাড়ি** → **গাড়ি যোগ করুন** → নাম, রেজিস্ট্রেশন নম্বর, কাগজের মেয়াদ দিন → সেভ; **কেনার গাইড** খোলে; **লাইভ ট্র্যাকিং** → **ট্র্যাকার যুক্ত করুন** → ভুল IMEI (যেমন ১২৩) দিলে "এটি সঠিক ১৫ সংখ্যার IMEI নয়।" দেখায়। পাস = এগুলো ঠিক চলে, কোনো খালি/মরা বোতাম নেই।
**যন্ত্র এলে:**
1. ফোন ক: **আমার গাড়ি** → **লাইভ ট্র্যাকিং** → **ট্র্যাকার যুক্ত করুন** → **ট্র্যাকারের IMEI**, নাম, **ট্র্যাকারের সিম** → **যুক্ত করা শুরু করুন**।
2. দেখানো সেটআপ SMS ফোন ক থেকে ট্র্যাকারের সিমে পাঠান → ১০ মিনিটের মধ্যে "ট্র্যাকার সংযুক্ত হওয়ার অপেক্ষায়" বদলে ম্যাপে গাড়ি।
3. ১০ মিনিট চালান → **গতি**, **ইগনিশন** ঠিক দেখায়; ফোন খ-কে শেয়ার করুন → ফোন খ-এও চলন্ত গাড়ি।
4. থামার পর **গত ২৪ ঘণ্টা** → **যাত্রা**-তে দূরত্ব ও **সর্বোচ্চ গতি**; **পথ চালান** চাপলে পথ রিপ্লে হয়।
**পাস:** ম্যাপে গাড়ি ৩০ সেকেন্ডের বেশি পিছিয়ে থাকে না, যাত্রার দূরত্ব মিটারের কাছাকাছি (±১০%)।

### ১.৪ ট্র্যাকার চিপ — ব্যাগ/জুতা (বোর্ড #৩৫, স্কোর ২) — 🔌 আগে চালু করুন: `kids_watch` (চিপ এই পাতার ভেতরে)
**যন্ত্র:** ট্র্যাকার চিপ (**অনুমোদনের অপেক্ষায়**: SinoTrack ST-903) + ডেটা সিম, ফোন ক, ফোন খ। শিশুর বাবা-মায়ের সম্মতি।
**চিপ আসার আগে আজই:** সাইডবার → **বাচ্চাদের ঘড়ি ও স্কুল-মোড** → **যোগ করুন** → **ট্র্যাকার চিপ যোগ করুন** ফর্ম খোলে; "কোথায় কিনবেন" লিংক ব্রাউজারে খোলে; ভুল IMEI দিলে পরিষ্কার ভুল-বার্তা।
**চিপ এলে** (`TRACKER_CHIP_BN.md` অংশ ৩-এর ছোট রূপ):
1. ফোন ক: **ট্র্যাকার চিপ যোগ করুন** → নাম, IMEI, সিম অপারেটর → "কারা দেখবে"-তে ফোন খ-এর মানুষ → পরের ধাপ।
2. দেখানো SMS চিপের সিমে পাঠান → ১০ মিনিটের মধ্যে চিপ ম্যাপে।
3. চিপ নিয়ে ৫ মিনিট হাঁটুন → দুই ফোনেই কার্ডে "শেষ অবস্থান" বদলায়, ব্যাটারি % (বা সৎভাবে "জানা যায়নি")।
4. চিপ বন্ধ করে রাখুন → ৩ ঘণ্টা পরে দুই ফোনে "সাড়া দিচ্ছে না" সতর্কতা।
**পাস:** দুই ফোনেই চিপের অবস্থান ৫০ মিটারের মধ্যে ঠিক, আর সতর্কতা আসে।

### ১.৫ ট্রেন ট্র্যাকার, গন্তব্য অ্যালার্ম ও ভ্রমণ প্ল্যানার (বোর্ড #৪১, স্কোর ২) — 🔌 আগে চালু করুন: `train_tracker`, `dest_alarm` (দুটিই A তালিকায়); ভ্রমণ পরিকল্পনা ✅ চালু (`travel_planner`)

**পাস:** চারটি অবস্থায় (খোলা, বন্ধ, অন্য অ্যাপ, লক-পরে) বাবল ঠিক আচরণ করে।

### ৬.৪ চ্যানেল ও কমিউনিটি, একবার-দেখা মিডিয়া (#৪৮) — ✅ চালু (`my_circle`); এলাকার কমিউনিটি (`area_community`) এখনো অন্যদের কাছে পোস্ট পৌঁছায় না — তৈরি বাকি
**যন্ত্র:** ফোন ক, ফোন খ।
1. ফোন ক: **আমার সার্কেল** → **আরও** → **নতুন কমিউনিটি**/চ্যানেল → **চ্যানেল তৈরি করুন**।
2. ফোন খ-কে যোগ করুন → ফোন ক একটি পোস্ট দেয় → ফোন খ-এ আসে।
3. ফোন ক → ফোন খ-কে একবার-দেখা ছবি → ফোন খ খুলে দেখার পর আর খোলা যায় না।
**পাস:** দুই ফোনে পোস্ট মেলে, একবার-দেখা সত্যিই একবার।

### ৬.৫ লিংকড ডিভাইস ও এনক্রিপ্টেড ব্যাকআপ রিকভারি (#৫০) — ✅ চালু
**যন্ত্র:** ফোন ক, পুরনো ফোন (দ্বিতীয় ডিভাইস)।
1. ফোন ক: **আমার সার্কেল** → **আরও** → **লিংক করা ডিভাইস** → **ডিভাইস লিংক করুন** → পুরনো ফোনে স্ক্যান।
2. পুরনো ফোনে চ্যাট দেখা যায়, বার্তা পাঠানো যায়।
3. ফোন ক: সেটিংস → **এনক্রিপ্টেড ব্যাকআপ ও ফোন ট্রান্সফার** → পাসফ্রেজ → **এনক্রিপ্টেড ব্যাকআপ তৈরি করুন**।
4. পুরনো ফোনে লগ আউট → নতুন করে লগইন → **রিস্টোর** → পাসফ্রেজ → চ্যাট ফেরত আসে।
**পাস:** পাসফ্রেজ দিয়ে সব চ্যাট ফেরত; ভুল পাসফ্রেজে কিছুই খোলে না।

### ৬.৬ Owner Admin (#৫১) — শুধু আপনার জন্য (ওয়েব)
**যন্ত্র:** ফোন ক-এর ব্রাউজার।
1. ফোনের ব্রাউজারে **https://api.lifeassisto.com/owner/** → লগইন।
2. প্রতিটি মেনু পাতা একবার খুলুন (ফিচার সুইচ, Integrations, ব্যবহারকারী, পেমেন্ট…)।
3. যে পাতা ভাঙে, লেখা কাটে বা ১০ সেকেন্ডের বেশি লাগে — নাম লিখে রাখুন। **কোনো সুইচ/চাবি বদলাবেন না** যদি না সেটাই পরীক্ষা হয়।
**পাস:** সব পাতা ফোনে খোলে, পড়া যায়।

### ৬.৭ অ্যাকাউন্ট রিকভারি (#৫২) — ✅ চালু
**যন্ত্র:** ফোন ক, পুরনো ফোন।
1. সেটিংস → অ্যাকাউন্টের নিরাপত্তা পাতা → **ইমেইল যাচাই করুন** → মেইলের লিংক → "ইমেইল যাচাই হয়েছে।"
2. পুরনো ফোনে লগইন পাতায় পাসওয়ার্ড ভুলে যাওয়ার পথ → ইমেইলে লিংক আসে → নতুন পাসওয়ার্ড।
3. ফোন ক-এ নিরাপত্তা পাতায় নতুন লগইনের খবর ও **সাইন-আউট** বোতাম কাজ করে।
**পাস:** ৫ মিনিটের মধ্যে অ্যাকাউন্ট ফেরত; অচেনা ডিভাইস সাইন-আউট করা যায়।

### ৬.৮ বিজ্ঞাপন (AdMob) ও সম্মতি (#৫৪) — ✅ চালু; আসল বিজ্ঞাপন আইডি সুইচ (`admob_real_ids`) এখন বন্ধ — তাই টেস্ট বিজ্ঞাপন দেখাবে (`ADMOB_CONNECT_BN.md`)
**যন্ত্র:** ফোন ক (ফ্রি অ্যাকাউন্ট), ফোন খ (Premium থাকলে)।
1. অ্যাপ নতুন ইনস্টল করে খুলুন → বিজ্ঞাপন-সম্মতির পাতা আসে → বাছাই করুন।
2. সাধারণ পাতায় বিজ্ঞাপন দেখায়; **SOS, কল, খোলা চ্যাট, পেমেন্ট, লগইন** পাতায় কখনো নয় — প্রতিটি খুলে দেখুন।
3. ফোন খ (Premium/Plus): কোথাও বিজ্ঞাপন নেই।
**পাস:** নিষিদ্ধ পাতায় শূন্য বিজ্ঞাপন, সম্মতি মনে রাখে।

### ৭.২ AI সেলস সহকারী — Messenger/Instagram/WhatsApp (#১৪, স্কোর ৪) — ✅ চালু (`business_agent`)

2. ফোন খ: দোকানের চ্যাটে "লাল শাড়ির দাম কত? ডেলিভারি কবে?"

### ৭.৩ CRM ও CRM অটোমেশন (#১৫, স্কোর ৪) — ✅ চালু (`crm`); রিটেনশনে 🔌 `retention_auto` (A তালিকায়)

**যন্ত্র:** ফোন ক, ফোন খ। **পাস:** বার্তা একবারই যায়, অপ্ট-আউট মানে।

### ৭.৫ সিটি সার্ভিস (#৬১, স্কোর ৪) — ✅ চালু (`city_service`)

1. সাইডবার → **সিটি সার্ভিস** → **কোথা থেকে** = **আমার বর্তমান অবস্থান**, **কোথায় যাবেন?** = একটি চেনা জায়গা।
2. সবচেয়ে সস্তা / দ্রুত পথ → বাস/মেট্রো, ভাড়ার পাশে "সরকারি"/"ব্যবহারকারীদের" লেবেল।

4. মেট্রো স্টেশনের গেট দেখুন; বিমান মোডে আবার খুলে মেট্রো রুট আসে কিনা।

### ৭.৬ AI চ্যাট (#১, স্কোর ৫) — ✅ চালু

**পাস:** উত্তর বিস্তারিত, সঠিক, বাংলাদেশি উদাহরণসহ, মাঝপথে কাটে না।

**পাস:** সব বার্তা ক্রমমতো, ভয়েস নোট বাজে, নেট ফেরার পর বার্তা হারায় না।

### ৭.৮ বিজনেস লেজার ও ইনভয়েস (#৮, স্কোর ৫) — ✅ চালু (`business`); পূর্ণ হিসাবে 🔌 `accounting_v2` (A তালিকায়)

### ৮.১ রিমাইন্ডার ও নোট (#১৩, স্কোর ৫) — ✅ চালু (`reminders`, `notes`)

2. ফোন লক করে রাখুন → ঠিক সময়ে অ্যালার্ম বাজে।
3. সাইডবার → **রিমাইন্ডার** → **পরিবারকে কাজ দিন** → ফোন খ-কে একটি কাজ → ফোন খ-এ আসে।
4. **নোট/কাজ** → একটি নোট লিখে সেভ।
**যন্ত্র:** ফোন ক, ফোন খ। **পাস:** অ্যালার্ম ১ মিনিটের মধ্যে, অ্যাপ বন্ধ থাকলেও।

### ৮.২ অ্যাপ চালু হওয়া (#৫৫, স্কোর ৫) — ✅
**যন্ত্র:** ফোন ক (Realme 9i/Android 13), ফোন খ, পুরনো ফোন (পুরনো Android)।
1. তিন ফোনেই অ্যাপ পুরো বন্ধ করে খুলুন → হোম আসতে কত সেকেন্ড (মনে মনে গুনুন)।
2. বিমান মোডে খুলুন → ক্র্যাশ নয়, পরিষ্কার "নেট নেই"।
3. নতুন অ্যাকাউন্টে সাইনআপ → লগইন।
**পাস:** তিন ফোনে ৩ সেকেন্ডের কম, কোনো ক্র্যাশ নেই।

### ৮.৩ ওয়েবসাইট lifeassisto.com (#৫৭, স্কোর ৫)
1. ফোনের ব্রাউজারে **lifeassisto.com** → বাংলা/ইংরেজি বদলান।
2. প্রতিটি ফিচার পাতা খুলুন → লেখা কাটে না, ছবি আসে।
3. Play Store বোতাম → Play-তে Assisto খোলে।
**যন্ত্র:** ফোন ক, ফোন খ। **পাস:** সব পাতা ৩ সেকেন্ডে, কোনো ভাঙা লিংক নেই।

### ৮.৪ ইমেইল পাঠানো (#৫৮, স্কোর ৫)
1. ৬.৭-এর **ইমেইল যাচাই করুন** মেইল কত সেকেন্ডে এল দেখুন।
2. মেইল Spam-এ নয়, Inbox-এ? বাংলা লেখা ঠিক?
3. Owner Admin → ইমেইল স্বাস্থ্য পাতায় পাঠানোর রেকর্ড।
**যন্ত্র:** ফোন ক (Gmail)। **পাস:** ১ মিনিটের মধ্যে Inbox-এ।

### ৮.৫ নিরাপদ যাত্রা (#৪, স্কোর ৬) — ✅ চালু (`safe_journey`); গন্তব্য অ্যালার্ম অংশে 🔌 `dest_alarm`
**যন্ত্র:** ফোন ক (যাত্রী), ফোন খ (পরিবার, সম্মতি নিয়ে)।
1. ফোন ক: সাইডবার → **নিরাপদ যাত্রা** → **আমার যাত্রা** → গন্তব্য → ফোন খ বাছুন → **শুরু করুন, পরিবারকে জানান**।
2. ফোন খ-এ push → চাপলে লাইভ ম্যাপে ফোন ক চলছে।
3. ফোন ক লক করে ১০ মিনিট হাঁটুন/রিকশায় যান → ফোন খ-এ অবস্থান ঠিক বদলায়।
4. **আপনি কি ঠিক আছেন?** এলে ডিউরেস PIN দিন → ফোন খ-এ গোপন সতর্কতা (ফোন ক-এর স্ক্রিনে স্বাভাবিক দেখায়)।
5. পৌঁছে **বন্ধ করুন** → ফোন খ-এ "পৌঁছেছে"।
**পাস:** লাইভ অবস্থান ৫০ মিটারের মধ্যে, ডিউরেস PIN গোপনে কাজ করে।

### ৮.৬ হোম স্ক্রিন (#৫, স্কোর ৬) — ✅ চালু (`home_v2`)
1. হোম খুলুন → **সাহায্য লাগবে?** কার্ড, নিচের বার (**হোম · সব সেবা · রিমাইন্ডার · আমার ব্যবসা · Assisto ভয়েস**)।
2. প্রতিটি বোতাম একবার চাপুন → ঠিক পাতা, কোনো মরা বোতাম নয়।
3. **সব সেবা** → একই কাজের দুটি টাইল নেই, নাম কাটে না।
4. ফোনের লেখা বড় (২০০%) ও ডার্ক মোড → সব পড়া যায়।
**যন্ত্র:** ফোন ক। **পাস:** সব বোতাম কাজ করে, বড় লেখায়ও কিছু কাটে না।

### ৮.৭ নোটিফিকেশন (#৬, স্কোর ৬) — ✅ চালু
1. ফোন ক থেকে অ্যাপ পুরো বন্ধ (Recent থেকে সরান)।
2. ফোন খ বার্তা পাঠায় → ফোন ক-এ ৫ সেকেন্ডে notification, আওয়াজসহ।
3. notification চাপলে ঠিক চ্যাট খোলে।
4. **নোটিফিকেশন** পাতা → **সব পড়া হয়েছে**।
**যন্ত্র:** ফোন ক, ফোন খ। **পাস:** অ্যাপ বন্ধ থাকলেও push আসে, চাপলে ঠিক জায়গায়।

### ৮.৮ পরিবারের SOS ও ফ্যামিলি কেয়ার (#১০, স্কোর ৬) — ✅ চালু (`emergency`, `family`); পতন-শনাক্তে 🔌 `fall_detect` (আসল ফোনে ভুল-সতর্কতার হার মাপা বাকি)
**যন্ত্র:** ফোন ক, ফোন খ। **আগে ফোন খ-কে বলুন "এটা পরীক্ষা"।**
1. ফোন খ: Do Not Disturb চালু, অ্যাপ বন্ধ, স্ক্রিন বন্ধ।
2. ফোন ক: সাইডবার → **জরুরি** → **SOS শুরু করুন** → কাউন্টডাউন শেষ হতে দিন → **SOS পাঠানো হচ্ছে…**
3. ফোন খ-এ জোরে অ্যালার্ম + ফোন ক-এর অবস্থান। ডায়ালারে ৯৯৯ এলে **কল দেবেন না**।
4. দ্বিতীয়বার SOS শুরু করে কাউন্টডাউনে বাতিল → "SOS বাতিল করা হয়েছে।", ফোন খ-এ কিছু যায় না।
5. **জরুরি তথ্য কার্ড** → রক্তের গ্রুপ, অ্যালার্জি → সেভ; সাইডবার → **পরিবার** → **আজকের ওষুধ** একটি ওষুধ যোগ → সময়ে মনে করায়।
**পাস:** DND ও অ্যাপ বন্ধ থাকলেও ১০ সেকেন্ডে ফোন খ-এ SOS বাজে; বাতিল করলে কিছু যায় না।
