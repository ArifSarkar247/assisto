## ক. ডিপ্লয়ের সময় যা লাগবে (একবার)

1. মাইগ্রেশন `0096_journey100` (নতুন টেবিল JourneyEvent, JourneyRoutine; Journey-তে কয়েকটি কলাম)।
2. ক্রন (প্রতি মিনিটে) — `/etc/cron.d/assisto-app`-এ এই লাইনটি যোগ করুন:
   ```
   * * * * * ubuntu cd /home/ubuntu/assisto/backend && flock -n /tmp/assisto-journey-sweep.lock /home/ubuntu/assisto/.venv/bin/python manage.py journey_sweep --quiet >> /home/ubuntu/assisto/logs/journey_sweep.log 2>&1
   ```
   (পুরোনো `purge_l1_retention` ঘণ্টায় একবার চলতেই থাকবে; journey_sweep নিজেও মেয়াদ-শেষ যাত্রার লোকেশন মুছে দেয়।)
3. ম্যাপ (ঐচ্ছিক): watcher-এর ওয়েব পাতায় ম্যাপ দেখাতে `.env`-এ `MAP_TILE_URL=https://...{z}/{x}/{y}...` (যে টাইল সার্ভিসের অ্যাকাউন্ট আছে, যেমন MapTiler)। গাড়ি-ট্র্যাকিংও একই চাবি ব্যবহার করে। **tile.openstreetmap.org কখনো নয়।** চাবি না থাকলে পাতাটা সৎভাবে বলে "ম্যাপ এখনো চালু হয়নি" আর Google Maps-এ খোলার বোতাম দেয়।
4. Play Console → App content → Foreground service: নিচের **খ** অংশের লেখা LOCATION ঘোষণায় যোগ করুন + নতুন ভিডিও।

## খ. Play Console — LOCATION ঘোষণায় Safe Journey যোগ (কপি করে বসান)

**Feature name / description (copy, আগের লেখার শেষে যোগ করুন):**
> (3) Safe Journey — when the user taps "Start journey", Assisto shares the phone's location with the people the user picked for that one trip, until the user arrives or stops it. It starts only from that tap, shows a persistent "Safe Journey is on" notification for the whole trip, and stops by itself on arrival or stop. No background location permission is requested.

**Why it must run in the foreground (copy):**
> The traveller puts the phone in a pocket during the trip. Watchers must keep receiving the location (and an alert if the traveller is late, stops for long or goes off route) while the screen is off; Android allows that only through a location foreground service started by the user.

**Impact if deferred or interrupted (copy):**
> If location stops while the screen is off, the family sees a stale position exactly when something may be wrong on the way home. This is a personal-safety feature and cannot be deferred.

**ভিডিওতে যা দেখাতে হবে (৩০ সেকেন্ড):**
1. (০–৬ সে) Assisto → নিরাপদ যাত্রা → গন্তব্য লিখুন → একজন watcher বাছুন → **Start journey**।
2. (৬–১০ সে) লোকেশন অনুমতি: **"While using the app"** বাছুন (Always নয় — আমরা চাই-ই না)।
3. (১০–১৮ সে) হোম চাপুন → নোটিফিকেশন নামিয়ে **"Safe Journey is on"** দেখান। স্ক্রিন বন্ধ করে ৫ সেকেন্ড পর খুলুন — নোটিফিকেশন তখনো আছে।
4. (১৮–২৬ সে) অ্যাপে ফিরে **I've arrived safely** চাপুন → নোটিফিকেশন চলে যায়।
5. (২৬–৩০ সে) watcher-এর ফোনে "Arrived safely" নোটিফিকেশন দেখান (দ্বিতীয় ফোন থাকলে)।

## গ৩. অভিভাবকের অনুরোধে যাত্রা (মালিকের আইডিয়া ১, ২৮ Oct) — কীভাবে কাজ করে ও ১০ মিনিটের পরীক্ষা

**কী:** বাবা (ফোন B) নিজের ফোনে গন্তব্য আর সময় (যেমন চট্টগ্রাম, ৩টা–৯টা) দিয়ে মেয়েকে (ফোন A) অনুরোধ পাঠান। A দেখে "বাবা আজ আপনার যাত্রা দেখতে চান — চট্টগ্রাম, ৩টা থেকে ৯টা" → এক ট্যাপে **রাজি**। সময় হলে শেয়ার শুরু, পৌঁছালে বাবা খবর পান, সময় শেষে নিজে থেকে বন্ধ। দেরি হলে আগে A-কে "ঠিক আছেন?", উত্তর না দিলে বাবা শেষ লোকেশন পান, তারপর A-র My Circle-এর কাছের পরিবার। পথ: নিরাপদ যাত্রা → উপরের পরিবার-আইকন।

**সৎ কথা — "নিজে থেকে শুরু":** A-র ফোনে Assisto খোলা থাকলে সময় হলেই নিজে শুরু হয়। খোলা না থাকলে একটা জরুরি নোটিফিকেশন আসে "বাবা এখন আপনার যাত্রা দেখছেন — শুরু করতে ট্যাপ করুন" — **প্রথমবার একটা ট্যাপ লাগতে পারে।** কারণ: অ্যাপ বন্ধ অবস্থায় লোকেশন চালু করতে Android "সবসময় লোকেশন" অনুমতি চায়, যা আমরা ইচ্ছা করে নিই না (Play নীতি + গোপনীয়তা)। কেউ ট্যাপ না করলে সময় শেষে বাবাকে সৎভাবে জানানো হয় "শেয়ার শুরুই হয়নি — ফোন করে খোঁজ নিন"।

**নিরাপত্তার নিয়ম (সার্ভারে, প্রতিটার টেস্ট আছে — `core/tests_guardian_journey.py`):**
* প্রাপ্তবয়স্কের সম্মতি **প্রতিবার** — "সবসময় রাজি" নেই; সময় শুরুর আগে রাজি না হলে অনুরোধ বাতিল।
* সময় শেষে নিজে থেকে বন্ধ (দেরির খোঁজের জন্য সর্বোচ্চ ৪৫ মিনিট বাড়তি — শুধু "ঠিক আছেন?" → বাবা → পরিবার ধাপের জন্য)।
* যাত্রা শেষে পথের সব লোকেশন মুছে যায়; থাকে শুধু সারাংশ (কখন শুরু/পৌঁছানো/শেষ)।
* A-র স্ক্রিনে সবসময় ব্যানার "বাবা আপনার যাত্রা দেখছেন — বন্ধ করুন" (নোটিফিকেশনেও); এক ট্যাপে বন্ধ, PIN লাগে না, বাবাকে জানানো হয়।
* কখনো চুপচাপ নয়: শুরু, বন্ধ, সময়-শেষ, বাবাকে সতর্ক করা — প্রতিটাতে A নোটিফিকেশন পায়। দুই পাশেই ইতিহাস (অডিট) দেখা যায়।
* স্কুল-মোড শুধু **নিজের ১৮-র কম সন্তান** — বাবার My Circle-এ সম্পর্ক "সন্তান" **আর** সন্তানের My Circle-এ "বাবা/মা/অভিভাবক", আর বাবা "১৮-র কম" নিশ্চিত করেন। সন্তান একবার রাজি হয়; তার স্ক্রিনে সবসময় দেখা যায়; যেকোনো দিনের যাত্রা সে বন্ধ করতে পারে (বাবাকে জানানো হয়)।
* সব প্ল্যানে ফ্রি (প্রতি প্ল্যানে টেস্ট), এই পাতাগুলোতে বিজ্ঞাপন নেই; অনুরোধে স্প্যাম-সীমা (একজনকে একসাথে ৩টা, দিনে ১০টা)।

**ডিপ্লয়:** একই মাইগ্রেশন `0120_journey2` (নতুন টেবিল JourneyRequest)। নতুন ক্রন লাগবে না — আগের `journey_sweep` (প্রতি মিনিট) এটাও চালায়।
