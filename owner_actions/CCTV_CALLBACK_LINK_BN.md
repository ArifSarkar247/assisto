# CCTV কলব্যাক লিংক — DoLynk / Imou (publicurl, ১৭ নভেম্বর)

> imou-real লেন এই অংশটি `CCTV_REAL_TEST_BN.md`-এ মার্জ করবে।

## কী ভাঙা ছিল
Owner Admin-এর DoLynk কার্ডে কলব্যাক লিংক দেখাত `http://127.0.0.1:8700/...` — এটি সার্ভারের নিজের ভেতরের ঠিকানা, DoLynk বা Imou কখনো পৌঁছাতে পারে না। তাই Dahua/Imou অ্যালার্ম আসত না। এখন সব লিংক `https://api.lifeassisto.com/...` দিয়ে শুরু হয়, আর স্ক্রিনশটে দেখা পুরোনো টোকেন বদলে (rotate) বন্ধ করা হয়েছে।

## নতুন DoLynk লিংক কোথায় পাবেন (টোকেন গিটে লেখা হয় না)
1. Owner Admin → Integrations → **Dahua DoLynk** কার্ড।
2. "কলব্যাক লিংক" ঘরে লিংকটি `https://api.lifeassisto.com/api/v1/cctv/dolynk/callback/` দিয়ে শুরু — পুরোটা সিলেক্ট করে কপি করুন।
3. DoLynk কনসোল (open.dolynkcloud.com) → লগইন → আপনার অ্যাপ/প্রোডাক্ট → **Message Subscription** → **Callback configuration** → পুরোনো `127.0.0.1` লিংক থাকলে মুছে দিন → **Add** → লিংক পেস্ট → Push চালু → **Save**।
4. একই পাতায় ক্যামেরার মেসেজ টাইপ (মানুষ/মোশন, অনলাইন/অফলাইন, SD কার্ড) সাবস্ক্রাইব করুন। (Assisto ক্যামেরা যুক্ত হলে নিজেও এটি করে।)

## Imou
Imou-র লিংক Assisto নিজেই Imou-তে বসায় (কিছু পেস্ট করতে হয় না)। লিংকটি Owner Admin → Integrations → **Imou** কার্ডে দেখা যায়।

## লিংক আবার বদলাতে চাইলে
কার্ডে "বুঝেছি, পুরোনো লিংক এখনই বন্ধ হবে" টিক দিয়ে **কলব্যাক লিংক বদলান** চাপুন। পুরোনো লিংক সঙ্গে সঙ্গে বন্ধ হয়। "ভেন্ডরের কনসোলে কপি করে দিন" দেখালে ধাপ ৩ আবার করুন। শুধু কলব্যাক লিংক বদলায় — DoLynk/Imou-র API কী কখনো বদলায় না।

## পরীক্ষা (সার্ভারে, লিড চালাবে)
`python manage.py cctv_callback_selftest` — পাবলিক ইন্টারনেট দিয়ে প্রতিটি ভেন্ডরের লিংকে একটি সাইন করা **টেস্ট** মেসেজ পাঠায়; "PASS" মানে লিংক, nginx, টোকেন আর সাইন ঠিক আছে। টেস্ট মেসেজ কখনো অ্যালার্ট বা নোটিফিকেশন হয় না।

## দুই ফোনে মালিকের পরীক্ষা
1. ফোন ১ (মালিক): Assisto → CCTV → Dahua ক্যামেরা যুক্ত করুন।
2. ক্যামেরার সামনে দিয়ে হাঁটুন।
3. ফোন ১ ও ফোন ২ (পরিবারের সদস্য, সাইটে দর্শক): ৩০ সেকেন্ডের মধ্যে "মানুষ দেখা গেছে" অ্যালার্ট আসা উচিত।
