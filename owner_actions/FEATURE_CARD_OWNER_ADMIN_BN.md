# ফিচার কার্ড — Owner Admin (সব পাতা)

শাখা `agent/owneradmin` · ১৮ Nov · বোর্ড সারি ৫১।

## ১. উদ্দেশ্য
মালিক প্রতিদিন ফোন থেকে এক জায়গায় দেখবেন অ্যাপ কেমন চলছে (বিল্ড, কল, ভুল, সাইনআপ, ক্র্যাশ, CI) আর দরকারি কাজ (দাম, ফিচার, ইউজার, পেমেন্ট, রিপোর্ট) নিরাপদে করবেন।

## ২. যা আছে
- ~১২০টি পাতা: হোম, ইউজার, পেমেন্ট, AI, কল, CCTV, ফিচার সুইচ, রিপোর্ট, সিস্টেম, অডিট ইত্যাদি।
- পাসওয়ার্ড + ২-ধাপ কোড (TOTP), শুধু HTTPS, প্রতিটি ফর্মে CSRF, কড়া CSP, অডিট লগ।

## ৩. এই শাখায় যা নতুন / ঠিক হলো
- **স্বয়ংক্রিয় ক্রল টেস্ট** (`backend/web/tests_owneradmin_crawl.py`): প্রতিটি পাতা বাংলা ও ইংরেজিতে খোলে — ২০০ স্ট্যাটাস, সময়, ৩০০ KB-এর কম, বাংলায় ইংরেজি শব্দ/ইংরেজি অঙ্ক নেই, টেবিল ফোনে আলাদা স্ক্রল, প্রতিটি ফর্মে CSRF, মুছে ফেলা/ব্যান/রিফান্ড জাতীয় কাজে নিশ্চিত-প্রশ্ন, সেভ করা কি আর দেখায় না, কোনো মৃত লিংক নেই।
- **হোমে "আজ" কার্ড:** নতুন বিল্ডে কত % ফোন, ২৪ ঘণ্টার কল-রিং পৌঁছানো (ব্র্যান্ড ধরে), সার্ভারের ৫xx ভুল, নতুন সাইনআপ, ক্র্যাশ রিপোর্ট, CI লাইন — শুধু সংখ্যা, কারও নাম/নম্বর নেই।
- বাংলা মোডে সব পাতায় বাংলা অঙ্ক (ফোন নম্বর, মডেল কোড, আইডি ইংরেজিতেই থাকে যাতে মেলানো যায়)।
- ফোনে বাঁ দিকের ৫৮টি লিংক এখন একটি "মেনু" বোতামে ভাঁজ করা — আগে পাতার আগে লম্বা লিংকের দেয়াল ছিল।
- মুছুন / ব্যান / সাসপেন্ড / রিফান্ড / কি বদল / ২FA রিসেট — সব বোতাম আগে জিজ্ঞেস করে।

## ৪. যা বাকি ও কেন
- আসল ফোনে মালিকের নিজের হাতে যাচাই এখনো লিখিত নেই (CI-তে হেডলেস ব্রাউজারে ৩৬০ px যাচাই হয়েছে)।
- CI লাইনের সংখ্যা GitHub-এর খোলা API থেকে আসে; রিপো প্রাইভেট হলে "এখনো মাপা হয়নি" দেখাবে।

## ৫. সেরা বিকল্প
Stripe Dashboard (ফোনে এক নজরে আজকের সংখ্যা, প্রতিটি ঝুঁকির কাজে নিশ্চিত-প্রশ্ন)।

## ৬. মালিকের ফোন-টেস্ট (৩ মিনিট)
১. ফোনে Owner Admin খুলুন → ওপরে "আজ" কার্ডে ছয়টি সংখ্যা দেখুন, সব অঙ্ক বাংলায়।
২. "মেনু" চাপুন → লিংক খুলবে; যেকোনো পাতায় যান — পাতা পাশে সরে না।
৩. ইউজার পাতায় একজন টেস্ট ইউজার → "সাসপেন্ড" চাপুন → আগে প্রশ্ন আসবে; "বাতিল" চাপলে কিছু হবে না।
