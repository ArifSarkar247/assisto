# গাড়ি ট্র্যাকিং — আসল ডিভাইসে ১০ মিনিটের পরীক্ষা (মালিকের জন্য)

এই পরীক্ষা আপনি তখন করবেন যখন হাতে একটি আসল GPS ট্র্যাকার (বা শুধু আপনার ফোন) থাকবে।
সার্ভারের দিকের সব অংশ সিমুলেটর দিয়ে আগেই শেষ থেকে শেষ পর্যন্ত পরীক্ষা করা হয়েছে
(`tools/e2e/vehicle_e2e.sh` — GT06, H02/Sinotrack ও Teltonika তিনটিই পাস)। এখানে শুধু
আসল যন্ত্র, আসল সিম আর আসল রাস্তা যাচাই হবে।

---

## ক. আপনাকে যা জোগাড় করতে হবে

| জিনিস | কোনটা কিনবেন | আনুমানিক দাম (estimate) |
|---|---|---|
| GPS ট্র্যাকার (বিকল্প ১ — সবচেয়ে সহজলভ্য) | **Sinotrack ST-901** (মোটরসাইকেল/গাড়ি, H02 প্রোটোকল) — Daraz / বিক্রয় / স্টেডিয়াম মার্কেটে পাওয়া যায় | ২,০০০–৩,০০০ টাকা (estimate) |
| GPS ট্র্যাকার (বিকল্প ২ — GT06 প্রোটোকল) | **Concox GT06N** (বা GT06 প্রোটোকলের যেকোনো "GT06N" ক্লোন; বাক্সে "GT06 protocol" লেখা থাকে) | ৩,৫০০–৫,০০০ টাকা (estimate) |
| GPS ট্র্যাকার (বিকল্প ৩ — দামি, OBD সহ) | Teltonika FMB920 / FMB003 | ৭,০০০–১২,০০০ টাকা (estimate) |
| ট্র্যাকারের সিম | যেকোনো অপারেটরের সাধারণ সিম + ছোট ডাটা প্যাক (মাসে ৩০০–৫০০ MB যথেষ্ট) | মাসে ৫০–১০০ টাকা (estimate) |
| ইঞ্জিন বন্ধের রিলে (ঐচ্ছিক) | ট্র্যাকারের সাথে আসা রিলে, মেকানিক দিয়ে লাগানো | মিস্ত্রি খরচ ৫০০–১,০০০ টাকা (estimate) |
| ম্যাপের চাবি (key) | **MapTiler** অ্যাকাউন্ট (maptiler.com) → API key | শুরুতে ফ্রি টিয়ার; লঞ্চে ব্যবহার বাড়লে Flex প্ল্যান প্রায় $২৫/মাস (estimate — দাম ওয়েবসাইটে মিলিয়ে নিন) |

**ম্যাপ নিয়ে সিদ্ধান্ত (আপনার জন্য):** অ্যাপে এখন আসল রাস্তার ম্যাপ আছে, কিন্তু টাইল (ম্যাপের ছবি)
আসে সার্ভারে লেখা একটি ঠিকানা থেকে। চাবি না দিলে অ্যাপ আগের মতো রাস্তা-ছাড়া রুট-ছবি দেখায় —
কিছু ভাঙে না। OpenStreetMap-এর ফ্রি সার্ভার (tile.openstreetmap.org) অ্যাপে ব্যবহার করা নিষেধ,
তাই সেটি কোডে বন্ধ করা আছে। আমার সুপারিশ: লঞ্চে MapTiler (চাবি সার্ভারে, অ্যাপে নয়); পরে খরচ
বাড়লে বাংলাদেশের নিজস্ব টাইল সার্ভার (এককালীন কাজ, মাসিক খরচ প্রায় শূন্য)। অ্যাপ টাইল ফোনে
ক্যাশ করে রাখে, তাই খরচ কম হয়।

চাবি পেলে ইন্টিগ্রেটরকে দিন; তিনি `backend/.env`-এ লিখবেন:
```
MAP_TILE_URL=https://api.maptiler.com/maps/streets-v2/256/{z}/{x}/{y}.png?key=<আপনার_চাবি>
MAP_TILE_ATTRIBUTION=© MapTiler © OpenStreetMap contributors
```
তারপর `assisto.service` রিস্টার্ট। আর H02 (Sinotrack) চালু করতে একবার
`sudo systemctl restart assisto-tracker` (নতুন পোর্ট/ফায়ারওয়াল লাগবে না — একই 5023)।

## খ. ট্র্যাকার সেট করার SMS (ট্র্যাকারের সিম নম্বরে আপনার ফোন থেকে পাঠান)

APN: গ্রামীণফোন `gpinternet`, রবি/এয়ারটেল `internet`, বাংলালিংক `blweb`, টেলিটক `wap`।

**Sinotrack ST-901 (H02)** — ডিফল্ট পাসওয়ার্ড `0000`:
1. `8030000 gpinternet`   (APN)
2. `8040000 16.4.105.173 5023`   (সার্ভার IP ও পোর্ট — ST-901-এ ডোমেইনের বদলে IP দিন)
3. `7100000`   (GPRS চালু)
4. অ্যাপে পেয়ার করার সময় লেবেলে লেখা **১০ অঙ্কের ID** দিন (১৫ অঙ্কের IMEI নয়), প্রোটোকল "H02 / Sinotrack"।

**Concox GT06N (GT06)**:
1. `APN,gpinternet#`
2. `SERVER,1,track.lifeassisto.com,5023,0#`
3. `GPRSON,1#`
4. অ্যাপে পেয়ার করার সময় বাক্সে/স্টিকারে লেখা **১৫ অঙ্কের IMEI** দিন, প্রোটোকল "GT06"।
   (কিছু ক্লোন মডেলে কমান্ডের আগে পাসওয়ার্ড লাগে, যেমন `SERVER,666666,1,track.lifeassisto.com,5023,0#` —
   বাক্সের ম্যানুয়াল দেখুন। উত্তর না এলে `PARAM#` পাঠিয়ে বর্তমান সেটিং দেখুন।)

**Teltonika FMB**: `  setparam 2004:track.lifeassisto.com;2005:5023;2006:0` (শুরুতে দুটি স্পেস)।

প্রতিটি SMS-এর পর ট্র্যাকার সাধারণত "OK" / "SET OK" উত্তর পাঠায়।

(পরিবারের কাছে পুশ যায় শুধু হার্ডওয়্যার ট্র্যাকার থেকে)। ট্র্যাকার→সার্ভার সংযোগ সাধারণ TCP
(এই ধরনের ট্র্যাকার এনক্রিপশন পারে না); অ্যাপ↔সার্ভার HTTPS।

## ঘ. কিছু কাজ না করলে
স্ক্রিনশট + সময় লিখে রাখুন। ইন্টিগ্রেটর দেখবেন:
`journalctl -u assisto-tracker -n 100 --no-pager` (অচেনা IMEI হলে "unknown_imei" লগ হয়),
এবং অ্যাপে ট্র্যাকারের "অডিট" তালিকা।
