# গাড়ি ট্র্যাকিং — ১০০ পর্যন্ত কী বাকি (২ নভেম্বর, veh100b)

বোর্ডে শুধু মোট স্কোর আছে। নিচে ১২ শর্তে কোথায় কত নম্বর কাটা গেছে, সেটা প্রমাণ দেখে আমার হিসাব (যোগফল বোর্ডের সাথে মেলে)।
শর্ত: E2E ২০ · বোতাম ১০ · নকল-নেই ১০ · খালি/ত্রুটি ৫ · অফলাইন ৫ · ভাষা ৫ · ২GB ৫ · সীমা ১০ · গোপনীয়তা/Play ১০ · টেস্ট ১০ · ১০-মিনিট ৫ · আসল প্রয়োজন ৫।
**নিয়ম:** আসল ট্র্যাকার + আসল ফোনে আপনার পরীক্ষা ছাড়া কোনো সারি ১০০ নয়; E2E-তে সর্বোচ্চ ১৪–১৫।

## ২. কী কিনবেন (বাংলাদেশ, আনুমানিক দাম — দোকানে মিলিয়ে নিন)
2G/3G বন্ধের সরকারি পরিকল্পনা চলছে (চূড়ান্ত তারিখ আমি যাচাই করিনি) — তাই **শুধু 4G (LTE Cat-1) মডেল** কিনুন। Sinotrack ST-901 / ST-906 (শেষে "L" নেই) আর Concox GT06N = **2G**, কিনবেন না।
1. **প্রথম পছন্দ: Concox/Jimi JM-VL01 (4G)** — ৳৪,৫০০–৬,০০০; রিলে সাথে বা আলাদা ~৳৩০০। প্রোটোকল GT06 পরিবার (4G প্যাকেট 0xA0) — আজ কোডে যোগ হচ্ছে।
2. **দ্বিতীয়: Sinotrack ST-901L (4G)** — ৳৩,০০০–৪,০০০, রিলে সাথে আসে। প্রোটোকল H02 — কোডে আছে।
3. **SIM:** গ্রামীণফোন বা রবি-র নতুন ডাটা সিম (৳৩০০–৪০০); মাসে ~২৫ MB লাগে, তাই সবচেয়ে ছোট ৩০ দিনের ১ GB প্যাক (~৳১০০–১৫০/মাস)। SMS চালু রাখুন। ব্যালান্স শেষ = ট্র্যাকার চুপ (অ্যাপ "সাড়া দিচ্ছে না" জানায়)।
4. **রিলে (ইঞ্জিন বন্ধ):** মিস্ত্রি দিয়ে ফুয়েল-পাম্প বা স্টার্টার লাইনে **normally-closed** ভাবে লাগাবেন — ট্র্যাকার নষ্ট হলেও গাড়ি চলবে। লাল তার ১২V (সরাসরি ব্যাটারি), কালো গ্রাউন্ড, **ACC তার ইগনিশনে** (না হলে ইগনিশন দেখাবে না)। মিস্ত্রি খরচ ~৳৫০০–১,০০০।

## ৩. ১৫ মিনিটের আসল-ডিভাইস পরীক্ষা (একজন গাড়িতে, একজন বাসায় দ্বিতীয় ফোন)
1. ট্র্যাকারে সিম ঢুকিয়ে চালু করুন; সবুজ বাতি জ্বলা পর্যন্ত (১–৩ মিনিট) খোলা আকাশে রাখুন।
2. অ্যাপ → গাড়ি → "ট্র্যাকার যুক্ত করুন" → ব্র্যান্ড + অপারেটর বাছুন → ID (বাক্সের IMEI) লিখুন। টাইমার চালু হবে।
3. ট্র্যাকারের সিম নম্বরে SMS (অ্যাপ নিজেই লিখে দেয়):
   - **JM-VL01:** `APN,gpinternet#` → `SERVER,1,track.lifeassisto.com,5023,0#` → `TIMER,10,300#` (রবি হলে `internet`)
   - **ST-901L:** `8030000 gpinternet` → `8040000 16.4.105.173 5023` → `7100000`
   - **পাস:** প্রতিটির উত্তরে "OK"/"SET OK" SMS আসে।
4. **পাস:** ৩ মিনিটের মধ্যে অ্যাপে "ট্র্যাকার যুক্ত হয়েছে" push + ম্যাপে বিন্দু; সময় ঠিক (বাংলাদেশ সময়, ৬ ঘণ্টা ভুল নয়)।
5. চাবি ঘোরান → **পাস:** ১ মিনিটে "ইঞ্জিন চালু" push দুই ফোনে।
6. ৫ মিনিট চালান (৩০+ কিমি/ঘণ্টা) → **পাস:** ম্যাপে বিন্দু চলে, গতি স্পিডোমিটারের ±৫ কিমি।
7. বাড়ির চারপাশে ২০০ মি জিওফেন্স আগে বানিয়ে রাখুন; বেরিয়ে যান → **পাস:** "এলাকা ছেড়েছে" push, একবারই।
8. গতিসীমা ২০ কিমি দিন, ৩০-এ চালান → **পাস:** একটাই "অতিরিক্ত গতি" push।
9. গাড়ি থামিয়ে ইঞ্জিন বন্ধ → **পাস:** "ইঞ্জিন বন্ধ" push; আজকের যাত্রা-তালিকায় যাত্রা + কিমি।
10. (রিলে থাকলে, গাড়ি থামা) ইঞ্জিন বন্ধ কমান্ড → PIN → নিশ্চিত → **পাস:** স্টার্ট নেয় না, অ্যাপে "নিশ্চিত"; তারপর "আবার চালু" → স্টার্ট নেয়।
11. ট্র্যাকারের ১২V তার খুলুন → **পাস:** "বিদ্যুৎ কাটা" push (JM-VL01; ST-901L-এ শুধু "সাড়া দিচ্ছে না" ৩০ মিনিট পরে)।
12. প্রতিটি ধাপের ✅/❌ আর স্ক্রিনশট আমাদের পাঠান — এটাই ১০০-র প্রমাণ।
