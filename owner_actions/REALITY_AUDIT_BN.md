- ☐ **১. অ্যাপ খোলা + লগইন** — অ্যাপ খুলুন। লগআউট থাকলে নম্বর + পাসওয়ার্ড দিন। **দেখবেন:** ৫ সেকেন্ডের মধ্যে হোম, কোনো "অ্যাপ বন্ধ হয়ে গেছে" নয়।
- ☐ **২. ভাষা বদল** — Settings → ভাষা → English → আবার বাংলা; নিচে About খুলুন। **দেখবেন:** সব লেখা সঙ্গে সঙ্গে বদলায়, About-এ ভার্সন ২০২।
- ☐ **৩. হোম চ্যাট** — হোমে লিখুন "আজ কী কী কাজ আছে?" → Send। **দেখবেন:** আপনার মেসেজ বাবলে থাকে, উত্তর আসে। AI key না দিলে সৎ "AI কী লাগবে" ধরনের উত্তর। মেসেজ হারিয়ে গেলে সেটা বাগ।
- ☐ **৪. ভয়েস** — পাওয়ার বাটন চেপে ধরুন (অথবা হোমের মাইক) → বাংলায় বলুন "কাল সকাল ৯টায় ওষুধ খাওয়ার রিমাইন্ডার দাও"। **দেখবেন:** লেখা ঠিকঠাক আসে, উত্তর শোনা যায়, রিমাইন্ডার তৈরি হয়।

### খ. রোজকার কাজ (৬ মিনিট)
- ☐ **৫. রিমাইন্ডার, অ্যাপ বন্ধ অবস্থায়** — ড্রয়ার → রিমাইন্ডার → "২ মিনিট পরে পানি খাও" যোগ করুন → অ্যাপ সোয়াইপ করে বন্ধ করুন। **দেখবেন:** ২ মিনিটে নোটিফিকেশন/অ্যালার্ম বাজে।
- ☐ **৬. নোট + টু-ডু** — ড্রয়ার → নোট/কাজ → একটি নোট, একটি কাজ যোগ → কাজে টিক দিন। **দেখবেন:** অ্যাপ বন্ধ করে আবার খুললেও আছে, কাজটি "সম্পন্ন"।
- ☐ **৭. খরচ** — ড্রয়ার → হিসাব ও অর্থ → লেনদেন ট্যাব → + → ৭৫ টাকা যাতায়াত। **দেখবেন:** সারাংশে ব্যালান্স ৭৫ কমে।
- ☐ **৮. বাজেট** — ড্রয়ার → বাজেট → যাতায়াত ৩০০০ টাকা। **দেখবেন:** বাজেটে ৭৫ খরচ দেখায়।

### গ. My Circle: দুই ফোন (১০ মিনিট)
- ☐ **৯. মেসেজ + টিক** — My Circle → পরিচিত একজন → "পরীক্ষা ১" পাঠান। **দেখবেন:** ✓ → অন্য ফোনে পৌঁছালে ✓✓ (২ সেকেন্ডের কম) → সে চ্যাট খুললে নীল ✓✓ (১ সেকেন্ডের কম)। সময় মোটামুটি লিখে রাখুন।
- ☐ **১০. টাইপ করছে… / অনলাইন** — অন্যজন চ্যাট খুলে টাইপ করুক। **দেখবেন:** আপনার চ্যাটের উপরে "টাইপ করছে…", থামলে "অনলাইন"।
- ☐ **১১. ভয়েস কল** — আপনি Wi-Fi-তে, অন্যজন মোবাইল ডেটায়। দুজনের অ্যাপ খোলা অবস্থায় ভয়েস কল দিন, ৩০ সেকেন্ড কথা বলুন, কাটুন। **দেখবেন:** অন্য ফোনে বাজে, ৫ সেকেন্ডের মধ্যে জোড়ে, দুই দিকে শোনা যায়, কাটলে দুই ফোনেই শেষ।
- ☐ **১২. ভিডিও কল** — অন্যজন আপনাকে ভিডিও কল দিক, আপনার অ্যাপ খোলা থাকবে। **দেখবেন:** আপনার ফোনে ইনকামিং স্ক্রিন আসে, ছবি দুই দিকে চলে।
- ☐ **১৩. অ্যাপ বন্ধ থাকলে কল** — আপনার অ্যাপ সোয়াইপ করে বন্ধ করুন, ফোন লক করুন → অন্যজন কল দিক। **দেখবেন:** পূর্ণ-স্ক্রিনে কল বাজে (Android 14+ হলে "পুরো স্ক্রিনে কল" অনুমতি চালু রাখুন)।
- ☐ **১৪. ছবি + ভয়েস মেসেজ** — চ্যাটে + → একটি ছবি, তারপর একটি ৫ সেকেন্ডের ভয়েস মেসেজ পাঠান। **দেখবেন:** অন্য ফোনে ছবি খোলে, ভয়েস বাজে।
- ☐ **১৫. নম্বর দিয়ে যোগ / ফোনবুক** — My Circle → + → Add to My Circle → ফোনবুক থেকে বা নম্বর লিখে (০১…, +৮৮০…, স্পেস দিয়ে) খুঁজুন। **দেখবেন:** Assisto-তে থাকা মানুষ "Assisto-তে আছেন" তালিকায় আসেন; যেকোনো ফরম্যাটে খুঁজে পাওয়া যায়।

### ঘ. নিরাপত্তা, ভল্ট, ব্যবসা, ছবি (৮ মিনিট)
- ☐ **১৬. ডকুমেন্ট ভল্ট** — ড্রয়ার → ডকুমেন্টস → PIN সেট → নতুন ডকুমেন্ট → ক্যামেরা/গ্যালারি থেকে NID-এর একটি ছবি (চাইলে নকল কাগজ) সংযুক্ত করুন। **দেখবেন:** সেভ হয়; অ্যাপ বন্ধ করে খুললে PIN চায়, ছবি খোলে।
- ☐ **১৭. পরিবার + SOS** — ড্রয়ার → ফ্যামিলি → সদস্যরা দেখা যায়। তারপর ইমার্জেন্সি → SOS চাপুন → কাউন্টডাউনে **বাতিল** চাপুন। **দেখবেন:** বাতিলে কিছুই পাঠানো হয় না। (আসল SOS শুধু পরিবারকে জানিয়ে আলাদা দিনে পরীক্ষা করবেন।)
- ☐ **১৮. কুইক সেল** — ড্রয়ার → বিজনেস → কুইক সেল → একটি পণ্য → কার্ট → বিক্রি → রসিদ → বাতিল। **দেখবেন:** দাম ৳০ নয়, কার্টে যোগ হয়, বাতিলে স্টক ফেরত আসে। (বিল্ড ১৯৮-এর আগে এটা ভাঙা ছিল, এখনো এমুলেটরে প্রমাণ হয়নি, তাই এটা গুরুত্বপূর্ণ।)
- ☐ **১৯. ফটো স্টুডিও এনহ্যান্স** — ড্রয়ার → ফটো স্টুডিও → একটি ঝাপসা ছবি → এক-ট্যাপ এনহ্যান্স। **দেখবেন:** ফল আসে, মুখ বদলায় না। কত সেকেন্ড লাগল লিখে রাখুন (এখনো কখনো মাপা হয়নি)।

### ঙ. শেষ (২ মিনিট)
- ☐ **২০. লগআউট → আবার লগইন + সমস্যা জানান** — Settings → লগআউট। **দেখবেন:** সঙ্গে সঙ্গে লগইন স্ক্রিন। আবার লগইন করুন: আগের চ্যাট/নোট ফিরে আসে। তারপর Settings → "সমস্যা জানান" → "চেকলিস্ট শেষ" লিখে পাঠান। **দেখবেন:** Owner Admin → Reports-এ সেটি এসেছে।
