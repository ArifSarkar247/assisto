# ব্যানার বিজ্ঞাপন — সব সাধারণ পাতায় (মালিকের সিদ্ধান্ত, ২৬ Oct)

**কে দেখে:** শুধু **ফ্রি** প্ল্যান (লগইন করা)। প্রিমিয়াম, বিজনেস, বার্ষিক, ফাউন্ডার, প্রবাসী, ট্রায়াল — কোনো ব্যানার নয়। অ্যাপ নিজে আটকায়, সার্ভারও আটকায়।

## ১. কোন কোন পাতায় ব্যানার (প্রতি পাতায় ঠিক একটা, নিচে)
প্রতিটা পাতার একটা নির্দিষ্ট নাম (কী) আছে — Owner Admin → Ads → "ব্যানারের পেজ"-এ এই নামগুলোই লেখা হয়।

**নতুন পাতা নিজে থেকে কখনো ব্যানার পায় না** — কেউ ইচ্ছে করে তালিকায় না যোগ করলে।

## ২. কখনো কোনো বিজ্ঞাপন নয় (AdMob ও Play নীতি — কোডে ও টেস্টে বাধ্যতামূলক)
SOS, নিরাপত্তা, নিরাপদ যাত্রা (লাইভ, সেটিংস, ইতিহাস — যাত্রার সব পাতা), পতন শনাক্ত, ইমার্জেন্সি, চুরি-রোধ ও হারানো ফোন, গাড়ি ট্র্যাকিং, পরিবারের সতর্কতা ও পরিবার/লোকেশন পাতা, কল (আসা কল, কল চলাকালীন, কল-লগ ও Calls ট্যাব), **চ্যাটের ভেতরে** (কিবোর্ড ও পাঠানোর বোতামের পাশে), চ্যাট লক ও ভল্ট, PIN পাতা, পেমেন্ট, প্ল্যান, চেকআউট, টপ-আপ, রেমিট্যান্স, লগইন, OTP, সাইন-আপ, পাসওয়ার্ড, অ্যাকাউন্ট নিরাপত্তা ও অ্যাকাউন্ট মোছা, প্রাইভেসি, অনবোর্ডিং, ভাষা বাছাই, অনুমতি ও রিং-চেক পাতা।

তিন স্তরে আটকানো:
1. শুধু উপরের তালিকার পাতায় ব্যানার (বাকি সব আপনাআপনি বন্ধ)।
2. পাতার নামে sos / safe / journey / theft / lost / alert / alarm / call / chat / messenger / conversation / lock / vault / pin / pay / plans / topup / checkout / login / otp / signup / password / account / delete / privacy / family / location / track / live / onboarding / permission / ring_check থাকলে — তালিকায় লেখা থাকলেও বাতিল।
3. সার্ভার (Owner Admin) শুধু তালিকা **ছোট** করতে পারে, নতুন পাতা যোগ করতে পারে না; ওখানে "sos" বা "circle_chat" লিখলেও বাদ পড়ে যায়।

## ৩. সীমা
- প্রতি পাতায় **একটাই** ব্যানার (একই পাতায় দ্বিতীয়টা কোড নিজেই আটকায়)।
- ব্যানার বদলায় (refresh) **৬০ সেকেন্ডের আগে কখনো নয়** — পাতা বন্ধ করে আবার খুললেও।
- অ্যাপ পেছনে গেলে, অন্য পাতা উপরে থাকলে বা কিবোর্ড খোলা থাকলে ব্যানার লোড/রিফ্রেশ হয় না, কিবোর্ডের সময় দেখায়ও না।
- ব্যানার পাতার লেখা, বোতাম, FAB বা লেখার ঘরের **উপরে কখনো পড়ে না** — পাতার একদম নিচে আলাদা জায়গায় (নিচের ট্যাব-বার থাকলে তার ঠিক উপরে), উপরে অন্তত ৮dp ফাঁক। বিজ্ঞাপন না এলে কোনো খালি জায়গা নেয় না।
- ব্যানারের ধরন: Google-এর adaptive anchored banner (ফোনের চওড়া অনুযায়ী)।

## ৪. "বিজ্ঞাপন সরান" লিংক
প্রতিটা ব্যানারের ঠিক উপরে ডান দিকে ছোট লিংক: **"বিজ্ঞাপন সরান" / "Remove ads"** — চাপলে প্রিমিয়াম প্ল্যানের পাতা খোলে। লিংকটা বিজ্ঞাপনের বাইরে, বিজ্ঞাপন থেকে ৮dp দূরে (ভুল করে বিজ্ঞাপনে চাপ না পড়ে), আঙুলের জন্য ৪৮dp, TalkBack বলে "বিজ্ঞাপন সরান। প্রিমিয়াম প্ল্যান খুলবে"। বাঁ দিকে "বিজ্ঞাপন" লেবেল।

## ৫. AdMob কনসোলে আপনার করণীয় (৩০ সেকেন্ড)
AdMob → Apps → Assisto → Ad units → **Banner** ইউনিট (`…/4940910375`) → Advanced settings → **Automatic refresh: Disabled (বন্ধ)** → Save।
কারণ: অ্যাপ নিজেই ঠিক ৬০ সেকেন্ডে রিফ্রেশ করে। কনসোলেও চালু থাকলে দুবার রিফ্রেশ হয়ে নীতির চেয়ে দ্রুত হতে পারে। ("Google optimized" বা ৩০ সেকেন্ড **রাখবেন না**।)

## ৬. লাইভ সেটিং (ইন্টিগ্রেটর করবে, আপনাকে কিছু করতে হবে না)
এখন লাইভে `banner_screens = saved_items,dictionary,health_tips` (শুধু ৩টা পাতা)। নতুন অ্যাপ বিল্ড Play-তে যাওয়ার পর লাইভে এটা বসানো হবে:
```
saved_items,dictionary,health_tips,money,budget,money_report,money_trends,money_networth,money_tax,reminders,notes_todos,birthdays,meetings,documents,jobs,cv_builder,business,crm,contract,prepaid_meter,all_services,guide,nearby,quick_tools,medicine_db,ramadan,exam,photo_gallery,circle_list,settings
```
কোনো পাতায় বন্ধ করতে চাইলে Owner Admin → Ads → "ব্যানারের পেজ" থেকে নামটা মুছে দিন — অ্যাপ আপডেট লাগবে না।
