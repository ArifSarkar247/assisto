# বাড়ি ও দোকানের পাহারাদার (CCTV এআই ওয়াচম্যান) — ফেজ ১

**ফ্ল্যাগ:** `cctv_watchman` (Owner Admin → Features)। ৯/৯ DoD পাস না হওয়া পর্যন্ত লুকানো; Play-তে আলাদাভাবে লুকানো।

## যা তৈরি হয়েছে
- **POS ছাড়াও:** মেনুতে "বাড়ি ও দোকানের পাহারাদার" — বাড়ি (যেকোনো প্ল্যান) বা দোকান (Business)। ৩ ধাপের সেটআপ: বাড়ি/দোকান → গেটওয়ে (পুরনো ফোন / Shop Box পিসি / নিজের পিসি) → নাম → জোড়া লাগানোর কোড (QR)।
- **ক্যামেরা যোগ ও পরীক্ষা:** Imou (Safety Code), Hikvision, Dahua, Tapo (Camera Account), EZVIZ (verification code), অন্য ONVIF, নিজের RTSP ঠিকানা। পিসি গেটওয়ে Wi-Fi-তে ক্যামেরা খোঁজে (ONVIF) ও পরীক্ষা করে: নেটওয়ার্কে আছে? পাসওয়ার্ড ঠিক? ভিডিও খোলে? রেজোলিউশন/fps? ছবি? ক্যামেরার নিজের ইভেন্ট? — ফলাফলে বাংলা/ইংরেজিতে সমাধান।
- **পাসওয়ার্ড কখনো সার্ভারে থাকে না:** একবার গেটওয়েতে পৌঁছে মুছে যায় (টেস্টে প্রমাণিত)।
- **স্ক্রিনে জোন আঁকা:** পরীক্ষার ছবির উপর নিষিদ্ধ জায়গা, টাকার জায়গা, প্রবেশ-রেখা; পাহারার দিন ও সময়, সংবেদনশীলতা, নীরব সময়। গেটওয়ে এক মিনিটের মধ্যে নেয়।
- **সতর্কতা:** "সন্দেহজনক — একটু দেখে নিন" + একটি ছবি + আত্মবিশ্বাস; একই ক্যামেরা+ধরন ১০ মিনিটে = একটি সতর্কতা (কতবার দেখা গেছে সহ); প্রতি জায়গায় দিনে সর্বোচ্চ ৩০টি (বাকিগুলো গোনা হয় ও দেখানো হয়)। পরিবারের সদস্য (সর্বোচ্চ ৫) একই সতর্কতা পান, শুধু দেখতে পারেন।
- **ঠিক/ভুল থেকে শেখা** (নিচে নিয়ম)।
- **কখনো ভিডিও নয়:** সার্ভার ভিডিও আপলোড গ্রহণই করে না (প্রতিটি CCTV আপলোড পথে স্বয়ংক্রিয় টেস্ট)। লাইভ ভিউ গেটওয়ে থেকে সরাসরি (WebRTC)।
- শুধু Apache/MIT মডেল (YOLOX-nano); মুখ চেনা নেই; শব্দ নেই।

| watchman_daily_alert_cap | ৩০ | প্রতি জায়গায় দিনে সর্বোচ্চ সতর্কতা |

| watchman_snapshot_kb | ১০২৪ | সবচেয়ে বড় ছবি আপলোড (তারপর ছোট করে ৬৪০px) |

## ঠিক/ভুল থেকে থ্রেশহোল্ড কীভাবে বদলায় (সীমাবদ্ধ, সরল)
- **ভুল** চাপলে সেই ক্যামেরা: মানুষ-শনাক্তের আত্মবিশ্বাস +০.০৫, নড়াচড়ার সীমা ×১.১৫, বিরতি +৬০ সেকেন্ড → একটু কড়া ও চুপ।
- **ঠিক** চাপলে প্রতিটি মান ডিফল্টের দিকে অর্ধেক ফেরে — কখনো ডিফল্টের চেয়ে বেশি সংবেদনশীল হয় না।
- সীমা: আত্মবিশ্বাস ০.৩৫–০.৮৫, নড়াচড়া ×০.৫–৩.০, বিরতি ৬০–৯০০ সে.। ডিফল্ট ০.৪৫ / ১.০ / ১৮০।

## কর্মী/অতিথি নোটিশের নমুনা (অ্যাপে "কর্মীদের নোটিশ" থেকে শেয়ার করা যায়)
**বাংলা:** বিজ্ঞপ্তি: এই জায়গাটি সিসিটিভি ক্যামেরা দিয়ে নজরে রাখা হয়। ক্যামেরা শুধু নিরাপত্তার জন্য — কোনো কিছু সন্দেহজনক মনে হলে মালিকের ফোনে একটি ছবি যায়, যা ৩০ দিনের মধ্যে মুছে যায়। কোনো ভিডিও আমাদের সার্ভারে রাখা হয় না, কোনো শব্দ রেকর্ড হয় না, আর মুখ চেনার কোনো ব্যবস্থা নেই। প্রশ্ন থাকলে মালিকের সাথে কথা বলুন।

**English:** Notice: this place is watched by CCTV cameras. They are used only for safety — if something looks unusual, one still photo goes to the owner's phone and is deleted within 30 days. No video is kept on any server, no sound is recorded, and there is no face recognition. Please talk to the owner if you have any questions.

## পুরনো ফোন গেটওয়ে — সিদ্ধান্ত (ফেজ ১)
ফোনে LAN ক্যামেরা (RTSP) পড়ার কোনো অনুমোদিত (Apache/MIT/BSD) প্লাগইন pubspec-এ নেই; নতুন নেটিভ ভিডিও-ডিকোডার যোগ করা পুরনো ফোনে ক্র্যাশ-ঝুঁকি ও অ্যাপের আকার বাড়ায়। তাই ফেজ ১-এ পুরনো ফোন = **ফোনের নিজের ক্যামেরা** (Shop Box মোড) + **Imou ক্লাউড সতর্কতা**। ফোনে LAN-RTSP ফেজ ২ (Android media3 exoplayer-rtsp, Apache-2.0, অলস লোড)।

## ১০ মিনিটের পরীক্ষা (মালিক)
1. (১ মি.) Owner Admin → Features → cctv_watchman → নিজের অ্যাকাউন্টে preview আছে কিনা দেখুন। অ্যাপ → মেনু → **বাড়ি ও দোকানের পাহারাদার** → ৩ ধাপের গাইড দেখা যায়।
2. (২ মি.) **সেটআপ শুরু করুন** → আমার বাড়ি → আমার নিজের কম্পিউটার → নাম "টেস্ট বাসা" → তৈরি → কোড ও QR দেখায়।
3. (২ মি.) Windows পিসিতে AssistoShopBox.exe → Pair → কোড পেস্ট। অ্যাপে "চালু আছে" দেখায় (আগে "এখনো যুক্ত হয়নি")।
4. (২ মি.) **ক্যামেরা যোগ করুন** → Imou → "আমার Wi-Fi-তে ক্যামেরা খুঁজুন" → IP বাছুন → **ভুল** Safety Code দিন → পরীক্ষা → "Safety Code ভুল…" সমাধান দেখায় → ঠিক কোড দিয়ে আবার → "ক্যামেরা চলছে" + রেজোলিউশন।
5. (১ মি.) **এখন জোন আঁকুন** → ছবিতে ৩টি ট্যাপ → জায়গা শেষ করুন → পাহারার সময় বন্ধ রাখুন (সবসময়) → সংরক্ষণ।
6. (১ মি.) ক্যামেরার সামনে হাঁটুন → ফোনে "সন্দেহজনক — একটু দেখে নিন" ও একটি ছবি → আবার হাঁটুন → একই সতর্কতায় "২ বার দেখা গেছে"।
7. (১ মি.) **পরিবারের যারা দেখবেন** → দ্বিতীয় অ্যাকাউন্টের নম্বর → সেই ফোনেও সতর্কতা আসে, শুধু দেখা যায়। প্রথম ফোনে **ভুল** চাপুন → "এই ক্যামেরা এখন একটু কম সতর্কতা দেবে"। পিসি বন্ধ করুন → ৩ মিনিট পর "… থেকে বন্ধ"।
