- সাইন-ইন করা: লিংক ট্যাপ (ব্রাউজার খোলে) → লিংক কপি (২) → Assisto-তে ফেরা (২) → মেনু → সার্কেল → ＋ → যোগ → পেস্ট-লিংক (৫) → পেস্ট (২) → যোগ দিন (১) = **≈১৩ ট্যাপ**
- সাইন-আউট: ওপরের সাথে লগইন (২ টাইপ-ঘর + ৩ ট্যাপ) = **≈১৬ ট্যাপ**

### (গ) নতুন ব্যবহারকারী একা শুরু করলে (নিজে ডাকবেন)

## ২. পরে (এই শাখায় যা বানানো হলো)

### (ক) অ্যাপ নেই — **৫ ট্যাপ + ২ টাইপ-ঘর** (SMS চালু থাকলে + কোড)

| # | কী হয় | ট্যাপ |
|---|---|---|
| ১ | WhatsApp-এ ছোট লিংক `https://lifeassisto.com/i/K7QF2M9PAB` ট্যাপ → বাংলা পাতা: "রহিম আপনাকে তার সার্কেলে ডেকেছেন" | ১ |
| ২ | "Google Play থেকে Assisto নিন" (লিংকে `referrer=ci=<code>`) | ১ |
| ৩–৪ | Install → Open | ২ |
| ৫ | অ্যাপ খুলেই **"রহিম-এর সার্কেলে যোগ দিন"** (Play install referrer থেকে কোড; ভাষা-পাতা নেই, ওপরে বাংলা/English বোতাম)। নাম (কীবোর্ড আগে থেকে খোলা) + মোবাইল নম্বর → **যোগ দিন** | ১ |
| | → সরাসরি রহিমের সাথে চ্যাট খোলে, "সালাম দিন!" | |
| | **মোট** | **৫ ট্যাপ** (লক্ষ্য ≈৬ ✔) |

পাসওয়ার্ড **নেই**। SMS gateway চালু থাকলে একটি কোড-পাতা (৬ সংখ্যা দিলেই নিজে যাচাই); SMS না এলে "ইমেইল দিয়ে চালিয়ে যান"। ছবি ঐচ্ছিক (একটি বোতাম)।

### (খ) অ্যাপ আছে — **২ ট্যাপ**

- সাইন-ইন করা: লিংক ট্যাপ → অ্যাপ খোলে "রহিম-এর সার্কেলে যোগ দিন" → **যোগ দিন** → চ্যাট = **২ ট্যাপ**
- সাইন-আউট: লিংক ট্যাপ → নাম + নম্বর → যোগ দিন = **২ ট্যাপ + ২ টাইপ-ঘর** (পুরনো অ্যাকাউন্ট থাকলে "সাইন ইন করুন" → লগইন → এক ট্যাপে যোগ)
- App Link যাচাই না হলে (নিচে মালিকের ধাপ দেখুন) লিংক ব্রাউজারে খোলে → "Assisto-তে খুলুন" বোতাম = **৩ ট্যাপ**

### (গ) একা শুরু — সাইন-আপ অংশ বদলায়নি (পাসওয়ার্ডসহ রেজিস্টার এখনো আছে — এই কাজের পরিধির বাইরে, সৎভাবে লেখা হলো); ডাকার অংশ ছোট হলো

সার্কেল → ＋ → যোগ → **"লিংক দিয়ে ডাকুন"** → WhatsApp → কন্টাক্ট → পাঠান = **৭ ট্যাপ** (আগে ≈৯), বার্তা ছোট বাংলা, লিংক ছোট। পরে "ডাকা হয়েছে, এখনো যোগ দেননি" তালিকায় কে যোগ দিলেন/দেননি, "আবার পাঠান" ও "লিংক বাতিল"।

| পথ | আগে | পরে |

| (ক) অ্যাপ নেই | ≈২৬ ট্যাপ + ৩ ঘর + পাসওয়ার্ড + কপি-পেস্ট | **৫ ট্যাপ + ২ ঘর**, পাসওয়ার্ড নেই |
| (খ) অ্যাপ আছে, সাইন-ইন | ≈১৩ | **২** |

## ৩. কী কী বানানো হলো

**সার্ভার** (`backend/core/invite_join.py`, `views_invite_join.py`, মাইগ্রেশন `0102_circle_invite_code`)
- ছোট এলোমেলো কোড (১০ অক্ষর, O/0/I/1 নেই, ৩২^১০ সম্ভাবনা) — লিংকে কোনো ইউজার আইডি নেই।
- মেয়াদ ৭ দিন; "আবার পাঠান" মেয়াদ বাড়ায়; "বাতিল" করা যায়; এক-বার (ডিফল্ট) বা পরিবারের গ্রুপ লিংক (১০ জন পর্যন্ত, সর্বোচ্চ ২০); "আমার QR" = ১০ জনের লিংক।
- অপব্যবহার রোধ: দিনে ৪০টি লিংক/জন; প্রিভিউ মিনিটে ৩০/IP; যোগ ঘণ্টায় ২০/জন; নতুন অ্যাকাউন্ট ঘণ্টায় ৬/IP; ভুল কোড ১০ মিনিটে ২০টি হলে সেই IP বন্ধ (আসল কোডও)। অজানা/বাতিল/ভুল-গঠন কোড — তিনটিরই হুবহু এক উত্তর (কেউ গুনে বের করতে পারবে না)।
- নাম-প্রকাশ: শুধু প্রেরকের **প্রথম নাম**; ফোন/ইমেইল/আইডি কখনো না।
- যোগ API: দুই দিকেই ACCEPTED সংযোগ, E2E চাবি, "এখন সংযুক্ত" লাইন + push (connect-flow)। আগে থেকে সংযুক্ত হলে ব্যবহার কাটে না। শেষ ব্যবহার নিয়ে দুজনের দৌড়ে একজনই জেতে (atomic)।
- পাসওয়ার্ড-ছাড়া সাইন-আপ: SMS চালু → ফোন OTP প্রমাণ বাধ্যতামূলক (পুরনো o1-otp, purpose signup); SMS বন্ধ বা "SMS আসেনি" → আজকের পাসওয়ার্ড-সাইন-আপের সমান বিশ্বাস-স্তর (লঞ্চ-গেট `auth_password_only_signup`) + বৈধ আমন্ত্রণ। গেট বন্ধ থাকলে সৎ "এখন নতুন অ্যাকাউন্ট খোলা যাচ্ছে না"। কোনো ব্যর্থতায় অ্যাকাউন্ট তৈরি হয় না, ব্যবহারও কাটে না (rollback)।
- পরে পাসওয়ার্ড: `POST /auth/set-password` (শুধু যার পাসওয়ার্ড নেই)। SMS চালু হলে ফোন-OTP লগইন তো আছেই।
- কৃতিত্ব: `CircleInviteJoin` সারি; নতুন অ্যাকাউন্ট হলে প্রেরকের রেফারেল কোড `growth.claim()` দিয়ে দাবি — **ক্রেডিটের নিয়ম একটুও বদলানো হয়নি** (ডিভাইস/ফোন/সময়/মাসিক সীমা সব আগের মতো; ক্রেডিট কেবল activation-এর পরে)।
- সার্কেল পূর্ণ: গ্রহণ করা সদস্যের সীমা `limits.circle_max_members` (ডিফল্ট ২৫৬, দুই পাশেই)। প্ল্যানের "family" সংখ্যা কোথাও প্রয়োগ হয় না (Free = ০ প্রয়োগ করলে SOS ভাঙে — বোর্ডে আগেই "মালিকের সিদ্ধান্ত" লেখা), তাই এখানে চাপানো হয়নি।
- পুরনো পথ চালু: পুরনো লম্বা টোকেন-লিংক, "লিংক পেস্ট" (এখন ছোট কোডও নেয়), `/messenger/invite/share-link` ও SMS-আমন্ত্রণ এখন ছোট লিংক দেয়। রেফারেল কোড (৮ অক্ষর) `/i/`-এ আগের পাতাতেই যায়।
- ওয়েব পাতা `/i/<code>`: বাংলা-প্রথম, "Assisto-তে খুলুন" (intent লিংক, অ্যাপ না থাকলে Play) + "Google Play থেকে নিন" (referrer সহ); মেয়াদ শেষ/ব্যবহৃত হলে সৎ পাতা (410); noindex, no-store, no-referrer।

**অ্যাপ**
- `lib/invite/invite_link.dart` — কোড পার্স, অপেক্ষমাণ কোড (৭ দিন মনে রাখে, অ্যাপ বন্ধ হলেও), Play install referrer (প্রতি ইনস্টলে একবার, প্রথম ফ্রেমের পরে (০.৩ সেকেন্ড), ৬ সেকেন্ড সীমা)।

- `invite_router.dart` — একটিই পথ ঠিক করে কী দেখাবে (দুবার পাতা খোলে না): সাইন-আউট + কোড → লগইনের বদলে "যোগ দিন" পাতা; সাইন-ইন + কোড → এক-ট্যাপ কার্ড ওপরে।

- `invite_share_sheet.dart` — WhatsApp (wa.me), SMS (নিজের সিম), "imo, Messenger, আরও" (সিস্টেম শেয়ার — imo-র পাবলিক টেক্সট-লিংক নেই, তাই ভান করা হয়নি), QR, কপি; "কার জন্য" নাম; পরিবারের গ্রুপ লিংক। "ডাকা হয়েছে, এখনো যোগ দেননি" তালিকা: যোগ দিয়েছেন/অপেক্ষা/মেয়াদ শেষ, আবার পাঠান, বাতিল।

## ৫. মালিকের ধাপ (আপনার হাতে)

1. **App Links যাচাই (জরুরি, ৫ মিনিট):** Play Console → Assisto → Setup → **App integrity → App signing** → "App signing key certificate"-এর **SHA-256** কপি করুন। সার্ভারের `.env`-এ `ANDROID_CERT_SHA256`-এ কমা দিয়ে **যোগ** করুন (এখন লাইভে একটি আঙুলছাপ আছে — ওয়েবসাইট APK-র)। না দিলে Play থেকে ইনস্টল করা অ্যাপে লিংক ব্রাউজারে খুলবে ("Assisto-তে খুলুন" বোতামে ১ ট্যাপ বেশি)। তারপর Play Console → **Deep links** পাতায় `lifeassisto.com` "verified" দেখাবে।
2. **SMS gateway** চালু হলে নতুনরা নিজে থেকেই ফোন-OTP পাবে (কিছু বদলাতে হবে না)। ততদিন SMS-ছাড়া সাইন-আপ চলে লঞ্চ-গেট `auth_password_only_signup` (এখন ON) দিয়ে — বন্ধ করলে আমন্ত্রণ-সাইন-আপও বন্ধ হবে, সৎ বার্তাসহ।
3. **দুই ফোনে ১০ মিনিটের পরীক্ষা** (নিচে)।

## ৬. বাংলায় ১০ মিনিটের পরীক্ষা (দুই ফোন)

ফোন ক = আপনার (Assisto আছে, সাইন-ইন)। ফোন খ = Assisto **নেই** (বা আনইনস্টল করুন)।

1. ক: আমার সার্কেল → ＋ → আমার সার্কেলে যোগ → **লিংক দিয়ে ডাকুন** → "কার জন্য": খ-এর নাম → **WhatsApp** → খ-কে পাঠান। ✔ বার্তা বাংলায়, লিংক ছোট (`/i/` + ১০ অক্ষর)।
2. খ: WhatsApp-এ লিংক ট্যাপ → পাতায় আপনার **প্রথম নাম** দেখাচ্ছে? ফোন নম্বর **নেই** তো? → **Google Play থেকে Assisto নিন** → Install → Open।
3. খ: অ্যাপ খুলেই "**<আপনার নাম>-এর সার্কেলে যোগ দিন**"? (ভাষা-পাতা এক মুহূর্ত দেখা গেলেও নিজে থেকেই "যোগ দিন" পাতায় চলে যাওয়ার কথা) → নাম + নম্বর → **যোগ দিন** → সরাসরি আপনার সাথে চ্যাট? পাসওয়ার্ড চায়নি তো? ট্যাপ গুনুন (লক্ষ্য ≤৬)।
4. ক: আমার সার্কেলে খ এসেছে? "ডাকা হয়েছে, এখনো যোগ দেননি" → খ-এর সারিতে "যোগ দিয়েছেন: …"?
5. খ: একটি মেসেজ পাঠান → ক পায়? ক উত্তর দিন।
6. সেই একই লিংক অন্য কেউ (ফোন গ) খুললে → "এই আমন্ত্রণ আগেই ব্যবহার হয়েছে" পাতা?
7. ক: নতুন লিংক বানিয়ে "লিংক বাতিল" → সেই লিংক খুললে "সঠিক নয়" বার্তা?
8. খ: অ্যাপ বন্ধ করে নেট বন্ধ করুন → ক-এর নতুন লিংক ট্যাপ → "ইন্টারনেট নেই… আবার চেষ্টা করুন" → নেট চালু → আবার চেষ্টা → কাজ করে?
9. খ: সেটিংসে ফন্ট সবচেয়ে বড় + ডার্ক মোড → যোগ দিন পাতা কাটা/ভাঙা লাগে?
10. খ (অ্যাপ আছে, সাইন-ইন): ক-এর নতুন লিংক ট্যাপ → সরাসরি অ্যাপে "যোগ দিন" কার্ড (২ ট্যাপ)? ব্রাউজারে খুললে → ধাপ ৫.১ (App Links) বাকি আছে।
