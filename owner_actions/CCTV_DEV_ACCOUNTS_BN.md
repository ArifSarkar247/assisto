## IMOU OAUTH NOW (৯ Nov, Imou-র সর্বজনীন ডক মিলিয়ে হালনাগাদ ১৭:৩০)

**অবস্থা (১৭:১৫):** ফর্ম জমা হয়েছে — প্রজেক্টের নাম **"Assisto Camera Link"**, Callback
`https://api.lifeassisto.com/api/v1/cctv/imou/oauth/callback`, Android-এ Play app-signing কী-র SHA1, iOS bundle `com.assisto.assisto`।
Imou বলেছে "work ticket দিয়ে অনুমতি চান" — **টিকিট ৪৮৩ জমা হয়েছে, অনুমোদনের অপেক্ষা।** ততদিন Owner Admin-এর Imou কার্ডে লেখা থাকে
"Imou-র অনুমোদনের অপেক্ষায় (টিকিট ৪৮৩)", অ্যাপে এক-ট্যাপ বোতাম দেখায় না; সিরিয়াল + Safety Code দিয়ে যুক্ত করা এখনই চলে।
Callback লিংকটি চালু আছে (খুললে একটি পরিষ্কার পাতা দেখায়)। অনুমোদন এলে নিচের ধাপ মতো তিনটি মান পেস্ট করুন।

Imou-র ডক (open.imoulife.com → API reference → Account → OAuth; Concepts → OAuth 2.0 authorization) অনুযায়ী
কনসোলের OAuth মেনুতে **মাত্র তিনটি জিনিস** চায়, তারপর রিভিউ:

| কনসোলের ঘর | যা দেবেন |
|---|---|
| Project logo | Assisto লোগো (রিপোর `logo/` ফোল্ডারের PNG) |
| Project name | `Assisto Camera Link` (জমা দেওয়া নাম; ব্যবহারকারী অনুমতির পাতায় এটাই দেখবেন) |
| Authorization success notification URL (Callback URL) | `https://api.lifeassisto.com/api/v1/cctv/imou/oauth/callback` (শেষে `/` ছাড়া, হুবহু) |

- **Scope:** Imou-র ডকে একটিই scope — `all` (আলাদা টিক-বক্স নেই)। ফর্মে টিক-বক্স দেখালে আগের তালিকামতো দিন:
  ডিভাইস তথ্য, লাইভ, রেকর্ডিং, অ্যালার্ম/মেসেজ (passenger flow সহ), ছবি; **না:** মুছা/হস্তান্তর/শেয়ার/পাসওয়ার্ড।
- **Submit → রিভিউ।** অনুমোদনের পর কনসোল তিনটি মান দেখাবে:
  1. **User Authorization H5 Page** (একটি লিংক)
  2. **Project Access Key** (AK)
  3. **Project Secret Key** (SK)
- এগুলো চ্যাটে/এখানে **লিখবেন না**। Owner Admin → Integrations → **"Imou Open Platform"** কার্ডে তিনটি নতুন ঘর:
  "OAuth Project Access Key", "OAuth Project Secret Key", "OAuth User Authorization H5 Page" → পেস্ট → **Save → Test**।
  তিনটিই থাকলে অ্যাপে "Imou অ্যাকাউন্ট দিয়ে এক ট্যাপে যুক্ত করুন" বোতাম নিজে চালু হয়।
- **কীভাবে চলে:** গ্রাহক বোতাম চাপেন → Imou-র নিজের অনুমতির পাতা → Imou Life অ্যাকাউন্টে লগইন করে "Allow" →
  আমাদের সার্ভার কোড বদলে টোকেন নেয় (Secret Key শুধু সার্ভারে) → তাঁর সব Imou ক্যামেরা তালিকায় আসে → বেছে যোগ।
  টোকেন এনক্রিপ্টেড, শুধু সেই জায়গার (site); ২ ঘণ্টা পরপর নিজে নবায়ন; অনুমতি **৯০ দিন** — শেষ হওয়ার আগে অ্যাপ "আবার যুক্ত করুন" বলবে।
- **সৎ নোট:** (১) Imou ডক H5 পাতায় `state` ফেরত দেয় কিনা বলে না — আমরা `state` + নিরাপদ কুকি দুটোই রাখি, তাই যেভাবেই হোক কাজ করবে।
  (২) OAuth-এ PKCE Imou সমর্থন করে বলে ডকে নেই; Secret Key শুধু সার্ভারে থাকে। (৩) OAuth-এ Imou ডক নিশ্চিতভাবে বলে: ডিভাইস তথ্য,
  অনলাইন, মেসেজ, RTSP লাইভ (`getStreamUrl`)। HLS লাইভ ও প্লেব্যাক OAuth টোকেনে চলে কিনা ডকে স্পষ্ট নয় — আমরা আগে চেষ্টা করি,
  না চললে RTSP লাইভ ও রেকর্ডিং-তালিকা দেখাই। (৪) OAuth-এ খরচ "প্রতি অনুমোদিত ব্যবহারকারী" ধরে, ফ্রি কোটার পর প্রিপেইড ব্যালান্স থেকে কাটে।
- **ফ্রি কোটা পাহারা:** মাসে ৩০,০০০ API কল, ৩০,০০০ মেসেজ, ২ GB ট্রাফিক — Owner Admin-এর Imou কার্ডে এই মাসের ব্যবহার দেখায়;
  ৮০%-এ আপনাকে একবার ইমেইল/নোটিশ, তখন ঐচ্ছিক পোলিং কমে; ১০০%-এ ঐচ্ছিক পোলিং বন্ধ (পুশ সতর্কতা ও লাইভ চলবে)।


**কেন দরকার:** গ্রাহকের পুরনো Hikvision / Dahua / EZVIZ / Imou ক্যামেরা ও DVR Assisto-তে **কোনো পিসি ছাড়াই** দেখাতে —
ডিভাইস তালিকা, লাইভ, প্লেব্যাক, ক্যামেরার নিজের AI সতর্কতা (মানুষ/গাড়ি/রেখা পার), হার্ডডিস্কের অবস্থা।
কোড তৈরি ও নকল সার্ভারে পরীক্ষিত। **যে ব্র্যান্ডের চাবি নেই, সেটি অ্যাপে দেখায়ই না** (মৃত বোতাম নেই)।

**নিয়ম:** চাবি (key / secret) কখনো কোডে, গিটে, চ্যাটে বা STATUS-এ নয় — শুধু **Owner Admin → Integrations**-এ।
সেখানে **Save → Test** চাপুন; সবুজ হলে সেই ব্র্যান্ড অ্যাপে নিজে চালু হয়। লাল হলে বন্ধই থাকে।

গ্রাহক একবার অনুমতি দেন: ক্যামেরা / DVR-এর **সিরিয়াল নম্বর + লেবেলের কোড** লিখে (কোডটি একবার ব্যবহার হয়, কোথাও রাখা হয় না)।
প্রতি জায়গার (site) অনুমতি এনক্রিপ্ট করে রাখা, অন্য জায়গায় খোলে না; "সংযোগ সরান" চাপলে ভেন্ডর থেকেও ডিভাইস ছাড়িয়ে দেয়।

## DAHUA DOLYNK NOW (৯ Nov ২০:৩০ — আপনার পাঠানো আসল Doc Center দেখে হালনাগাদ)

আগের ✋ অনুমানগুলো বাদ। নিচের সব কথা DoLynk Doc Center-এর পাতা থেকে (পাতার নাম বন্ধনীতে)। যা ডকে নেই, সেখানে শুধু ✋।

### ১) পথ ১ — Open IoT (নতুন বা মিস্ত্রির লাগানো ক্যামেরা) — যা আছে, তা-ই যথেষ্ট
- প্রোডাক্ট: **Assisto CCTV**, Product ID **212808822**, চাবি **Access Key** + **Secret Access Key** (Quick Start → Calling API)।
- API ঠিকানা: সিঙ্গাপুর **https://open-api-sg.dolynkcloud.com** (আরও আছে ফ্রাঙ্কফুর্ট `-fk`, ওরেগন `-or`)। বাংলাদেশের জন্য সিঙ্গাপুরই ঠিক।
- প্রোডাক্টে যে Service Package লাগবে: **Universal** (সাইন-ইন, ডিভাইস যোগ/তালিকা, মেসেজ), **Video** (লাইভ HLS, প্লেব্যাক, ভিডিও ক্লিপ, ছবি)।
  **Cloud Storage** ঐচ্ছিক — প্যাকেজ কিনতে হয়, **এখন কিনবেন না**। **Access Control নেবেন না** (মুখ চেনা — আমাদের নিয়মে নিষেধ)।
- সাইন-ইন: টোকেন ৭ দিন চলে; সার্ভারের ঘড়ি ৫ মিনিটের বেশি ভুল হলে চলবে না (Obtaining AppAccessToken)।
- ডিভাইস যোগ: **সিরিয়াল + ডিভাইসের পাসওয়ার্ড** (DVR/ক্যামেরার admin পাসওয়ার্ড)। পাসওয়ার্ড Secret দিয়ে AES-এ তালাবদ্ধ হয়ে **একবার** যায়,
  Assisto কোথাও রাখে না (Adding Devices)। ডিভাইসের ধরন: IPC, SD (PTZ), NVR, XVR (Device Category)। মডেল তালিকায় না থাকলে "IDV0022" — Dahua-কে জানাতে হয়।
- অন্য অ্যাকাউন্টে বাঁধা ডিভাইস হলে "IDV004 / PRM0137" আসে — তখন পথ ২ (ARC)। DMSS-এ থাকা ডিভাইসে ঠিক কোনটা আসে ✋ — প্রথম আসল ফোন-পরীক্ষায় দেখব।
- লাইভ: **HLS** ঠিকানা (মুছে না ফেলা পর্যন্ত থাকে — সংযোগ সরালে Assisto নিজেই মুছে দেয়)। RTSP/websocket শুধু Dahua-র SDK-তে চলে (FAQ Video Play) — নিইনি।
- প্লেব্যাক: SD/HDD রেকর্ডিংয়ের অংশ থেকে HLS (১০ সেকেন্ডের মধ্যে চালু করতে হয়)। **প্রমাণের ভিডিও**: রেকর্ডিং থেকে MP4 ফাইল (Dump Task) → ডাউনলোড লিংক।
- ক্লাউড রেকর্ডিং: তালিকা + ছোট ছবি দেখাই; চালাতে Dahua-র প্লেয়ার SDK লাগে — পরে।
- অ্যালার্ম: **Message Subscription** — প্রতিটি মেসেজে `sign = HMAC-SHA512(id, Secret)`; Assisto মেলায়, না মিললে ফেলে দেয়।
  মানুষ/গাড়ি (SMD), লাইন পার, ঘোরাঘুরি, ক্যামেরা ঢাকা, দৃশ্য বদল, আগুন/ধোঁয়া, শব্দ → CCTV Guard সতর্কতা।
  অনলাইন/অফলাইন ও ডিস্কের সমস্যা → পরের মিনিটে স্বাস্থ্য-পরীক্ষা → **সকালের দৈনিক CCTV কার্ড**। মুখ-সংক্রান্ত সব ঘটনা বাদ।
  ছবি কখনো তালাবদ্ধ (.dav) থাকে — Assisto "Cloud Image Decryption" দিয়ে খোলে; ছবি ~১০ সেকেন্ড পরে তৈরি হয়।

**আপনার কাজ (৩টি):**
1. Owner Admin → Integrations → **Dahua DoLynk** → Save → **Test** → সবুজে **"DoLynk sign-in OK"** দেখালে চালু।
2. কনসোল → **Message Subscription** → চালু করুন → Push Settings-এ কার্ডে দেখানো **Callback URL** দিন (Assisto প্রতিটি ডিভাইসের জন্য API দিয়েও নিজে সাবস্ক্রাইব করে)।
3. নিজের একটি Dahua NVR/ক্যামেরা দিয়ে নিচের দুই-ফোন পরীক্ষা।

### ২) পথ ২ — Open ARC (DMSS ব্যবহারকারী DMSS রেখেই Assisto-কে শেয়ার করবেন) — আপনাকে যা বানাতে হবে
ডকে যা লেখা (Introduction of Open ARC, ARC Quick Start, FAQ Account):
- এটি **আলাদা প্রোডাক্ট**: **open.dolynksecurity.com → openConverter** মেনু → **Create product** → নতুন Access Key / Secret / Product ID / API ঠিকানা (প্রোডাক্টের পাতায় লেখা থাকে)।
  একই কোম্পানির জন্য একটি ডেভেলপার অ্যাকাউন্টই ভালো (FAQ)। এই কনসোলে একই লগইন চলে কিনা ✋ — না চললে সেখানে রেজিস্টার।
- প্যাকেজ: **ARC Account Service Package** + **Video Service Package (ARC)**। (AlarmHub প্যাকেজ লাগবে না।)
- তারপর একটি **ARC অ্যাকাউন্ট** (আমাদের "অ্যালার্ম কোম্পানি"): কোম্পানির নাম, ঠিকানা, কোম্পানির ইমেইল (ছোট হাতের অক্ষর), ইউজারনেম, কাজের এলাকা (দেশ/বিভাগ/শহর), ইমেইলে আসা কোড।
  নিবন্ধনের দেশ ডেটা-সেন্টারের সাথে মিলতে হয় (FAQ #8) — বাংলাদেশ সিঙ্গাপুর ডেটা-সেন্টারের তালিকায় আছে কিনা ✋ (কনসোলের API Debug-এ "getAreaInfo" দিয়ে দেখা যায়)।
- **Dahua-র রিভিউ:** ARC অ্যাকাউন্ট দেশের Dahua দল অনুমোদন করে (অবস্থা: পরীক্ষায় → রিভিউয়ের অপেক্ষায় → পাস/ফেল)। অনুমোদনের আগে লগইনে "Account not audited" আসে।
  রিভিউর জন্য তৈরি রাখুন: AXON Dynamic-এর ট্রেড লাইসেন্স, অফিসের ঠিকানা, কাজের এলাকা (ঢাকা/সারা বাংলাদেশ), ছোট বিবরণ — "Assisto অ্যাপে দোকান/বাড়ির CCTV অ্যালার্ম দেখা ও জানানো; গ্রাহক নিজে DMSS থেকে শেয়ার করেন, যেকোনো সময় বাতিল করতে পারেন"।
- অনুমোদনের পর: Owner Admin → **Dahua DoLynk ARC** কার্ড → ARC প্রোডাক্টের চাবি + Product ID + API ঠিকানা + ARC ইমেইল/পাসওয়ার্ড → **switch-এ on** → Save → Test → **"DoLynk ARC sign-in OK"**।
- গ্রাহকের দিক: DMSS-এ ডিভাইস → Assisto-র অ্যালার্ম কোম্পানিকে শেয়ার (মেনুর নাম ✋) → Assisto-তে সিরিয়াল + **যে DMSS অ্যাকাউন্ট থেকে শেয়ার করেছেন** (ইমেইল/ফোন) → মিললে যুক্ত।
- ARC-তে যা পাই: ডিভাইস তালিকা, অ্যালার্ম (push + প্রাপ্তি-স্বীকার), ছবি, রেকর্ডিং তালিকা। **লাইভ ভিডিও ARC-তে শুধু Dahua SDK দিয়ে** — Assisto এখন ছবি দেখায়, সৎভাবে বলে।
- Assisto-র দিক তৈরি ও পরীক্ষিত (সিমুলেটরে), কিন্তু **switch বন্ধ** — উপরের প্রোডাক্ট + অনুমোদন ছাড়া চালু হবে না। ARC অ্যাকাউন্ট নিবন্ধন Assisto থেকে এখনো করা যায় না (কনসোলের API Debug দিয়ে করুন)।
