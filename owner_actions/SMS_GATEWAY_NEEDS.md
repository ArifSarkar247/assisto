# SMS গেটওয়ে — মালিককে যা দিতে হবে (OTP চালু করার জন্য)

> **নতুন (২৭ অক্টোবর):** প্রতিটি গেটওয়ের আলাদা এন্ট্রি, ঘরের টেবিল, ব্যাকআপ গেটওয়ে, দৈনিক সীমা, খরচ ও Gmail ইমেইল-OTP — সব দেখুন **owner_actions/SMS_EMAIL_SETUP_BN.md**।

OTP (সাইন-আপ, SMS দিয়ে লগইন, পাসওয়ার্ড রিসেট, অ্যাকাউন্ট ডিলিট ও সেকশন-৮ নিশ্চিতকরণ)
কোড সম্পূর্ণ তৈরি। শুধু একটি SMS গেটওয়ের তথ্য পেস্ট করলেই চালু হবে।
তথ্য না দেওয়া পর্যন্ত অ্যাপ সৎভাবে দেখায় "SMS কোড এখনো চালু হয়নি" এবং পাসওয়ার্ড দিয়ে সব কাজ চলে।

## ১. যে তথ্যগুলো লাগবে

| # | তথ্য | উদাহরণ / ব্যাখ্যা |
|---|---|---|
| ১ | **প্রোভাইডারের নাম** | `ssl_wireless`, `bulksmsbd`, `alpha_sms`, `mim_sms`, `infobip` — অথবা অন্য কোম্পানি হলে `custom` |
| ২ | **API URL** | প্রোভাইডারের "send SMS" লিংক। উপরের ৫টির জন্য আগে থেকেই ভরা আছে; Infobip-এর ক্ষেত্রে আপনার নিজস্ব base URL (যেমন `https://xxxxx.api.infobip.com/sms/2/text/advanced`) দিতে হবে। `custom` হলে পুরো URL, GET/POST, আর প্যারামিটারের নাম (নম্বর, মেসেজ, কি, সেন্ডার) দিতে হবে। |
| ৩ | **API Key / Token** | প্রোভাইডারের প্যানেল থেকে। MiM SMS-এ ইউজারনেমও লাগে। এটা গোপন — এনক্রিপ্ট করে রাখা হয়, কখনো দেখানো হয় না। |
| ৪ | **Sender ID / মাস্কিং নাম** | যেমন `Assisto`। **মাস্কিং নাম BTRC-র অনুমোদন লাগে** — প্রোভাইডারের মাধ্যমে আবেদন করতে হয়, সাধারণত ট্রেড লাইসেন্স/প্রতিষ্ঠানের কাগজ লাগে এবং কয়েক দিন থেকে কয়েক সপ্তাহ সময় লাগতে পারে। অপারেটর (GP/Robi/Banglalink/Teletalk) অনুযায়ী আলাদা অনুমোদন হতে পারে। |
| ৫ | **নন-মাস্কিং বিকল্প** | মাস্কিং অনুমোদন আসার আগে নন-মাস্কিং নম্বর (যেমন `8809617xxxxxx`) দিয়ে শুরু করা যায় — SMS একটি নম্বর থেকে আসবে, নাম দেখাবে না। খরচ সাধারণত কম, দ্রুত চালু হয়। পরে শুধু Sender ID বদলালেই হবে। |
| ৬ | **ব্যালান্স চেক** | প্রোভাইডারের balance API লিংক (BulkSMSBD ও Alpha SMS-এর জন্য আগে থেকে ভরা)। "Test" চাপলে এটা দিয়ে সংযোগ যাচাই হয়। ব্যালান্স API না থাকলে **টেস্ট ফোন নম্বর** দিন — Test চাপলে ওই নম্বরে একটি আসল SMS যাবে। দুটোর কোনোটাই না দিলে Test সৎভাবে "যাচাই করা যায়নি" দেখাবে এবং OTP চালু হবে না। |
| ৭ | **SMS-প্রতি আনুমানিক খরচ** | বাংলাদেশে সাধারণত নন-মাস্কিং প্রায় ৳০.২৫–০.৪০ এবং মাস্কিং প্রায় ৳০.৩৫–০.৬০ প্রতি SMS (প্যাকেজ ও পরিমাণ অনুযায়ী বদলায়; Infobip-এর মতো আন্তর্জাতিক প্রোভাইডারে বেশি হতে পারে)। বাংলা SMS ইউনিকোড, তাই ৭০ অক্ষরের পর ২টি SMS ধরা হয় — আমাদের বাংলা OTP মেসেজ প্রায় ১–২ সেগমেন্ট। নির্দিষ্ট দাম প্রোভাইডারের কাছ থেকে নিশ্চিত করুন। |
| ৮ | (ঐচ্ছিক) **Android অ্যাপ হ্যাশ** | ভবিষ্যতে স্বয়ংক্রিয় কোড-পড়ার (SMS Retriever) জন্য ১১ অক্ষরের হ্যাশ। এখন খালি রাখলেই চলবে। |

## ২. কোথায় পেস্ট করবেন

১. অ্যাপে মালিক অ্যাকাউন্টে লগইন → **Admin → Integrations** (ওয়েব `/admin/integrations`)।
২. **"SMS Gateway"** (Messaging বিভাগ) খুলুন।
৩. Provider, API Key / Token, Sender ID দিন; প্রয়োজনে Username, API URL, Balance URL বা Test phone দিন।
৪. **Save** → **Test** চাপুন। স্ট্যাটাস **CONNECTED** হলে OTP সাথে সাথে সব জায়গায় চালু হবে (কোনো নতুন বিল্ড লাগবে না)।
৫. স্ট্যাটাস **NOT WORKING** হলে পাশে কারণ দেখাবে (কি ভুল, ব্যালান্স নেই ইত্যাদি)।

## ৩. পাবলিক লঞ্চের আগে: শুধু-পাসওয়ার্ড সাইন-আপ বন্ধ করুন

এখন (টেস্ট বিল্ডের জন্য) **"শুধু পাসওয়ার্ডে সাইন-আপ (টেস্ট বিল্ড)"** চালু আছে, যাতে বর্তমান ব্যবহারকারী ও টেস্ট চলতে থাকে।
লঞ্চের আগে: **Admin → Cost & feature flags** (`/admin/flags`) → **`auth_password_only_signup`** → **OFF** (কারণ লিখে নিশ্চিত করুন)।
এরপর নতুন সাইন-আপে অবশ্যই SMS কোড দিয়ে ফোন নম্বর যাচাই লাগবে।
**আগে SMS গেটওয়ে CONNECTED করুন, তারপর এই ফ্ল্যাগ OFF করুন** — নইলে কেউ সাইন-আপ করতে পারবে না।
পুরনো ব্যবহারকারীরা পাসওয়ার্ড দিয়ে আগের মতোই লগইন করতে পারবেন।
