# Imou ক্যামেরা — মালিকের ধাপ (CCTV ওয়াচম্যান, ফেজ ১)

Imou ক্যামেরা Assisto-তে **দুইভাবে** চলে। প্রথমটির জন্য কোনো key লাগে না।

| পথ | কী লাগে | কী পাওয়া যায় |
|---|---|---|
| **ক) গেটওয়ে দিয়ে (RTSP)** — সুপারিশ | Shop Box পিসি বা আপনার Windows কম্পিউটার, ক্যামেরা একই Wi-Fi-তে, ক্যামেরার নিচের স্টিকারের **Safety Code** | আমাদের নিজের AI (মানুষ শনাক্ত, জোন, প্রবেশ-রেখা), ছবিসহ সতর্কতা, লাইভ ভিউ (পিসি থেকে সরাসরি) |
| **খ) Imou ক্লাউড সতর্কতা** | Imou Open Platform-এর **appId + appSecret** (নিচে) | ক্যামেরার **নিজের** নড়াচড়া/মানুষের সতর্কতা ও তার ছবি — পুরনো-ফোন গেটওয়েতেও চলে |

## ক) গেটওয়ে দিয়ে (key লাগে না)
1. Imou Life অ্যাপে ক্যামেরা Wi-Fi-তে যুক্ত আছে নিশ্চিত করুন।
2. ক্যামেরার **IP ঠিকানা** দেখুন: Imou Life → ক্যামেরা → ⚙️ → Device info / Network (অথবা রাউটারের "connected devices")। যেমন `192.168.1.20`।
3. **Safety Code**: ক্যামেরার নিচের/পেছনের স্টিকারে লেখা (সাধারণত ৬–৮টি বড় হাতের অক্ষর)। এটাই RTSP পাসওয়ার্ড; ইউজার সবসময় `admin`।
4. Assisto → মেনু → **বাড়ি ও দোকানের পাহারাদার** → ক্যামেরা যোগ করুন → **Imou** → IP + Safety Code → **যোগ করে পরীক্ষা করুন**।
5. গেটওয়ে ক্যামেরা খুলে ফলাফল দেখাবে (নেটওয়ার্কে পাওয়া গেছে / পাসওয়ার্ড / ভিডিও / ছবি)। ব্যর্থ হলে কারণ ও সমাধান সেখানেই লেখা থাকে।

প্রযুক্তিগত (গেটওয়ে নিজে বানায়): `rtsp://admin:<Safety Code>@<IP>:554/cam/realmonitor?channel=1&subtype=1` (হালকা) বা `subtype=0` (পূর্ণ)।
Safety Code একবার গেটওয়েতে পৌঁছে আমাদের সার্ভার থেকে মুছে যায়; গেটওয়ে নিজের নিরাপদ স্টোরে রাখে।

## খ) Imou ক্লাউড সতর্কতা (key লাগবে — একবারই)
1. **open.imoulife.com**-এ যান → আপনার Imou অ্যাকাউন্ট দিয়ে লগইন (না থাকলে Imou Life অ্যাপ দিয়ে অ্যাকাউন্ট খুলুন)।
2. **Developer** হিসেবে নিবন্ধন করুন (ব্যক্তিগত/কোম্পানি — সাধারণত বিনামূল্যে, দৈনিক কলের সীমা আছে)।
3. **App Management / My App → Create App** → নাম: `Assisto` → তৈরি হলে **appId** ও **appSecret** দেখাবে।
4. যদি সার্ভার অঞ্চল (data center) বাছাই করতে বলে, এশিয়ার জন্য সিঙ্গাপুর বাছুন। আলাদা API ঠিকানা দিলে সেটাও কপি করুন (না দিলে খালি রাখুন; ডিফল্ট `https://openapi.easy4ip.com/openapi`)।
5. Owner Admin → **Integrations** → **Imou Open Platform (CCTV watchman)** → appId, appSecret, (ঐচ্ছিক) API ঠিকানা → **Save** → **Test**। সবুজ "CONNECTED" হলে চালু।
6. এরপর অ্যাপে Imou ক্যামেরা যোগ করার সময় "Imou সতর্কতা যুক্ত করুন" দেখাবে: ক্যামেরার স্টিকারের **SN (সিরিয়াল)** + **Safety Code** দিন।
7. আমাদের সার্ভার নিজে Imou-কে সতর্কতা পাঠানোর ঠিকানা (callback) জানিয়ে দেয় — আপনাকে কিছু করতে হবে না।

### সৎ সীমাবদ্ধতা (ফেজ ১)
- কোনো ক্যামেরা **অন্য কারও Imou অ্যাকাউন্টে** যুক্ত থাকলে ক্লাউড সতর্কতা যুক্ত হবে না (Imou-র নিয়ম) — অ্যাপ সেটা স্পষ্ট বলবে; তখন পথ (ক) গেটওয়ে দিয়ে চলবে।
- Imou-র কিছু ত্রুটি-কোড আমরা আসল ক্যামেরায় এখনো যাচাই করিনি — **প্রথম আসল ক্যামেরা দিয়ে পরীক্ষা লাগবে** (মালিকের একটি Imou ক্যামেরা)।
- ভিডিও কখনো আমাদের সার্ভারে আসে না; প্রতি সতর্কতায় শুধু একটি ছোট ছবি (Imou-র নিজের সার্ভার থেকে নেওয়া, ছোট করে রাখা, আপনার বেছে নেওয়া দিন পর মুছে যায়)।

## পরীক্ষার জন্য আপনার কাছে যা চাই
- একটি Imou ক্যামেরা (যেকোনো মডেল, যেমন Ranger 2 / Cue / Bullet) + তার স্টিকারের SN ও Safety Code
- (ক) এর জন্য একটি Windows পিসি একই Wi-Fi-তে; (খ) এর জন্য appId/appSecret
