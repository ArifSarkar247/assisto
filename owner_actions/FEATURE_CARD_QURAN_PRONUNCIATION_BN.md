# ফিচার কার্ড — কুরআনের বাংলা উচ্চারণ (তাজবীদসহ, নিয়মভিত্তিক)

লেন ১৫ (`agent/quranpron`), ৯ Nov ২০২৬। আদেশ: owner_actions/OWNER_QURAN_BILINGUAL_9NOV_2155.md। স্পেক: QURAN_BILINGUAL_SPEC_BN.md (অংশ ৪/৬)।

## ১. কাজ কী
প্রতিটি আয়াতের আরবি (Tanzil উসমানী, হুবহু) থেকে **নির্দিষ্ট নিয়মে** বাংলা অক্ষরে উচ্চারণ — তাজবীদসহ। **কোথাও AI নেই**: একই আয়াত সবসময় একই লেখা দেয়। আলেম/ক্বারি Owner Admin-এ অনুমোদন না দেওয়া পর্যন্ত অ্যাপে লেখা থাকে **"যাচাই চলছে"**।

## ২. যা তৈরি হয়েছে
* ইঞ্জিন: `backend/core/quran_pron.py` (খাঁটি Python)। আরবি ফাইল বদলানো হয়েছে কিনা sha256 মিলিয়ে দেখে — বদলানো থাকলে উচ্চারণ দেখায় না।
* API: `GET /api/v1/quran/pron/<সূরা>[?ayah=N]` → `{items:[{ayah, bn, review, spans, rules, note_bn?}], bismillah_bn?, label:"under_review", legend_bn, source}`। `spans` দিয়ে অ্যাপ তাজবীদের রঙ দেখাতে পারে।
* Dart-এ আলাদা ইঞ্জিন **নেই** — সার্ভার থেকে সূরা ধরে আসে, ফোনে ক্যাশ হয়। কারণ: (১) আলেম যা ঠিক করবেন, তা অ্যাপ আপডেট ছাড়াই সব ফোনে যায়; (২) দুই জায়গায় দুই ইঞ্জিন থাকলে আলাদা ফল দেওয়ার ঝুঁকি থাকে; (৩) কোনো Quran Foundation ডেটাবেস অ্যাপে ঢোকে না।
* Owner Admin → **কুরআন উচ্চারণ** (`/owner/quran-pron`): সূরা বাছুন → প্রতিটি আয়াতে আরবি + বাংলা উচ্চারণ + নিয়মের তালিকা → **অনুমোদন / নোটসহ বাতিল / নিয়ম ঠিক করতে বলুন** (সঠিক উচ্চারণও লেখা যায়)। প্রতিটি কাজ অডিট লগে যায়, ইতিহাস দেখা যায়। কোনো নিয়ম বদলে কোনো আয়াতের লেখা বদলালে আগের অনুমোদন আর গণ্য হয় না — আয়াতটি নিজে থেকেই আবার "যাচাই চলছে"-তে ফেরে।
* মাইগ্রেশন নেই (PaCollectionItem, collection `quran_pron`)।

## ৩. লেখার নিয়ম (convention)
| চিহ্ন | মানে | উদাহরণ |
|---|---|---|
| `া` `ি` `ু` | যবর, যের, পেশ | বি, মা |
| `-` / `--` / `---` | টান ২ / ৪ / ৬ হরকত | রাহী--ম্ (৪), দ্বা---ল্লী (৬) |
| `্` (দৃশ্যমান হসন্ত) | স্বরহীন অক্ষর (সাকিন) | আল্‌হাম্‌দু |
| `ঁ` | গুন্নাহ (নাকে ২ হরকত) | ইঁন্না, মাঁই ইয়াক্বূলু |
| `ং` | ইখফা | মিং শার্‌রি |
| `ম্‌` + `ঁ` | ইক্বলাব | মিঁম্‌ বা‘দি |
| ভারী অক্ষর (খ ছ দ্ব গ ত্ব ক্ব য্ব, ভারী র) | বন্ধ অক্ষরে যবর = বাংলা অ-ধ্বনি | রব্বি, ক্বর্দ্বন্ |
| `‘` / `’` | আইন / হামযা | না‘বুদু, ইউ’মিনূন |
| `।` | এখানে থামুন (ۘ ۗ, আমরা থামি) | |
| `,` | না থেমেও পড়া যায় (ۖ ۚ) | |
| `∴` | মুআনাকা (ۛ) | |
| `—` | সাকতা (ۜ) | মান্‌ — রা--ক্ব্ |

অক্ষর: ث ও ص দুটোই "ছ", ذ ز "য", ظ "য্ব", ض "দ্ব", ط "ত্ব", ق "ক্ব"। বাংলায় আলাদা অক্ষর নেই বলে কয়েকটি এক রকম দেখায় — আরবি পাশে থাকে।

## ৫. এখনো যা বাকি / সৎ সীমা
* **আলেম/ক্বারির যাচাই বাকি** — তাই সব আয়াত "যাচাই চলছে"। মালিকের কাজ: একজন আলেম/ক্বারিকে Owner Admin-এ বসানো।
* ওয়াকফ: আয়াতের শেষে আর ۘ ۗ ۜ চিহ্নে থামা ধরা হয়েছে; ۖ ۚ-তে না থেমে পড়া দেখানো হয়।
* আরিদ লিস-সুকূন সবসময় ৪ হরকত (২/৪/৬ সবই জায়েয), মুত্তাসিল/মুনফাসিল ৪ (হাফস ৪–৫)।
* يَـٰٓأَبَانَا-র মতো "ইয়া" যুক্ত শব্দকে মুত্তাসিল ট্যাগ দেয় (দৈর্ঘ্য একই, ৪)।
* বাংলা লিপিতে আরবির সব ধ্বনি আলাদা করা যায় না — উচ্চারণ শেখার জন্য আরবি ও অডিও সাথে থাকবে।
* সেরা প্রতিদ্বন্দ্বী: Quran.com (শুধু ইংরেজি transliteration, তাজবীদ রং আরবিতে); বাংলা অ্যাপগুলোর উচ্চারণ হাতে লেখা, নিয়মের ব্যাখ্যা বা যাচাই-চিহ্ন নেই। আমাদের সুবিধা: তাজবীদ নিয়মসহ, রঙের তথ্যসহ, প্রতিটি আয়াতে আলেমের অনুমোদনের অবস্থা।
