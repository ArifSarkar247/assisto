## ১. Imou (টোকেন ঠিক আছে)

### ১ক. চাবি কোথায় (একবারই, আগেই করা হয়ে গেছে)
1. কম্পিউটারে **lifeassisto.com/owner** → লগইন।
2. বাঁ মেনু → **Integrations** → কার্ড **"Imou Open Platform (CCTV watchman)"**।
3. **appId** ঘরে AppId, **appSecret** ঘরে AppSecret পেস্ট → **Save** → **Test**।
4. সবুজ = ঠিক আছে। লাল হলে শুধু Imou-র ত্রুটি কোড দেখাবে (যেমন `SN1001` = সই ভুল → AppSecret আবার পেস্ট করুন)।
5. একই কার্ডের নিচে লেখা থাকে **"এই মাসের ফ্রি কোটা: API কল …/৩০,০০০, মেসেজ …/৩০,০০০, ট্রাফিক (MB) …/২,০৪৮"**। ৮০% ছুঁলে আপনার ফোনে একবার সতর্কবার্তা যাবে।

### ১খ. ক্যামেরা প্রথমে Wi-Fi-তে, তারপর Imou Life থেকে সরান (যদি সেখানে যুক্ত থাকে)
একটি Imou ক্যামেরা একসাথে একটাই অ্যাকাউন্টে থাকতে পারে। তাই:
1. ক্যামেরা চালু করুন। এখনো Wi-Fi না দেওয়া থাকলে: **Imou Life** অ্যাপ → **+** → QR স্ক্যান → Wi-Fi দিন → ক্যামেরা অনলাইন দেখাবে।
2. Imou Life অ্যাপে ক্যামেরাটি খুলুন → উপরে ডানে **⚙ (সেটিংস)** → একদম নিচে **"Delete Device" / "ডিভাইস মুছুন"** → নিশ্চিত করুন।
   (মুছলে ক্যামেরার Wi-Fi সাধারণত থেকে যায়; ক্যামেরা অফলাইন হয়ে গেলে ধাপ ১ আবার করে আবার মুছুন।)
3. ক্যামেরার গায়ের/বাক্সের **স্টিকার** দেখুন: **SN (সিরিয়াল নম্বর)** আর **Safety Code** (৬–৮ অক্ষর) — ছবি তুলে রাখুন, কাউকে পাঠাবেন না।

### ১গ. ক্যামেরা যুক্ত করা — দুটি পথ, যেকোনো একটি
**পথ ক (সবচেয়ে সহজ, আমরা এটাই চাই): Owner Admin থেকে**
1. lifeassisto.com/owner → বাঁ মেনু → **"Imou পরীক্ষার ক্যামেরা"**।
2. **সিরিয়াল নম্বর (SN)** ও **Safety Code** লিখুন, নাম দিন (যেমন "ডেস্ক ক্যামেরা")।
3. সম্মতির টিক দিন → **যুক্ত করুন**। সবুজ "যুক্ত হয়েছে" + নিচের ছকে SN, ক্যামেরা ১, অবস্থা active।
   Safety Code একবারই ব্যবহার হয়, কোথাও রাখা হয় না। ক্যামেরাটি আপনার নিজের CCTV জায়গায় "Owner test (Imou)" নামে আসবে।

**পথ খ: Imou Control Board (open.imoulife.com) থেকে**
1. open.imoulife.com → লগইন → উপরে **Console / Control Board**।
2. বাঁ মেনু **Device Management (ডিভাইস ব্যবস্থাপনা)** → **Add Device / Bind Device**।
3. **Device SN** = স্টিকারের SN, **Safety Code / Verification code** = স্টিকারের কোড → **OK**। তালিকায় ক্যামেরা "Online" দেখাবে।
4. তারপরও Assisto-তে আনতে **পথ ক-এর ১–৩ ধাপ** একবার করুন (ক্যামেরা আগেই আমাদের অ্যাকাউন্টে থাকলে Assisto সেটা যাচাই করে নিয়ে নেয়)।

**ফোন থেকে (আপনি মালিক/অ্যাডমিন বলে):** Assisto → মেনু → **"বাড়ি ও দোকানের পাহারাদার"** → আপনার জায়গা → **"DVR-এর ব্র্যান্ড অ্যাপ যুক্ত করুন"** → **Imou** → SN + স্টিকারের কোড → সম্মতি → **যুক্ত করুন**। (গ্রাহকদের জন্য এই পথ এখনো বন্ধ, শুধু মালিক/অ্যাডমিন।)

### ১ঘ. Imou-র জন্য বিশেষ কথা
- লাইভ: শুরুতে কম ডেটার SD স্ট্রিম; HD শুধু আপনি চাপলে। প্রতিটি লাইভ ঠিকানা ~১০ মিনিট চলে।
- প্লেব্যাক: SD কার্ডের রেকর্ডিং (না থাকলে Imou ক্লাউড রেকর্ডিং) থেকে HLS ভিডিও (Imou-র `createDeviceRecordHls`)। **ক্যামেরায় SD কার্ড লাগবে** (বা Imou ক্লাউড প্ল্যান)। এক দিনের ভেতরের সময়ই চলে।
- সতর্কতা: Imou নিজে আমাদের সার্ভারে পুশ করে — মানুষ (humanAlarm) ও নড়াচড়া। ক্যামেরায় Imou Life-এ আগে "Human Detection / মানুষ শনাক্তকরণ" চালু রাখা ভালো (মুছে ফেলার আগে)। প্রতিটি সতর্কতা কত সেকেন্ডে এল, সার্ভার নিজেই লিখে রাখে (latency)।
- **এখন বাধা:** callback লিংক localhost → সতর্কতা পুশ চালু হবে publicurl ঠিক হলে। ততক্ষণ ধাপ ১, ২, ৩, ৬, ৭, ১০ পরীক্ষা করুন।

## ২. EZVIZ (টোকেন ঠিক আছে)

### ২ক. চাবি
lifeassisto.com/owner → **Integrations** → কার্ড **"EZVIZ Open Platform (CCTV cash guard)"** → AppKey + Secret (আগেই দেওয়া, Test সবুজ)। কার্ডে এই মাসের কোটাও দেখায়।

### ২খ. ক্যামেরা Wi-Fi-তে, এনক্রিপশন বন্ধ, তারপর EZVIZ অ্যাপ থেকে সরান
1. ক্যামেরা চালু করুন। Wi-Fi না থাকলে: **EZVIZ** অ্যাপ → **+** → স্টিকারের QR স্ক্যান → Wi-Fi দিন → অনলাইন।
2. EZVIZ অ্যাপে ক্যামেরা → **⚙ সেটিংস** → **"Image Encryption" / "Video Encryption"** → **বন্ধ** করুন (চালু থাকলে লাইভ ও ছবি আমরা দেখাতে পারি না)। চাইলে **"Human/Motion Detection"** চালু করুন।
3. একই সেটিংসের নিচে **"Delete Device" / "ডিভাইস মুছুন"** → নিশ্চিত করুন।
4. স্টিকার থেকে **Serial No. (৯ অক্ষর)** আর **Verification Code (৬টি বড় হাতের অক্ষর)** লিখে রাখুন।

### ২গ. ক্যামেরা Assisto-তে যুক্ত করা (আমাদের EZVIZ Open Platform অ্যাকাউন্টে যায়)
1. ফোনে Assisto → মেনু → **"বাড়ি ও দোকানের পাহারাদার"** → আপনার জায়গা (না থাকলে "সেটআপ শুরু করুন" → "আমার বাড়ি")।
2. **"DVR-এর ব্র্যান্ড অ্যাপ যুক্ত করুন"** → **EZVIZ**।
3. **সিরিয়াল নম্বর (SN)** + **লেবেলের ৬ অক্ষরের Verification Code** → সম্মতির টিক → **যুক্ত করুন**।
4. ✅ "যুক্ত হয়েছে" + ক্যামেরার নাম তালিকায়। ভুল কোড হলে স্পষ্ট বাংলা বার্তা; "অন্য অ্যাকাউন্টে আছে" এলে ২খ-এর ধাপ ৩ আবার করুন।

### ২ঘ. EZVIZ-এর জন্য বিশেষ কথা
- সতর্কতা: EZVIZ এখনো আমাদের পুশ অনুমোদন দেয়নি → সার্ভার **প্রতি মিনিটে** জিজ্ঞেস করে। তাই ধাপ ৪-এ সময় **৬০–৯০ সেকেন্ড** পর্যন্ত হতে পারে — এটা লিখে রাখুন, এটা "ফেল" নয়। পুশ অনুমোদন এলে সেকেন্ডে নামবে।
- ছবি এনক্রিপ্টেড থাকলে (২খ ধাপ ২ না করলে) সতর্কতা আসবে কিন্তু ছবি আসবে না।

## ৩. Dahua DoLynk (সিরিয়াল + ডিভাইসের পাসওয়ার্ড)

### ৩ক. আগে এই একটি ক্লিক (টোকেন ত্রুটি PRM0016-এর সমাধান)
লাইভ চেকে DoLynk টোকেন কল **PRM0016 = "Sign error" (সই ভুল)** দিচ্ছিল। চাবি ঠিক আছে; DoLynk আপনার অ্যাকাউন্টে **"full" সই-পদ্ধতি** চায়
(শুধু-পড়া পরীক্ষায়: simple → PRM0016, full → টোকেন OK)। চাবি বদলাতে হবে না।
1. lifeassisto.com/owner → **Integrations** → কার্ড **"Dahua DoLynk (CCTV — Dahua / DMSS cameras)"**।
2. ঘর **"সিগনেচার (খালি = simple…)"** → লিখুন **full** → **Save** → **Test**।
3. ✅ লেখা আসবে **"DoLynk sign-in OK"**। (পরের বিল্ড থেকে Assisto নিজেই simple ব্যর্থ হলে full চেষ্টা করে সেভ করবে।)

### ৩খ. Callback লিংক DoLynk কনসোলে দিন (publicurl ঠিক হওয়ার পরে)
1. একই কার্ডের নিচে লাইন: **"DoLynk কনসোলের Message Subscription-এ এই Callback URL দিন: https://…"** → পুরো লিংকটি কপি করুন।
   লিংক `https://` দিয়ে শুরু না হলে (এখন `http://localhost`) — এখনো দেবেন না, publicurl কাজ শেষ হওয়ার অপেক্ষা করুন।
2. open.dolynkcloud.com → লগইন → **Open IoT** → প্রোডাক্ট **"Assisto CCTV"** → **Message Subscription** → Callback URL ঘরে পেস্ট →
   মেসেজের ধরন: **alarm / event** (মানুষ, নড়াচড়া) ও **device status** টিক → **Save**।
3. লিংকে একটি গোপন অংশ আছে — এটি শুধু DoLynk কনসোলে দিন, চ্যাটে বা গিটে নয়।

### ৩গ. ক্যামেরা যুক্ত করা
1. ক্যামেরা/NVR Wi-Fi বা তারে ইন্টারনেটে থাকুক (DMSS অ্যাপ দিয়ে নেটওয়ার্ক দেওয়া যায়)।
2. **DMSS** অ্যাপে যুক্ত থাকলে: DMSS → ডিভাইস → **⋮ / সেটিংস → Delete** (একটি ডিভাইস একসাথে একটাই ক্লাউড অ্যাকাউন্টে থাকে)।
3. দরকার: **SN** (স্টিকার বা DMSS-এর Device Details) আর **ডিভাইসের admin পাসওয়ার্ড** (যেটা দিয়ে ক্যামেরা/NVR-এ লগইন করেন)।
4. Assisto → পাহারাদার → আপনার জায়গা → **"DVR-এর ব্র্যান্ড অ্যাপ যুক্ত করুন"** → **Dahua** → SN + ডিভাইসের পাসওয়ার্ড → সম্মতি → **যুক্ত করুন**।
   পাসওয়ার্ড একবারই ব্যবহার হয়, আমাদের সার্ভারে রাখা হয় না।
5. তারপর অংশ ৫-এর ১০ ধাপ। DoLynk-এ প্লেব্যাক ও ভিডিও ক্লিপ (MP4) সার্ভার থেকেই আসে।

## ৪. Hikvision — Guard Box দিয়ে (একই Wi-Fi, RTSP/ONVIF), Hik-Connect চাবি না আসা পর্যন্ত

### ৪ক. ক্যামেরার সেটিংস (একবার, কম্পিউটারের ব্রাউজারে ক্যামেরার IP খুলে, বা Hik-Connect / iVMS-4500 অ্যাপে)
ক্যামেরার IP জানতে: রাউটারের "Connected devices" তালিকা, বা Hikvision-এর **SADP** প্রোগ্রাম। ব্রাউজারে `http://<IP>` → admin দিয়ে লগইন → **Configuration**:
| কোথায় | কী চালু করবেন |
|---|---|
| Network → Basic Settings → **Port** | **RTSP Port = 554** (বদলানো থাকলে নম্বরটি লিখে রাখুন) |
| Network → Advanced Settings → **Integration Protocol** | **Enable ONVIF** টিক → **Add** user: নাম যেমন `assisto`, পাসওয়ার্ড, Level = **Media user** (বা Operator) → Save। (একই পাতায় "Enable Hikvision-CGI" টিক থাকুক।) |
| Video/Audio → Video → **Sub Stream** | Video Encoding = **H.264** (H.265/H.265+ নয়), Resolution **640×360** (বা 640×480), Frame Rate **10–15**, Bitrate **384–512 Kbps** → Save |
| Event → Basic Event → **Motion Detection** | **Enable** টিক, Draw Area দিয়ে পুরো ছবি, Sensitivity ৬০–৮০, Arming Schedule সব দিন → Save |
| Event → Smart Event → **Intrusion Detection / Line Crossing** (AcuSense মডেলে **Target: Human**) | থাকলে Enable + এলাকা আঁকুন → Save |
| System → Security → Authentication | **RTSP Authentication = digest/basic** (ডিফল্ট থাকলেই চলে) |
| Image → (অপশনাল) | Video Encryption / Stream Encryption **বন্ধ** |
সাব-স্ট্রিম লিংক (Guard Box নিজেই বানায়): `rtsp://<user>:<password>@<IP>:554/Streaming/Channels/102`।

### ৪খ. পুরনো ফোনকে Guard Box বানানো (ফোন G = ক্যামেরার একই Wi-Fi-তে, চার্জে)
এই অংশটি এখনো সবার জন্য বন্ধ (সুইচ "গার্ড বক্স" = off); **মালিকের অ্যাকাউন্টে প্রিভিউ হিসেবে দেখা যায়** — তাই ফোন G-তে **আপনার নিজের অ্যাকাউন্ট** দিয়ে লগইন করুন।
1. **ফোন A (আপনার):** পাহারাদার → জায়গা → **"পুরনো ফোনকে ক্যামেরা বানান"** → QR + কোড দেখায়।
2. **ফোন G:** Assisto → পাহারাদার → "এই ফোনকে ক্যামেরা বানান" → A-র QR স্ক্যান বা কোড লিখুন → যুক্ত।
3. **ফোন G:** একই পাতায় **"এই ফোন দিয়ে ওয়াই-ফাই আইপি ক্যামেরা দেখুন"** → ক্যামেরার ব্র্যান্ড **Hikvision** → ক্যামেরার IP, ইউজার (`admin` বা ৪ক-এর ONVIF ইউজার), পাসওয়ার্ড → **পরীক্ষা করুন** → "ক্যামেরা চলছে: …" ✅।
   (পাসওয়ার্ড শুধু ফোন G-তে এনক্রিপ্ট করে থাকে, Assisto-তে যায় না।) ভুল হলে স্ক্রিনের বার্তা অনুযায়ী (যেমন "সাব স্ট্রিমে H.264 বাছুন") ৪ক ঠিক করুন।
4. **"পাহারা শুরু করুন"** → ফোন G চার্জে, এই স্ক্রিন খোলা রাখুন।
5. তারপর অংশ ৫-এর ১০ ধাপ, ফোন A থেকে। এই পথে: লাইভ = ফোন G থেকে ছবির ধারা (শব্দ নেই); মানুষ-চেনা ফোন G-তেই;
   প্লেব্যাক = সতর্কতার ক্লিপ/ছবি (ক্যামেরার SD/NVR রেকর্ডিং দূর থেকে নয়) — ছকে সৎভাবে লিখুন।
6. Hik-Connect চাবি এলে Owner Admin → Integrations-এ পেস্ট করার পর ক্লাউড পথও (সিরিয়াল + Verification Code) একই ১০ ধাপে পরীক্ষা হবে।

## ৫. সব ব্র্যান্ডের জন্য একই ১০ ধাপের ফোন-পরীক্ষা
আগে: আপনার ফোন (A) আর পরিবারের একটি ফোন (B), দুটিতেই Play থেকে Assisto-র সর্বশেষ সংস্করণ। B-কে আগে দর্শক বানান:
A → পাহারাদার → জায়গা → **"পরিবারের যারা দেখবেন"** → **"দর্শক যোগ করুন"** → My Circle থেকে বা নম্বর দিয়ে B।
প্রতিটি ধাপে **পাস / ফেল** আর সময় (সেকেন্ড) অংশ ৬-এর ছকে লিখুন।

1. **ক্যামেরা দেখা যায়:** A → পাহারাদার → জায়গা → ক্যামেরার তালিকায় নতুন ক্যামেরা, "অনলাইন" লেখা।
2. **লাইভ:** ক্যামেরা → **লাইভ** → ছবি আসতে কত সেকেন্ড লাগল লিখুন (লক্ষ্য ≤১০ সে.)। HD চাপুন → পরিষ্কার হয়।
3. **প্লেব্যাক:** (ক) সতর্কতা কার্ড → **"SD কার্ডের ক্লিপ"** টাইল (থাকলে) → সতর্কতার সময়ের ভিডিও; (খ) ক্যামেরা → **আগের ক্লিপ** পাতা → ১০–৩০ মিনিট আগের সময় → ভিডিও চলে।
   সৎ কথা: সার্ভার এখন Imou-র প্লেব্যাক ভিডিও-লিংক দেয়; অ্যাপের "আগের ক্লিপ" পাতা পরের বিল্ডে আসছে — আপনার সংস্করণে না থাকলে ছকে "অ্যাপে নেই" লিখুন (ফেল নয়)। Imou-তে SD কার্ড লাগবে।
4. **সতর্কতা (সময় ধরুন):** ঘড়ি দেখে ক্যামেরার সামনে দিয়ে হাঁটুন → A-তে পুশ আসা পর্যন্ত কত সেকেন্ড লিখুন। মানুষ হলে "মানুষ", না হলে "নড়াচড়া"।
5. **সতর্কতা কার্ডের বোতাম:** পুশ চাপুন → কার্ড খোলে → **"লাইভ দেখুন"** চাপুন → লাইভ খোলে ✅।
   তারপর **"৯৯৯-এ ফোন করুন"** চাপুন → আগে "৯৯৯-এ ফোন করবেন?" প্রশ্ন আসবে → নিশ্চিত করলে ফোনের ডায়ালার ৯৯৯ লেখা অবস্থায় খোলে।
   ⚠️ **পরীক্ষায় সবুজ কল বোতাম চাপবেন না** — ডায়ালার খুললেই পাস; তারপর ডায়ালার বন্ধ করুন।
6. **ছবি (snapshot):** কার্ডে ক্যামেরার একটি ছবি আছে, চাপলে বড় হয়।
7. **প্রমাণ-প্যাক (evidence pack):** কার্ড → **"প্রমাণের প্যাকেট"** → ফাইল তৈরি হয় (ছবি + সময় + ক্যামেরার নাম) → শেয়ার/সেভ করা যায়।
8. **মোবাইল ডেটায়:** A-র Wi-Fi বন্ধ করুন (শুধু মোবাইল ডেটা) → ধাপ ২ আর ৪ আবার → কাজ করে কি না।
9. **দ্বিতীয় (পরিবারের) ফোন:** আবার ক্যামেরার সামনে হাঁটুন → **B-তেও** পুশ + ছবি আসে (সময় লিখুন)। B-তে লাইভ: আপনি "পরিবার লাইভ দেখতে পারবে" চালু না করলে খোলে না (এটা ঠিক আচরণ)।
10. **ডেটা খরচ:** লাইভ ঠিক ৫ মিনিট চালান; আগে-পরে A-র **সেটিংস → নেটওয়ার্ক → ডেটা ব্যবহার → Assisto** দেখুন → পার্থক্য × ১২ = **ঘণ্টায় কত MB**। Owner Admin → Integrations → ব্র্যান্ডের কার্ডে "এই মাসের ফ্রি কোটা" কতটা বাড়ল তাও লিখুন।
