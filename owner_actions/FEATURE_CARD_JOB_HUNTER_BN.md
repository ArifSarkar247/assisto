# ফিচার কার্ড — জব হান্টার (Job Hunter)

শাখা `agent/p2career` · ৩ নভেম্বর · মালিকের PART 2 (২.৩)। নতুন অংশ সুইচ `career_plus`-এর পেছনে (ডিফল্ট বন্ধ)।

## ১. উদ্দেশ্য
বৈধ উৎস থেকে চাকরি খোঁজা, পছন্দের খোঁজ সেভ করে রাখা, আর আবেদনের শেষ তারিখ যেন কখনো না ছোটে — সব এক জায়গায়, প্রতিটা চাকরির পাশে সৎভাবে লেখা "কোথা থেকে এল"।

## ২. আজ কী আছে (ফাইল-প্রমাণ)
* `app/lib/screens/jobs_screen.dart` — Discover/Saved/Tracker ট্যাব; নিজের যোগ করা চাকরি, ফিল্টার, বেতন-তথ্য, পাইপলাইন (`backend/core/logic/job_hunter.py`)।
* `backend/core/views.py` JobTailorView — AI দিয়ে সিভি/কভার লেটার (অটো-অ্যাপ্লাই কখনো নয়)।
* `backend/core/world_service.py` — Careerjet-এর অফিশিয়াল পার্টনার API (মালিক কী দিলে) দিয়ে দৈনিক চাকরি-সতর্কতা।
* `backend/core/logic/world_content.py` JOB_PORTALS — BPSC, টেলিটক alljobs, জাতীয় বাতায়ন, বাংলাদেশ ব্যাংক, Bdjobs, Chakri, LinkedIn, BOESL — শুধু লিংক।
* যা ছিল না: জব হান্টারের ভেতরে আসল চাকরি খোঁজা, সেভ করা খোঁজ, কোম্পানির ক্যারিয়ার ফিড, শেষ-তারিখ রিমাইন্ডার।

## ৩. উৎস — কোনটা বৈধ (৩ Nov যাচাই)
| উৎস | অবস্থা | কারণ |
|---|---|---|
| Careerjet পার্টনার API | ✅ যুক্ত (মালিকের কী লাগবে) | অফিশিয়াল পাবলিশার API, শর্তে অনুমতি আছে |
| কোম্পানির Greenhouse / Lever জব বোর্ড | ✅ ব্যবহারকারী যোগ করেন | দুটোরই পাবলিক Job Board API — ঠিক এই কাজের জন্য বানানো |
| কোম্পানির RSS/Atom ফিড | ✅ ব্যবহারকারী যোগ করেন | ফিড মানেই পড়ার জন্য প্রকাশিত |
| কোম্পানির সাধারণ ক্যারিয়ার পাতা | 🔗 লিংক হিসেবে রাখা হয় — আমরা পাতা পড়ি না | HTML পড়া = স্ক্র্যাপিং |
| Bdjobs | 🔗 শুধু লিংক | পাবলিক API/RSS নেই; শর্তে অনুমতি নেই → পার্টনার চুক্তি লাগবে |
| BPSC, টেলিটক alljobs | 🔗 শুধু লিংক | কোনো অফিশিয়াল ফিড খুঁজে পাওয়া যায়নি |
সব সার্ভার-পড়া SSRF-সুরক্ষিত (`link_preview.safe_fetch`: শুধু https, প্রাইভেট IP বন্ধ, ৫১২KB সীমা)।

## ৪. নতুন যা বানানো হলো
* **চাকরি খুঁজুন** পাতা: শব্দ লিখে খোঁজ → Careerjet + নিজের যোগ করা কোম্পানি-ফিড থেকে ফল; প্রতিটা ফলের পাশে উৎসের নাম; "ট্র্যাকারে রাখুন" এক ট্যাপে।
* **সেভ করা খোঁজ:** খোঁজ সেভ → পরে এক ট্যাপে আবার চালান।
* **কোম্পানি যোগ:** Greenhouse/Lever বোর্ডের নাম বা RSS লিংক → "পরীক্ষা করুন" (কয়টা চাকরি পেল দেখায়) → সেভ।
* **শেষ তারিখ রিমাইন্ডার:** তারিখ দিলে ৩ দিন আগে ও শেষ দিনে সকাল ৯টায় রিমাইন্ডার (আগের রিমাইন্ডার ব্যবস্থায়, তাই পুশ আসে)।
* **সরকারি/বড় পোর্টাল:** সৎ লেবেল "শুধু লিংক — অফিশিয়াল ফিড নেই"।
* প্রতারণা-সতর্কতা: "চাকরির জন্য আগাম টাকা দেবেন না"।

## ৫. প্রতিযোগী
| অ্যাপ | শক্তি | দুর্বলতা |
|---|---|---|
| Bdjobs অ্যাপ | সবচেয়ে বেশি দেশি চাকরি | সরকারি বিজ্ঞপ্তি কম, শেষ-তারিখ রিমাইন্ডার নেই, ট্র্যাকার নেই |
| LinkedIn | বিদেশি কোম্পানি | বাংলা নেই, দেশি ছোট চাকরি কম |
| টেলিটক alljobs | সরকারি আবেদন | খোঁজা কঠিন, কোনো সতর্কতা নেই |
**আমাদের জয়:** এক জায়গায় খোঁজ + সেভ খোঁজ + শেষ-তারিখ রিমাইন্ডার + ট্র্যাকার + AI সিভি টেইলর, বাংলায়।

## ৬. সৎ সীমা / মালিকের কাজ
* Careerjet কী না দিলে খোঁজ শুধু নিজের যোগ করা কোম্পানি-ফিডে চলে — পাতায় সৎ "যুক্ত নয়" লেখা।
* Bdjobs/টেলিটক/BPSC-এর ফিড পেতে লিখিত অনুমতি/চুক্তি লাগবে — **মালিকের কাজ**: চিঠি পাঠানো।
* সেভ খোঁজে নতুন চাকরির পুশ এখনো নেই (খুললে দেখায়)। আসল ফোনে প্রমাণ বাকি।

## ৭. মালিকের ২-ফোন টেস্ট
1. Owner Admin → Integrations → jobs_careerjet কী দিন (থাকলে)।
2. ফোন A: জব হান্টার → "চাকরি খুঁজুন" → "accountant" → ফল ও উৎসের নাম দেখুন → একটাকে ট্র্যাকারে রাখুন।
3. "কোম্পানি যোগ" → Greenhouse বোর্ড (যেমন কোনো পরিচিত কোম্পানি) → পরীক্ষা → সেভ → আবার খুঁজুন।
4. ট্র্যাকারের চাকরিতে আজ+৩ দিনের শেষ তারিখ দিন → রিমাইন্ডার তালিকায় এসেছে কিনা দেখুন।
5. ফোন B-তে একই অ্যাকাউন্টে লগইন → সেভ খোঁজ ও কোম্পানি দেখা যাচ্ছে কিনা।
