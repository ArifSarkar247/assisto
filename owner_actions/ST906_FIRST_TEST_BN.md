# SinoTrack ST-906 4G — প্রথম পরীক্ষা (মালিকের জন্য, সহজ বাংলা)

> আপনি কিনছেন: **ST-906 4G (রিলে-তারসহ)** + **GP বা Robi ডেটা সিম** + **একটি iTag** (~৳৫,৭০০)। আমরা কিছু কিনছি না।
> আমাদের সার্ভার এই যন্ত্রকে **H02 (Sinotrack)** ভাষায় চেনে, পোর্ট **5023**। নকল ST-901/906 দিয়ে পুরো পথ আগেই
> পরীক্ষা হয়েছে (`backend/core/tests_e2e_vehicle_dhaka.py`), আসল যন্ত্র এখনো একবারও সংযোগ দেয়নি। তাই প্রথম দিনেই
> আসল প্যাকেট দেখে মিলিয়ে নেব।

## ১. যন্ত্রে সিম ঢোকানোর আগে

1. সিমটি আগে একটি সাধারণ ফোনে ঢুকিয়ে **PIN লক বন্ধ** করুন, একটি **ছোট মাসিক ডেটা প্যাক** কিনুন (মাসে ~১২–২০ MB লাগে; ১ GB প্যাক অনেক), আর **SMS পাঠানোর ব্যালান্স** রাখুন (যন্ত্র SMS-এ উত্তর দেয়)।
2. সিমের নম্বর লিখে রাখুন। যন্ত্রের লেবেলে লেখা **ID** (সাধারণত ১০ অঙ্ক, কোনো মডেলে ১৫ অঙ্কের IMEI) ছবি তুলে রাখুন।
3. যন্ত্রের তার: লাল = +12V (ব্যাটারি), কালো = মাটি (GND), হলুদ/কমলা = ACC (চাবি), রিলের তার = রিলে। **প্রথম দিন রিলে তেল-পাম্পে লাগাবেন না** (নিচে ধাপ ৮)।
4. চালু হলে আলো: সবুজ = GPS, নীল/কমলা = নেটওয়ার্ক। জ্বলে-নেভে = খুঁজছে; স্থির বা ধীরে জ্বলা = ঠিক আছে (মডেলভেদে রং আলাদা — বাক্সের কার্ড দেখুন)। প্রথম GPS পেতে খোলা আকাশের নিচে ১–৫ মিনিট।

## ২. সেটআপ SMS (আপনার ফোন থেকে **যন্ত্রের সিম নম্বরে**)

ডিফল্ট পাসওয়ার্ড **`0000`** (কিছু ST-906L-এ `123456` — `0000` কাজ না করলে সেটি দিয়ে চেষ্টা করুন; নিচের প্রতিটি কমান্ডে পাসওয়ার্ড বদলে দিন)।
কমান্ডের মাঝে **একটি করে স্পেস**, শেষে কিছু নেই। প্রতিটির পর উত্তরের অপেক্ষা করুন (সাধারণত "SET OK" / "OK" ধরনের)।

| # | কাজ | SMS (GP) | SMS (Robi) | নোট |
|---|---|---|---|---|
| ১ | APN | `8030000 gpinternet` | `8030000 internet` | ইউজার/পাসওয়ার্ড লাগে না। লাগলে: `8030000 APN ইউজার পাস` |
| ২ | সার্ভার | `8040000 16.4.105.173 5023` | একই | আগে IP দিন (সব ফার্মওয়্যার নেয়)। ডোমেইনও চলে এমন রিপোর্ট আছে: `8040000 track.lifeassisto.com 5023` — IP কাজ করলে বদলানোর দরকার নেই |
| ৩ | GPRS চালু | `7100000` | একই | `7000000` = শুধু SMS মোড — দেবেন না |
| ৪ | সময় অঞ্চল | `8960000 E06` | একই | বাংলাদেশ UTC+6 (শুধু SMS-এ পাঠানো সময়ের জন্য; সার্ভার নিজে UTC ধরে) |
| ৫ | চাবি-চালু থাকলে বিরতি | `8050000 30` | একই | ৩০ সেকেন্ড পরপর লোকেশন (১০–৩০ ভালো) |
| ৬ | চাবি-বন্ধ থাকলে বিরতি | `8090000 300` | একই | ৫ মিনিট পরপর (হার্টবিট) |
| ৭ | সেটিং দেখা | `RCONF` (কিছু মডেলে `CXZT`) | একই | উত্তরে IP 16.4.105.173 5023, APN, `TIME1/TIME2` বা `UT:30,300,…` মিলিয়ে নিন |
| ৮ | লোকেশন SMS (ঐচ্ছিক) | `6690000` | একই | Google Maps লিংকসহ উত্তর — GPS কাজ করছে কিনা বোঝার জন্য |
| ৯ | পাসওয়ার্ড বদল (সব ঠিক হলে) | `777` + নতুন + পুরোনো, যেমন `77712340000` (নতুন 1234, পুরোনো 0000) | একই | এর পর সব কমান্ডে নতুন পাসওয়ার্ড। **কাগজে লিখে রাখুন** |

উৎস: SinoTrack ST-906 / ST-906GL / ST-906L ম্যানুয়াল (manuals.plus, manuals.online), gps-trace.com-এর ST-906 পাতা, Traccar ফোরাম।
সতর্কতা: মডেল/ফার্মওয়্যারভেদে সামান্য তফাত হয় — কোনো কমান্ডে উত্তর না এলে বাক্সের ম্যানুয়াল দেখুন বা ছবি তুলে পাঠান।
(সার্ভার নিজেও সংযোগ হলেই S71 কমান্ড দিয়ে বিরতি ঠিক করতে চায়; যন্ত্র না মানলে উপরের ৫–৬ নম্বর SMS-ই চলবে।)

## ৩. প্রথম প্যাকেট আসছে কিনা দেখা

**অ্যাপে:** আমার গাড়ি → লাইভ ট্র্যাকিং → "ট্র্যাকার যুক্ত করুন" → Sinotrack → লেবেলের ID। অপেক্ষার পর্দা খোলা রাখুন —
প্রথম প্যাকেট এলে "প্রথম লোকেশন এসেছে" দেখায় (সার্ভারে ট্র্যাকারের `state` = `paired`, `last_seen_at` ভরে যায়)।
পেয়ার-জানালা ১০ মিনিট; SMS পাঠানোর পর সাধারণত **১–৫ মিনিট** লাগে (GPS খুঁজতে আরও কয়েক মিনিট লাগতে পারে)।

**Owner Admin-এ (কাঁচা প্যাকেট):** `https://api.lifeassisto.com/owner/` → বাম মেনু **"ট্র্যাকার প্যাকেট"**
(`/owner/tracker-packets`)। শেষ ৫০টি প্যাকেট: সময়, ID-র শেষ ৪ অঙ্ক (বাকিটা ঢাকা), প্রোটোকল, পড়া তথ্য (অক্ষাংশ/দ্রাঘিমা/গতি/চাবি),
পড়া না গেলে ভুলের কারণ, আর কাঁচা hex। **অচেনা ID** থেকে প্যাকেট এলে সেটিও দেখায় ("পেয়ার করা নেই") — মানে অ্যাপে
ID ভুল লেখা হয়েছে। প্যাকেট ৭২ ঘণ্টা পর নিজে মুছে যায়।

কিছুই না এলে: (ক) সিমে ডেটা আছে? (খ) `RCONF`-এ IP/পোর্ট/APN ঠিক? (গ) `7100000` পাঠিয়েছেন? (ঘ) সার্ভারের পোর্ট 5023 বাইরে থেকে খোলা? — নিচে "আপনার করণীয়"।

দুইবার নিশ্চিত + আঙুলের ছাপ + PIN; চলন্ত হলে "থামলে পাঠান" — যন্ত্রে পাঠানোর ঠিক আগে আবার যাচাই, ৩০ মিনিটে না থামলে
বাতিল ও আপনাকে জানানো; প্রতিটি ধাপ অডিটে লেখা। যন্ত্র নিজেও ২০ কিমি/ঘণ্টার বেশি গতিতে রিলে কাটে না (ST-906L ম্যানুয়াল)।
`vehicle_engine_cut` সুইচ সবার জন্য বন্ধ থাকবে যতক্ষণ না ধাপ ৮–৯ পাস করে আপনি নিজে চালু করেন।

## ৫. iTag (ব্যাগ/চাবির Bluetooth ট্যাগ) — **অ্যাপে এখনো নেই**

আজ Assisto-তে Bluetooth ট্যাগের কোনো অংশ নেই; লিড একটি আলাদা কাজ (chip lane) শুরু করেছেন। সেটি এলে এই ধাপগুলো:
1. iTag-এর ব্যাটারির প্লাস্টিক টেনে খুলুন; বোতাম ৩ সেকেন্ড চেপে রাখুন — বিপ = চালু।
2. ফোনের Bluetooth চালু। অ্যাপ → ট্র্যাকার চিপ → "Bluetooth ট্যাগ যুক্ত করুন" → অ্যাপ নতুন অনুমতি (কাছের ডিভাইস) চাইবে → দিন।
3. তালিকায় "iTag" / "iTAG" দেখালে চাপুন → নাম দিন (যেমন "চাবির গোছা")।
4. **বাজানো:** অ্যাপে "বাজান" → ট্যাগ বিপ দেয় (১০ মিটারের মধ্যে)।
5. **ফেলে আসা:** ট্যাগ টেবিলে রেখে ফোন নিয়ে ২০–৩০ মিটার দূরে যান → "ফেলে এসেছেন?" সতর্কবার্তা (কত সেকেন্ডে এল লিখুন)।
6. **উল্টো খোঁজা:** ট্যাগের বোতাম দুবার চাপুন → ফোন বাজে (অ্যাপ খোলা/পটভূমিতে থাকলে — Android-এর সীমা)।
7. সৎ সীমা: iTag-এর নিজস্ব GPS নেই — শুধু ফোনের কাছে থাকলে কাজ করে; Apple/Google/Samsung ট্যাগ আমাদের অ্যাপে যুক্ত করা যায় না (খোলা API নেই)।

## ৬. আপনার করণীয় (আমরা পারি না)
- **AWS Security Group-এ TCP 5023 inbound খোলা আছে কিনা** দেখুন (EC2 → Instances → সার্ভার → Security → Inbound rules → 5023, উৎস 0.0.0.0/0)। আমরা AWS ছুঁই না।
  সার্ভারের ভেতরে ট্র্যাকার সার্ভিস চালু ও 5023-এ শুনছে — ১৭ নভেম্বর যাচাই করা (`ss -ltnp`)।
- রিলে পাম্পে লাগানো **শুধু মেকানিক দিয়ে**, ধাপ ৮–৯ পাসের পর।
- কোনো ধাপ ফেল করলে: স্ক্রিনশট + সময় + Owner Admin → ট্র্যাকার প্যাকেট পাতার ছবি পাঠান — একই দিনে ঠিক করব।
