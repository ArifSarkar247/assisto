# ইমেইল প্রোভাইডার — মালিকের সিদ্ধান্ত (emailrel, ১৬ নভেম্বর)

**কেন:** এখন ইমেইল যায় কোম্পানির Gmail (SMTP) দিয়ে। Gmail দিনে প্রায় ৫০০ প্রাপকের বেশি নেয় না; সীমা পেরোলে "550 5.4.5 Daily sending quota" দেয় আর সেদিন আর মেইল যায় না। আমাদের নিজের সীমা ৪০০ (Owner Admin → Pricing → email)। ব্যবহারকারী বাড়লে লগইন কোড/নিরাপত্তা মেইল আটকে যাবে। আর Gmail বাউন্সের তথ্য দেরিতে, আলাদা মেইলে দেয়।

**এখন কী করা আছে (খরচ ছাড়া):** সীমার ৭০%-এ রিপোর্ট বন্ধ, ৯০%-এ শুধু কোড ও নিরাপত্তা; Gmail সীমা বললে ১ ঘণ্টা বিরতি + আপনাকে নোটিফিকেশন; কোড SMS-এ চলে যায়। Owner Admin → **ইমেইল স্বাস্থ্য**-এ প্রতিদিনের সংখ্যা দেখুন। দিনে ৩০০-র বেশি নিয়মিত হলে নিচের যেকোনো একটি নিন।

## সুপারিশ (চূড়ান্ত সিদ্ধান্ত আপনার)
**Zoho ZeptoMail** — শুধু লেনদেন/কোডের মেইলের জন্য বানানো, সবচেয়ে কম খরচ (মাসে ৩০,০০০ মেইলেও ≈ $৫-৮), দৈনিক সীমা নেই, বাউন্স তথ্য দেয়। দ্বিতীয় পছন্দ: Brevo-র ফ্রি প্ল্যান (দিনে ৩০০) Gmail-এর পাশে ব্যাকআপ হিসেবে।

## আপনি যা করবেন (আমরা কোনো অ্যাকাউন্ট খুলিনি, কোনো টাকা খরচ হয়নি)
১. প্রোভাইডারে অ্যাকাউন্ট খুলুন, lifeassisto.com ডোমেইন যোগ করুন।
২. তারা যে SPF, DKIM, DMARC রেকর্ড দেবে সেগুলো ডোমেইনের DNS-এ বসান (আমরা সাহায্য করব)।
৩. Owner Admin → Integrations → Email-এ Host / Port / Username / Password বদলে "টেস্ট ইমেইল পাঠান"।
৪. Pricing → email.daily_cap বাড়ান (যেমন ৫০০০)।
কোড বদলাতে হবে না — সব প্রোভাইডার SMTP দেয়। বাউন্স ওয়েবহুক যোগ করা পরের ছোট কাজ।
