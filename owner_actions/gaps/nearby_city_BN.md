# কাছের জরুরি তালিকা (সারি ৫৩) + সিটি সার্ভিস (সারি ৬১) — গ্যাপ (gap-nearby, ১৮ নভেম্বর)

শাখা `agent/gap-nearby`। কোড পড়ে, ডেটা-রানের আসল ফাইল খুলে আর লাইভ ম্যাপ সার্ভার যাচাই করে পাওয়া।
নিয়ম: জরুরি তালিকায় কোনো বিজ্ঞাপন নেই, কোনো পেওয়াল নেই; হাসপাতাল/থানা/ফায়ারের নম্বর শুধু সূত্রসহ তালিকা থেকে, কখনো বানানো নম্বর নয়।

* ডিস্ক: ১.১ GB/রিলিজ — পুরোনো রিলিজ ২টির বেশি রাখবেন না (ডিস্ক ৫০%-এর নিচে রাখার নিয়ম)।

## দুই-ফোন মালিক টেস্ট (৫ মিনিট)
1. ফোন ১: কাছের জরুরি → হাসপাতাল → তালিকা আসে; নিচে টানুন → "হালনাগাদ হলো"।
2. ফোন ১: বিমান মোড → আবার খুলুন → "অফলাইন — … তারিখে সেভ করা তালিকা"।
3. ফোন ২: Owner Admin → Nearby list → একটি হাসপাতালে নম্বর বসান → ফোন ১-এ টানুন → নতুন নম্বর, নিচে "Assisto যাচাই করা নম্বর"।
4. ফোন ২: সিটি সার্ভিস → মেট্রো গাইড → "দুই স্টেশনের ভাড়া": উত্তরা উত্তর → আগারগাঁও = ৬০ টাকা (কার্ডে ৫৪)।
5. ফোন ২: রুট → "নিরাপদ যাত্রা হিসেবে শুরু" (নেট বন্ধ) → নামার স্টপের ৪০০ মিটারের মধ্যে অ্যালার্ম বাজে।
