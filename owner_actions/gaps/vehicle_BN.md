# গাড়ি ট্র্যাকিং (বোর্ড সারি ১২) — ফাঁক, প্রমাণ, আসল ST-906 পরীক্ষা

> লেন: vehicle-e2e (১৮ নভেম্বর)। সব প্রমাণ CI-তে; লাইভ সার্ভার/ডেটাবেস/ফ্ল্যাগ ছোঁয়া হয়নি। সব নাম/জায়গা বানানো নমুনা।

## ১. কী প্রমাণ হলো (এমুলেটরে, আসল অ্যাপে)

রিয়েলিটি ফ্লো **12v** (`app/integration_test/flows/vehicle_st906_flow.dart`, reality.yml `only=vehicle`):
একটি **নকল SinoTrack ST-906** টেস্টের ভেতর থেকে আসল TCP দিয়ে CI-র **আসল ট্র্যাকার সার্ভারে** (পোর্ট 5023) কথা বলে —
ঠিক যন্ত্রের ভাষায় (H02): প্রথম লোকেশন ও চাবি বদলে লেখা `*HQ,…,V1,…#`, চলার সময় ৩২-বাইটের **বাইনারি** `$` রেকর্ড,
আর সার্ভারের নির্দেশে `*HQ,…,V4,S20,DONE,…#` উত্তর। অ্যাপ এমুলেটরে খোলা, মালিক A হিসেবে।

| # | কী | কীভাবে দেখা হলো |
|---|---|---|
| ক | ID দিয়ে পেয়ার | অ্যাপে "ট্র্যাকার যুক্ত করুন" → Sinotrack → ID → সেটআপ পর্দায় "প্রথম লোকেশন এসেছে" |
| খ | ঢাকার পথে লাইভ চলা | ধানমন্ডি ২৭ → পান্থপথ → কারওয়ান বাজার, আসল সময়ে (৩ সেকেন্ড পরপর); ম্যাপের চিহ্ন ও **রেখা** পর্দায় সরে |
| গ | চাবি চালু/বন্ধ | নোটিফিকেশন সেন্টারে "… started" / "… switched off" |
| ঘ | অতিরিক্ত গতি | সীমা ৬০, খালি রাস্তায় ৭৫ → "… is going fast" |
| ঙ | এলাকা ছাড়া | বাসার ১৫০ মি এলাকা ছাড়লে "… left an area" (অফিসে ঢুকলে "entered") |
| চ | ইঞ্জিন বন্ধ | চলন্ত অবস্থায় → প্রত্যাখ্যান (পুরো কারণ দেখায়) → "এখন না" = কিছুই যায় না; "থামলে বন্ধ করুন" → চলার সময় যন্ত্রে **কিছুই যায় না** → ৩টি থামা লোকেশন → যন্ত্রে ঠিক `*HQ,<id>,S20,<সময়>,1,1#` বাইট → "ট্র্যাকার নিশ্চিত করেছে", রিলে "বন্ধ"; তারপর আবার চালু `…,1,0#` |
| ছ | ট্র্যাকার নীরব | সংযোগ বন্ধ → "অফলাইন · শেষ দেখা …" (শেষ ফ্রেমের সময়ের ±১০ সেকেন্ডে) + "tracker not responding" সতর্কতা। CI-তে অনলাইন-জানালা ৬০ সেকেন্ড (নিম্নসীমা), আসলে ১০ মিনিট |
| জ | আজকের যাত্রা | ট্র্যাকার পর্দায় যাত্রা, কিমি, সর্বোচ্চ গতি — API-র সংখ্যার সাথে মেলে |

দেরি মাপা (প্যাকেট → সার্ভার → অ্যাপ পর্দা): ফ্লো নোটে ও লগে `VEH_E2E_LATENCY {…}` — নিচে রান আইডির পাশে সংখ্যা।

## ২. যে ফাঁক পাওয়া গেল ও ঠিক হলো

1. **"থামলে পাঠান" অ্যাপে ছিলই না।** সার্ভারে নিরাপদ হোল্ড (when_stopped, ৩০ মিনিট) ছিল, মালিকের পরীক্ষার ধাপ ৯-এও লেখা ছিল,
   কিন্তু অ্যাপ শুধু "গাড়ি চলছে" লিখে থেমে যেত। এখন: প্রত্যাখ্যানের পুরো কারণ + "থামলে বন্ধ করুন" / "এখন না" (ডিফল্ট "এখন না")।
2. **অপেক্ষমাণ নির্দেশের ভুল লেখা।** হোল্ড করা নির্দেশ দেখাত "পাঠানোর অপেক্ষায়" (যেন এখনই যাবে); এখন "গাড়ি থামার অপেক্ষায় (সর্বোচ্চ ৩০ মিনিট)";
   না থামলে "পাঠানো হয়নি: গাড়ি সময়মতো থামেনি" (আগে শুধু "মেয়াদ শেষ")।
3. **চলন্ত গাড়ির রেখা ও "যাত্রা" জমে থাকত।** ট্র্যাকার পর্দা খোলার সময় একবার রেখা আনত; চিহ্ন সরত কিন্তু রেখা/কিমি/যাত্রা
   পর্দা আবার না খোলা পর্যন্ত পুরোনো। এখন চলার সময় ~২৪ সেকেন্ডে, আর থামা/চলা/চাবি বদলালে সাথে সাথে।
4. **নকল যন্ত্রের বাইনারি এনকোডার** (`h02.binary_packet`) ১০ মিনিটের কম দ্রাঘিমায় ভাঙত (৫ অঙ্ক) — ৬ অঙ্ক করা হলো (সার্ভারের পার্সার ঠিকই ছিল)।
5. পেয়ার ফর্মের ঘরে স্থির কী (`veh-pair-imei`, `veh-pair-name`) — স্বয়ংক্রিয় পরীক্ষার জন্য।

টেস্ট: `app/test/vehicle_e2e_test.dart` (৫টি), `backend/core/tests_vehicle_e2e_lane.py` (নকল ST-906-এর ঠিক ফ্রেম, রিলে বাইট, সিড)।

## ৩. যা এখনো বাকি (সৎ)
- **আসল ST-906 একবারও সংযোগ দেয়নি** — সব প্রমাণ নকল যন্ত্রে। আসল ফার্মওয়্যার টেক্সট না বাইনারি পাঠায়, status-বিট (চাবি = বিট ১০) মেলে কিনা — প্রথম দিনেই Owner Admin → "ট্র্যাকার প্যাকেট" দেখে মেলাতে হবে।
- অ্যাপ বন্ধ থাকলে FCM পুশ CI-তে প্রমাণ করা যায় না (Firebase কী নেই) — অ্যাপে নোটিফিকেশন সেন্টার প্রমাণিত; বন্ধ-অ্যাপ পুশ দুই ফোনে দেখতে হবে।
- সেটিং (সীমা/এলাকা) CI-তে API দিয়ে রাখা; সেটিং পর্দা হাতে চালিয়ে দেখা মালিকের তালিকায়।
- রিলে আসলে তেল-পাম্প কাটে কিনা — শুধু আসল যন্ত্র + মেকানিক।
