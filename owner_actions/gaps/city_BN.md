# সিটি সার্ভিস — ফিচার গ্যাপ (gap-city, ১৭ নভেম্বর)

শাখা `agent/gap-city`। কোড পড়ে, ফ্লো চালিয়ে (টেস্টে) আর লাইভ ম্যাপ সার্ভার যাচাই করে পাওয়া — যেগুলো "আসল ফোন লাগবে" নয়।
ডেটার পরিমাণ (কত রুট/স্টপ) এখানে ধরা হয়নি — ওটা citycov3-এর কাজ।

**লাইভ ম্যাপ যাচাই:** `api.lifeassisto.com/maps/v1/` চালু — ৪টি স্টাইল, ফন্ট (বাংলা PGF সহ), স্প্রাইট, PMTiles (Range চলে, 206), অফলাইন manifest সব 200।
অ্যাপ আসলেই এটাই খোলে: সার্ভারের `/city/map` → `tiles_base` = এই ঠিকানা; টেস্ট-ক্যানভাস শুধু টেস্ট/গ্যালারিতে (`debugCanvas`)। স্টাইলের লেয়ার-নাম (`road-labels`, `buildings-3d`) অ্যাপের সাথে মেলে। ম্যাপের ভেতরের বাংলা লেখা টাইলেই pre-shaped (PGF); আমাদের নিজের লেবেল Flutter উইজেট — ঠিক আছে।

## দুই-ফোন মালিক টেস্ট (৫ মিনিট)
1. ফোন ১: সিটি সার্ভিস → "অফিসের গাইড" → পাসপোর্ট অফিসে "বাস / মেট্রোতে যাওয়ার পথ" → রুট ও ভাড়া আসে?
2. ফোন ১: লোকেশন বন্ধ করে গন্তব্য দিন → "কোথা থেকে যাবেন?" আর দুটি বোতাম আসে?
3. ফোন ২: মাইক → "Farmgate theke Motijheel jabo" → রুট আসে? একটা মলের নাম বলুন → "সব জায়গার মধ্যে খুঁজুন" → বাছলে রুট?
4. ফোন ২: ম্যাপ → অফলাইন ঢাকা নামান → বিমান মোড → ম্যাপে রাস্তার নাম (বাংলা) দেখা যায়?
