# সারি ৪৯ — সেফটি প্ল্যান, ম্যাপ-খরচ, দুই অভিভাবক (safety-plan লেন, ১৮ Nov)

**কী কথা দেওয়া ছিল** (মালিকের আদেশ ৩ Nov 18:40): ম্যাপ-খরচে লাগাম (যাত্রা নিজে ০টি পেইড কল, সীমা পার হলে বিনা খরচের বিকল্প); চাইল্ড প্ল্যান / সেফ ফ্যামিলি / স্কুল সেফ (Play সাবস্ক্রিপশন); দুই অভিভাবক — দুজনেই সব সতর্কবার্তা পাবেন, শিশু দেখবে কে কে দেখছে। লিড যোগ করেছেন: পরিবারের নিরাপত্তা পরিকল্পনা (কোথায় দেখা, জরুরি নম্বর, কাকে আগে ফোন) — শেয়ার করা যায়, ইন্টারনেট ছাড়াও খোলে।

**আগে থেকে ছিল:** দ্বিতীয় অভিভাবকের আমন্ত্রণ → অনুমোদন (`core/guardian_links.py`), SOS/স্কুল/কিডস-ওয়াচ সতর্কবার্তা দুজনকে; ম্যাপ-কলে দৈনিক সীমা (`core/maps_cost.py`); প্ল্যান/ক্রেডিটের সার্ভার নিয়ম (`core/safe_plans.py`)।

**সৎ সীমা:** ওয়েব শেয়ার পাতার OSM টাইল ব্রাউজার নিজে আনে (সার্ভারে গোনা যায় না; শুধু টাইল বদলালে আনে); যাত্রার সীমা যাত্রা শুরুর দিনে গোনা; ইমুলেটর ≠ আসল দুই ফোন।

**মালিকের দুই-ফোন পরীক্ষা (৫ মিনিট):** ফোন ১ = শিশু, ফোন ২ = মা, ফোন ৩ = বাবা (অনুমোদিত দ্বিতীয় অভিভাবক)। ১) শিশুর ফোনে My Trip শুরু, শুধু মাকে বাছুন → মা ও বাবা দুজনেই "যাত্রা শুরু" পান; শিশুর পর্দায় "দেখেন: মা, বাবা"। ২) পৌঁছেছি চাপুন → দুজনেই পান। ৩) Safe Journey → পরিবারের নিরাপত্তা পরিকল্পনা → জায়গা + মা + ৯৯৯ → সেভ করে শেয়ার → মায়ের ফোনে দেখা যায়। ৪) শিশুর ফোনে বিমান মোড → পরিকল্পনা তবুও খোলে।
