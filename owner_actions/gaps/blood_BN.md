# রক্তদাতা — ফিচার-ফাঁক তালিকা (গ্যাপ লেন `quranblood`, ১৭ Nov)

বোর্ড সারি ৪৬। যাচাই: দাতার নম্বর শুধু দাতা নিজে "আমার ফোন নম্বর দেখান" চালু করলে দেখা যায় (সার্ভার `public_card`, `thread_json`, `responders`) — অনুমতি ছাড়া নম্বর ফাঁসের পথ পাওয়া যায়নি (P0 নেই)। কোনো বিজ্ঞাপন/কেনার বোতাম নেই।

প্রতিটি ফাঁক: **ব্যবহারকারী যা দেখেন → যা হওয়া উচিত → গুরুত্ব**।

## মালিকের দুই-ফোন পরীক্ষা (১০ মিনিট)
১. ফোন ক (দাতা, A+) ফোন খ-কে বার্তায় ব্লক করুন → ফোন খ "দাতা খুঁজুন"-এ ক-কে আর দেখে না; অন্য ফোন গ দেখে।
২. ফোন খ অনুরোধ দিন → "অনুরোধটি শেয়ার করুন" → WhatsApp-এ লেখাটা দেখুন: গ্রুপ, ব্যাগ, হাসপাতাল, সময়, লিংক আছে; কোনো ফোন নম্বর নেই।
৩. "দাতা খুঁজুন" → B+ → "B+ রোগীকে দিতে পারেন এমন সব গ্রুপ" চাপলে O+/O−/B− দাতাও আসে।
৪. ফোন ক → "আমি দাতা" → "আপনার নম্বর: গোপন" চাপুন → কারা দেখবেন লেখা আসে; "গোপন রাখুন" চাপলে কিছু বদলায় না।
৫. "আজ রক্ত দিলাম" → "অন্য দিনে দিয়েছি" → ৩ দিন আগের তারিখ → পরের তারিখ সেই হিসাবে বদলায়।
